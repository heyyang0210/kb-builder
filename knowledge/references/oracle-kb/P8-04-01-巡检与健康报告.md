# Oracle巡检与健康报告

## 一、概述

### 1.1 一句话定义

Oracle巡检与健康报告是定期对数据库进行全面检查，生成包含性能、可用性、安全和容量状况的综合报告，为运维决策提供依据。
它在定期运维和质量评估中出现和使用，解决数据库当前状态如何、存在哪些风险的问题。

### 1.2 为什么重要

- **不掌握的后果：** 隐患积累，突发故障
- **掌握的价值：** 提前发现风险，保障数据库稳定运行

### 1.3 适用场景

| 场景 | 说明 |
|------|------|
| 定期巡检 | 每日/周/月巡检 |
| 健康评估 | 数据库健康度评分 |
| 性能报告 | 性能趋势分析 |
| 合规审计 | 安全合规检查 |

### 3.3 巡检脚本

```sql
-- 综合巡检脚本
-- 1. 实例状态
SELECT '=== Instance Status ===' FROM dual;
SELECT instance_name, status, database_status, 
       TO_CHAR(startup_time, 'YYYY-MM-DD HH24:MI') AS startup_time
FROM v$instance;

-- 2. 表空间
SELECT '=== Tablespace Usage ===' FROM dual;
SELECT tablespace_name, ROUND(used_percent, 2) AS used_pct,
       CASE WHEN used_percent > 95 THEN 'CRITICAL'
            WHEN used_percent > 85 THEN 'WARNING'
            ELSE 'OK' END AS status
FROM dba_tablespace_usage_metrics ORDER BY used_percent DESC;

-- 3. 性能概览
SELECT '=== Performance ===' FROM dual;
SELECT event, total_waits, time_waited_micro/1000000 AS seconds
FROM v$system_event WHERE wait_class = 'User I/O'
ORDER BY time_waited_micro DESC FETCH FIRST 5 ROWS ONLY;

-- 4. 备份状态
SELECT '=== Backup Status ===' FROM dual;
SELECT input_type, status, 
       TO_CHAR(start_time, 'MM-DD HH24:MI') AS start_time,
       ROUND(output_bytes/1024/1024/1024, 2) AS output_gb
FROM v$rman_backup_job_details
WHERE start_time > SYSDATE - 7 ORDER BY start_time DESC;

-- 5. 无效对象
SELECT '=== Invalid Objects ===' FROM dual;
SELECT owner, object_type, COUNT(*) 
FROM dba_objects WHERE status = 'INVALID'
GROUP BY owner, object_type;

-- 6. 告警日志最近错误
SELECT '=== Recent Alert Log Errors ===' FROM dual;
-- 需要OS级别检查alert log

-- 7. 过期密码
SELECT '=== Expiring Passwords ===' FROM dual;
SELECT username, account_status, expiry_date
FROM dba_users WHERE expiry_date < SYSDATE + 30
AND account_status = 'OPEN';
```

### 3.4 AWR健康报告

```sql
-- 生成AWR报告
-- 方法1：命令行
-- @$ORACLE_HOME/rdbms/admin/awrrpt.sql

-- 方法2：PL/SQL
DECLARE
    v_report CLOB;
BEGIN
    v_report := DBMS_WORKLOAD_REPOSITORY.AWR_REPORT_HTML(
        l_dbid => (SELECT dbid FROM v$database),
        l_inst_num => 1,
        l_bid => (SELECT MIN(snap_id) FROM dba_hist_snapshot WHERE begin_interval_time > SYSDATE - 1),
        l_eid => (SELECT MAX(snap_id) FROM dba_hist_snapshot WHERE begin_interval_time > SYSDATE - 1)
    );
    -- 输出报告
    DBMS_OUTPUT.PUT_LINE(v_report);
END;
/

-- SQL Statistics (by Elapsed Time, CPU, Gets)
-- Instance Activity Stats
-- Tablespace IO Stats
```

### 7.1 案例：月度巡检发现隐患

```
巡检发现：
1. USERS表空间使用率87%（按当前增长率，2周后满）
2. Top SQL #1消耗40% CPU（缺少索引）
3. 3个用户密码即将过期

处理：
1. 扩容USERS表空间
2. 为Top SQL添加索引
3. 通知用户修改密码

效果：避免了表空间满导致的业务中断
```
