# Oracle表空间日常管理

## 一、概述

### 1.1 一句话定义

Oracle表空间管理是对数据库逻辑存储单元的日常维护操作，包括创建、扩展、监控、收缩和迁移表空间。
它在数据库存储管理中出现和使用，解决数据如何组织存储以及存储空间如何分配的问题。

### 1.2 为什么重要

- **不掌握的后果：** 表空间满导致业务中断，存储碎片影响性能
- **掌握的价值：** 保障数据库持续可用，优化存储使用效率

### 1.3 适用场景

| 场景 | 说明 |
|------|------|
| 空间扩展 | 表空间容量不足 |
| 空间监控 | 日常容量规划 |
| 存储优化 | 减少碎片，回收空间 |
| 数据迁移 | 表空间在线移动 |

## 三、核心原理

### 3.1 表空间创建

```sql
-- 创建标准表空间
CREATE TABLESPACE app_data
    DATAFILE '/u02/oradata/app_data01.dbf' SIZE 10G
    AUTOEXTEND ON NEXT 1G MAXSIZE 100G
    EXTENT MANAGEMENT LOCAL AUTOALLOCATE
    SEGMENT SPACE MANAGEMENT AUTO;

-- 创建大文件表空间
CREATE BIGFILE TABLESPACE app_big
    DATAFILE '/u02/oradata/app_big01.dbf' SIZE 50G
    AUTOEXTEND ON NEXT 5G MAXSIZE UNLIMITED;

-- 创建临时表空间
CREATE TEMPORARY TABLESPACE app_temp
    TEMPFILE '/u02/oradata/app_temp01.dbf' SIZE 5G
    AUTOEXTEND ON NEXT 1G MAXSIZE 30G;

-- 创建Undo表空间
CREATE UNDO TABLESPACE app_undo
    DATAFILE '/u02/oradata/app_undo01.dbf' SIZE 10G
    AUTOEXTEND ON NEXT 500M MAXSIZE 50G;

-- 创建只读表空间
CREATE TABLESPACE archive_data
    DATAFILE '/u02/oradata/archive01.dbf' SIZE 5G;
ALTER TABLESPACE archive_data READ ONLY;
```

### 3.2 表空间扩展

```sql
-- 方法1：添加数据文件
ALTER TABLESPACE app_data
    ADD DATAFILE '/u02/oradata/app_data02.dbf' SIZE 10G
    AUTOEXTEND ON NEXT 1G MAXSIZE 100G;

-- 方法2：调整现有数据文件大小
ALTER DATABASE DATAFILE '/u02/oradata/app_data01.dbf' RESIZE 20G;

-- 方法3：启用自动扩展
ALTER DATABASE DATAFILE '/u02/oradata/app_data01.dbf'
    AUTOEXTEND ON NEXT 1G MAXSIZE 100G;

-- 查看表空间使用情况
SELECT tablespace_name,
       ROUND(SUM(bytes)/1024/1024) AS total_mb,
       ROUND(SUM(maxbytes)/1024/1024) AS max_mb
FROM dba_data_files
GROUP BY tablespace_name;
```

### 3.3 表空间监控

```sql
-- 表空间使用率
SELECT a.tablespace_name,
       ROUND(a.total_mb) AS total_mb,
       ROUND(b.free_mb) AS free_mb,
       ROUND((a.total_mb - b.free_mb) / a.total_mb * 100, 2) AS pct_used,
       ROUND(a.max_mb) AS max_mb
FROM (SELECT tablespace_name,
             SUM(bytes)/1024/1024 AS total_mb,
             SUM(maxbytes)/1024/1024 AS max_mb
      FROM dba_data_files
      GROUP BY tablespace_name) a
LEFT JOIN (SELECT tablespace_name,
                  SUM(bytes)/1024/1024 AS free_mb
           FROM dba_free_space
           GROUP BY tablespace_name) b
ON a.tablespace_name = b.tablespace_name
ORDER BY pct_used DESC;

-- 数据文件I/O统计
SELECT df.name AS file_name,
       fs.phyrds AS reads,
       fs.phywrts AS writes,
       fs.readtim AS read_time,
       fs.writetim AS write_time
FROM v$filestat fs
JOIN v$datafile df ON fs.file# = df.file#
ORDER BY fs.phyrds + fs.phywrts DESC;

-- 表空间增长趋势
SELECT tablespace_name,
       TO_CHAR(snap_time, 'YYYY-MM-DD') AS date,
       used_space * 8 / 1024 AS used_mb
FROM dba_hist_tbspc_space_usage
WHERE snap_time > SYSDATE - 30
ORDER BY tablespace_name, snap_time;
```

### 3.4 表空间收缩

```sql
-- 回收表空间中的空闲空间
-- 方法1：收缩数据文件
ALTER DATABASE DATAFILE '/u02/oradata/app_data01.dbf' RESIZE 5G;

-- 方法2：在线表空间收缩（12c+）
ALTER TABLESPACE app_data SHRINK SPACE;

-- 查看可回收空间
SELECT file_name, 
       bytes/1024/1024 AS current_mb,
       (bytes - (SELECT MAX(block_id) * 8192 FROM dba_extents 
                 WHERE file_id = df.file#))/1024/1024 AS reclaimable_mb
FROM dba_data_files df;
```

### 3.5 表空间在线移动（12c+）

```sql
-- 在线移动数据文件
ALTER DATABASE MOVE DATAFILE '/u02/oradata/app_data01.dbf'
    TO '/u03/oradata/app_data01.dbf';

-- 移动并重命名
ALTER DATABASE MOVE DATAFILE '/u02/oradata/app_data01.dbf'
    TO '/u03/oradata/new_name.dbf';

-- 复制到新位置（保留原文件）
ALTER DATABASE MOVE DATAFILE '/u02/oradata/app_data01.dbf'
    TO '/u03/oradata/app_data01.dbf' COPY;

-- 查看移动进度
SELECT file_name, status, bytes/1024/1024 AS mb,
       sofar/1024/1024 AS done_mb
FROM v$datafile_copy_migration;
```

### 3.6 表空间状态管理

```sql
-- 离线/在线
ALTER TABLESPACE app_data OFFLINE;
ALTER TABLESPACE app_data ONLINE;

-- 只读/读写
ALTER TABLESPACE app_data READ ONLY;
ALTER TABLESPACE app_data READ WRITE;

-- 查看表空间状态
SELECT tablespace_name, status, contents, extent_management
FROM dba_tablespaces;
```

## 九、最佳实践

### 9.1 官方推荐

- 使用本地管理表空间
- 启用自动扩展
- 分离应用数据和系统数据
- 定期监控表空间使用率

### 9.2 反模式

| 反模式 | 问题 | 正确做法 |
|--------|------|---------|
| 不监控空间 | 突然满导致宕机 | 设置告警 |
| 不启用自动扩展 | 手动干预不及时 | 启用AUTOEXTEND |
| 所有数据一个表空间 | 管理困难 | 按用途分离 |
| 不回收空间 | 存储浪费 | 定期收缩 |
