# Oracle系统触发器

## 一、概述

### 1.1 一句话定义

Oracle系统触发器是响应数据库级或Schema级事件（如登录、登出、启动、关闭、DDL操作）的触发器，用于实现数据库级的自动管理。
它在数据库安全管理中出现和使用，解决登录审计、DDL监控和自动管理的问题。

### 1.2 为什么重要

- **不掌握的后果：** 无法实现数据库级自动管理，安全审计不完整
- **掌握的价值：** 自动化数据库管理，完善安全审计

### 1.3 适用场景

| 场景 | 说明 |
|------|------|
| 登录审计 | 记录用户登录 |
| DDL监控 | 跟踪结构变更 |
| 自动初始化 | 会话初始化 |
| 安全控制 | 登录限制 |

## 二、术语与概念

### 2.1 核心术语表

| 术语 | 含义 | 类比 |
|------|------|------|
| DATABASE Trigger | 数据库级触发器 | 全局监控 |
| SCHEMA Trigger | Schema级触发器 | 用户监控 |
| System Event | 系统事件 | 数据库事件 |
| LOGIN/LOGOFF | 登录/登出 | 进出事件 |
| STARTUP/SHUTDOWN | 启动/关闭 | 开关机 |

## 三、核心原理

### 3.1 系统事件类型

| 事件 | 说明 | 时机 |
|------|------|------|
| LOGON | 登录后 | AFTER |
| LOGOFF | 登出前 | BEFORE |
| STARTUP | 数据库启动后 | AFTER |
| SHUTDOWN | 数据库关闭前 | BEFORE |
| SERVERERROR | 错误发生时 | AFTER |
| CREATE/ALTER/DROP | DDL操作 | BEFORE/AFTER |

### 3.2 登录审计触发器

```sql
-- 创建登录审计表
CREATE TABLE login_audit(
    logon_time TIMESTAMP,
    logoff_time TIMESTAMP,
    username VARCHAR2(30),
    machine VARCHAR2(64),
    ip_address VARCHAR2(30),
    session_id NUMBER
);

-- 登录触发器
CREATE OR REPLACE TRIGGER trg_logon_audit
AFTER LOGON ON DATABASE
BEGIN
    INSERT INTO login_audit(logon_time, username, machine, ip_address, session_id)
    VALUES(
        SYSTIMESTAMP,
        SYS_CONTEXT('USERENV', 'SESSION_USER'),
        SYS_CONTEXT('USERENV', 'HOST'),
        SYS_CONTEXT('USERENV', 'IP_ADDRESS'),
        SYS_CONTEXT('USERENV', 'SESSIONID')
    );
END;
/

-- 登出触发器
CREATE OR REPLACE TRIGGER trg_logoff_audit
BEFORE LOGOFF ON DATABASE
BEGIN
    UPDATE login_audit
    SET logoff_time = SYSTIMESTAMP
    WHERE session_id = SYS_CONTEXT('USERENV', 'SESSIONID')
      AND logoff_time IS NULL;
EXCEPTION
    WHEN OTHERS THEN NULL;  -- 登出时不抛异常
END;
/
```

### 3.3 DDL监控触发器

```sql
-- DDL审计表
CREATE TABLE ddl_audit(
    event_time TIMESTAMP,
    event_type VARCHAR2(30),
    object_owner VARCHAR2(30),
    object_name VARCHAR2(30),
    object_type VARCHAR2(30),
    sql_text CLOB,
    username VARCHAR2(30)
);

-- DDL触发器
CREATE OR REPLACE TRIGGER trg_ddl_audit
AFTER CREATE OR ALTER OR DROP ON DATABASE
DECLARE
    v_sql_text ORA_NAME_LIST_T;
    v_sql CLOB;
    v_lines NUMBER;
BEGIN
    v_lines := ORA_SQL_TXT(v_sql_text);
    FOR i IN 1..v_lines LOOP
        v_sql := v_sql || v_sql_text(i);
    END LOOP;
    
    INSERT INTO ddl_audit(
        event_time, event_type, object_owner, object_name,
        object_type, sql_text, username
    ) VALUES(
        SYSTIMESTAMP, ORA_SYSEVENT, ORA_DICT_OBJ_OWNER,
        ORA_DICT_OBJ_NAME, ORA_DICT_OBJ_TYPE,
        v_sql, SYS_CONTEXT('USERENV', 'SESSION_USER')
    );
END;
/
```

### 3.4 会话初始化触发器

```sql
-- 用户登录后自动设置
CREATE OR REPLACE TRIGGER trg_session_init
AFTER LOGON ON SCHEMA
BEGIN
    EXECUTE IMMEDIATE 'ALTER SESSION SET NLS_DATE_FORMAT = ''YYYY-MM-DD HH24:MI:SS''';
    EXECUTE IMMEDIATE 'ALTER SESSION SET CURRENT_SCHEMA = APP_SCHEMA';
END;
/
```

### 3.5 安全控制触发器

```sql
-- 限制特定时间登录
CREATE OR REPLACE TRIGGER trg_login_restriction
AFTER LOGON ON DATABASE
DECLARE
    v_hour NUMBER;
BEGIN
    v_hour := EXTRACT(HOUR FROM SYSTIMESTAMP);
    
    -- 非工作时间限制DBA登录
    IF (v_hour < 8 OR v_hour > 20) AND
       SYS_CONTEXT('USERENV', 'SESSION_USER') IN ('DBA1', 'DBA2') THEN
        RAISE_APPLICATION_ERROR(-20001, '非工作时间禁止DBA登录');
    END IF;
END;
/
```

## 七、高级系统触发器

### 7.1 登录审计触发器

```sql
-- 记录所有登录信息
CREATE OR REPLACE TRIGGER trg_logon_audit
AFTER LOGON ON DATABASE
DECLARE
    v_ip VARCHAR2(30);
BEGIN
    v_ip := SYS_CONTEXT('USERENV', 'IP_ADDRESS');
    INSERT INTO logon_audit(
        username, logon_time, ip_address, module, program
    ) VALUES (
        SYS_CONTEXT('USERENV', 'SESSION_USER'),
        SYSDATE, v_ip,
        SYS_CONTEXT('USERENV', 'MODULE'),
        SYS_CONTEXT('USERENV', 'PROGRAM')
    );
EXCEPTION WHEN OTHERS THEN NULL;
END;
/

-- 限制非工作时间登录
CREATE OR REPLACE TRIGGER trg_restrict_off_hours
AFTER LOGON ON DATABASE
DECLARE
    v_hour NUMBER;
BEGIN
    v_hour := TO_NUMBER(TO_CHAR(SYSDATE, 'HH24'));
    IF v_hour < 6 OR v_hour > 22 THEN
        IF SYS_CONTEXT('USERENV', 'SESSION_USER') NOT IN ('DBA', 'ADMIN') THEN
            RAISE_APPLICATION_ERROR(-20001, 'Login restricted during off-hours');
        END IF;
    END IF;
END;
/
```

### 7.2 DDL审计触发器

```sql
-- 记录所有DDL操作
CREATE OR REPLACE TRIGGER trg_ddl_audit
AFTER DDL ON DATABASE
DECLARE
    v_sql_list ORA_NAME_LIST_T;
    v_sql CLOB;
BEGIN
    -- 获取DDL语句
    SELECT sql_text INTO v_sql FROM v$sql
    WHERE sql_id = SYS_CONTEXT('USERENV', 'SQL_ID')
    AND ROWNUM = 1;
    
    INSERT INTO ddl_audit_log(
        event_time, username, event_type,
        object_owner, object_name, object_type,
        sql_text, ip_address
    ) VALUES (
        SYSDATE, SYS_CONTEXT('USERENV', 'SESSION_USER'),
        SYS_EVENT, SYS_DICT_OBJ_OWNER,
        SYS_DICT_OBJ_NAME, SYS_DICT_OBJ_TYPE,
        v_sql, SYS_CONTEXT('USERENV', 'IP_ADDRESS')
    );
EXCEPTION WHEN OTHERS THEN NULL;
END;
/
```

### 7.3 数据库启动/关闭触发器

```sql
-- 数据库启动后初始化
CREATE OR REPLACE TRIGGER trg_startup_init
AFTER STARTUP ON DATABASE
BEGIN
    -- 设置会话参数
    EXECUTE IMMEDIATE 'ALTER SYSTEM SET tracefile_identifier = ''STARTUP''';
    
    -- 记录启动时间
    INSERT INTO db_event_log(event_type, event_time, details)
    VALUES ('STARTUP', SYSDATE, 'Database started');
    COMMIT;
END;
/

-- 数据库关闭前清理
CREATE OR REPLACE TRIGGER trg_before_shutdown
BEFORE SHUTDOWN ON DATABASE
BEGIN
    INSERT INTO db_event_log(event_type, event_time, details)
    VALUES ('SHUTDOWN', SYSDATE, 'Database shutting down');
    COMMIT;
END;
/
```

### 8.1 查看系统触发器

```sql
-- 查看数据库级触发器
SELECT owner, trigger_name, trigger_type, triggering_event,
       base_object_type, status
FROM dba_triggers
WHERE base_object_type = 'DATABASE';

-- 查看SCHEMA级触发器
SELECT owner, trigger_name, trigger_type, triggering_event,
       table_name, status
FROM dba_triggers
WHERE base_object_type = 'SCHEMA' AND owner = 'HR';

-- 查看触发器源码
SELECT trigger_body FROM dba_triggers
WHERE trigger_name = 'TRG_LOGON_AUDIT' AND owner = 'SYS';
```

### 8.2 禁用和启用

```sql
-- 禁用数据库级触发器
ALTER TRIGGER trg_logon_audit DISABLE;

-- 启用
ALTER TRIGGER trg_logon_audit ENABLE;

-- 禁用所有系统触发器（维护时）
ALTER SYSTEM SET "_system_trig_enabled" = FALSE;
-- 恢复
ALTER SYSTEM SET "_system_trig_enabled" = TRUE;
```
