#YDBRD-31627 用户首次登录后支持强制修改口令功能

需求描述

     用户首次登录后支持强制修改口令功能，默认关闭

需求范围

      单机、分布式和集群

开发文档：  [(872) YDBRD-31627 用户首次登录后支持强制修改口令功能 | 知识管理 - PingCode](https://pingcode.yasdb.com/wiki/spaces/ZYK/pages/67c6b9292d2effe8fb20d6e3)  

# 1. 概述

 当用户第一次登录数据库时，必须需要修改口令

# 2. 需求分析

## 2.1.1功能点分析

1. create user语法 password expire ，用于在创建用户时使用户密码失效，用户密码失效后，用户无法登录，需要重新设置密码方可登录。
1. 不指定password expire，默认关闭


## 2.1.1视图观测

1. dba_users.account_status查看当前用户状态，密码过期会显示expired，重设密码后登录会显示open




## 2.2 应用场景

1. *create user设置密码过期，首次登陆强制修改密码*

# 3. 详细测试设计

## 3.1 测试设计方法

1. create user指定password expire，验证使用conn 用户/密码首次登录强制修改
1. create user指定password expire与其他语法account、profile 、tablespace混合使用，验证密码修改功能
1. create user指定password expire与alter user password expire同时使用
1. 连接登录方式验证命令行yasql、yasboot sql、SQL客户端conn、ystream连接
1. create user不指定password expire，使用alter user password expire修改
