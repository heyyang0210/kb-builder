## 1.1 审计清理高级包内容

审计清理高级包   DBMS_AUDIT_MGMT，该高级包为内置高级包，在数据库创建时自动创建。

  


（1）设置时间清理点

         PROCEDURE   SET_LAST_ARCHIVE_TIMESTAMP

（2）清理数据，根据指定方式，删除全部数据或时间清理点之前的数据

        PROCEDURE    PROCEDURE  CLEAN_AUDIT_TRAIL

（3）创建清理定时任务, 内部调用了DBMS_SCHEDULER.CREATE_JOB

```
PROCEDURE CREATE_PURGE_JOB(

    audit_trail_type IN INTEGER,

    audit_trail_start_time IN timestamp,

    audit_trail_purge_interval IN varchar,

    audit_trail_purge_name IN VARCHAR,

    use_last_arch_timestamp IN BOOLEAN := TRUE);
```

（4）设置清理定时任务状态， 包括enable, disable

```
PROCEDURE set_purge_job_status(

   audit_trail_purge_name IN VARCHAR, 

  audit_trail_status_value IN INTEGER);
```

（5）设置清理定时任务状态下次执行时间

修改的是定时任务的时间间隔

```
PROCEDURE set_purge_job_interval(

   audit_trail_purge_name IN VARCHAR,

   audit_trail_interval_value IN varchar);
```

  


（6）定时更新审计清理时间点

审计清理高级包中未提供该功能处理，用户需要使用定时任务进行处理。

  


（7）删除审计清理定时任务

本质是定时任务的删除

```
PROCEDURE drop_purge_job (audit_trail_purge_name IN VARCHAR);
```

  


（8）清空审计清理时间点

对系统表SYS.DAM_LAST_ARCH_TS$ 清空

```
PROCEDURE clear_last_archive_timestamp( audit_trail_type IN PLS_INTEGER);
```

  


（9）获取审计清理点时间

```
FUNCTION get_last_archive_timestamp(audit_trail_type IN PLS_INTEGER)

RETURN TIMESTAMP;
```

  


## 1.2 结论

 从上面可以看出，审计清理高级包   DBMS_AUDIT_MGMT 包含了：存储过程、函数、定时任务，没有专门的针对DBMS_AUDIT_MGMT的相关缓存，在集群支持高级包、函数、存储过程、定时任务job后即可正常使用审计清理高级包。
