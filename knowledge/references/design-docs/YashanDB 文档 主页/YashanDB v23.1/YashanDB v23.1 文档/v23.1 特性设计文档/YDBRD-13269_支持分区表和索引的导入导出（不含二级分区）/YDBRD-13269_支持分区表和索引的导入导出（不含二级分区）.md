#### 索引信息：

REVERSE  PCTFREE int INITRANS int MAXTRANS int TABLESPACE  name LOCAL  -- user_part_indexes中查询

#### 分区信息：

（PARTITION name PCTFREE int INITRANS int MAXTRANS int TABLESPACE "USERS" --user_ind_partitions查询

#### 分区名字：

系统生成和用户自定义均进行导出。

oralce：

CREATE INDEX "HASHTABLE_INDEX2" ON "HASHTABLE2" ("A" ) PCTFREE 10 INITRANS 2 MAXTRANS 255 TABLESPACE "SYSTEM" LOCAL(PARTITION "SYS_P3264" TABLESPACE "USERS" , PARTITION "SYS_P3265" TABLESPACE "USERS" )

#### interval分区说明

interval分区，自动扩展部分，表分区属性不导出，后续支持表空间迁移，再做改动。改动方式：自动扩展的分区存储形式：FLAG+自动扩展分区属性；导入时，如果是表空间迁移使用，则将信息附加到DDL上，其他模式忽略此信息。

interval分区，index的分区名字进行导出，不区分是否系统生成的分区名字

#### store in属性

（1）只能指定一个 STORE IN 或 <partition-description> 子句。

（2）只能针对表的hash分区。其他类型不能导出。

（3）store in或者 <partition-description>属性，全部以 <partition-description>形式导出。

（4）hash分区类型对应的local索引，索引分区的  **不导出表空间属性**

```
建表语句：
--store in 属性
drop table hashTable1;
create table hashTable1(a int, b int) partition by hash(a) partitions 2 store in (system,users);
create index hashTable_index on hashTable1(a) tablespace system local store in(users,system);
--导出格式：CREATE INDEX "HASHTABLE_INDEX2" ON "HASHTABLE2" ("A" )  PCTFREE 10 INITRANS 2 MAXTRANS 255 TABLESPACE "SYSTEM"  LOCAL(PARTITION "SYS_P3268" TABLESPACE "USERS" , PARTITION "SYS_P3269" TABLESPACE "USERS"  )
--partition-description属性
drop table hashTable2;
create table hashTable2(a int, b int) partition by hash(a) partitions 2 store in (system,users);
create index hashTable_index2 on hashTable2(a) tablespace system local (PARTITION TABLESPACE users, PARTITION tablespace users);
--导出格式：CREATE INDEX "HASHTABLE_INDEX" ON "HASHTABLE1" ("A" )  PCTFREE 10 INITRANS 2 MAXTRANS 255 TABLESPACE "SYSTEM"  LOCAL(PARTITION "SYS_P3266" TABLESPACE "USERS" , PARTITION "SYS_P3267" TABLESPACE "SYSTEM"  )
```

#### unusable

默认是usable（valid），USER_INDEXES->status

N/A --分区索引，在分区属性中单独指定。 USER_IND_PARTITIONS->STATUS属性

VALID --不导出此属性

UNUSABLE --导出属性，此时为非分区索引。

oracle：ALTER INDEX "UNUSABLE_INDEX" MODIFY PARTITION "P1" UNUSABLE

#### visible

DBA_INDEXES→VISIBILITY默认是visible，invisible则增加属性
