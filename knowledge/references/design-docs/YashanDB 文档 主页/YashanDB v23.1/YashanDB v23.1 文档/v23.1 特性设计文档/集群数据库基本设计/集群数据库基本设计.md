##   [1. Overview（概述）](#1-overview概述)  

数据库服务由实例和数据库组成，数据库一般指控制文件，数据文件，重做文件等数据库文件的集合。实例指运行数据库的进程、线程、内存等资源组成。集群由若干个数据库实例、一份数据库文件组成。

##   [2. Features（功能特性）](#2-features功能特性)  

集群形态下数据库文件被多个实例共享访问，但是依然存在某些文件是实例独自拥有。比如UNDO表空间的文件、REDO文件等。集群数据库文件因为需要被多个实例访问，因此这些文件放置于（YFS）共享文件系统上。

##   [3. Interfaces（接口）](#3-interfaces接口)  

集群数据库创建语法

```
create cluster database database_name [instances n][instance(logfile_clause | undo_tablespace_clause)]

```

创建集群数据库语法示例

```
create cluster database test instances 2; // 创建2实例数据库，数据库文件均为默认属性

create cluster database abc
system tablespace datafile 'system' size 64M
sysaux tablespace datafile 'sysaux' size 64M
default tablespace datafile 'users' size 64M
temporary tablespace tempfile 'temp' size 64M
swap tablespace tempfile 'swap' size 64M
instance(
logfile('logfile11' size 32M, 'logfile12' size 32M, 'logfile13' size 32M)
undo tablespace datafile 'undo1' size 64M
)
instance (
logfile('logfile21' size 32M, 'logfile22' size 32M, 'logfile23' size 32M)
undo tablespace datafile 'undo2' size 64M
);                              // 创建2实例数据库，自定义数据库文件

```

**创建集群数据库需要设置配置参数CLUSTER_DATABASE=TRUE**

##   [4. Specification And Constraints（规格与约束）](#4-specification-and-constraints规格与约束)  

1. 目前只支持4节点集群
1. instances关键字不能与instance关键字同时指定。
1. instances指定的值或者instance指定的列表个数不能大于maxInstances指定的值
1. 配置参数cluster_database和默认ctrl路径需要匹配，单机模式不允许路径在YFS上，集群模式不允许路径在本地磁盘上
1. 建库语句通过cluster关键字指定是否为集群数据库，集群模式必须创建集群数据库，单机模式不能创建集群数据库
1. 集群数据库文件必须指定为YFS路径，单机数据库文件必须指定为本地文件系统路径

```
    ...

typedef struct StXactManager {
    XactArea        area[ANK_MAX_INSTANCES]; // 事务区修改为数组，支持最大实例数的事务区管理
    ...
} XactManager;

typedef struct StInstanceCtrl {
    CodUint16       id; // 增加id字段
} InstanceCtrl;

```
