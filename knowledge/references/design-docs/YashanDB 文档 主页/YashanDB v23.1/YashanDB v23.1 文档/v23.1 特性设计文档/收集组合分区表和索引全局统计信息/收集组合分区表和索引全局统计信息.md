#   [收集组合分区表和索引全局统计信息](#收集组合分区表和索引全局统计信息)  

##   [1. Overview（概述）](#1-overview概述)  

支持单机和分布式下收集组合分区表和索引全局统计信息。    [https://jira.yasdb.com/browse/YDBRD-20764](https://jira.yasdb.com/browse/YDBRD-20764)  

##   [2. Features（功能特性）](#2-features功能特性)  

单机接口：

DBMS_STATS.GATHER_TABLE_STATS，收集组合分区表，支持收集全局(即表)级别，暂不支持收集指定的分区/子分区

DBMS_STATS.GATHER_INDEX_STATS，收集组合分区local索引，支持收集全局(即索引)级别，暂不支持收集指定的分区/子分区

DBMS_STATS.GATHER_SCHEMA_STATS，收集某个schema下所有表的统计信息

DBMS_STATS.GATHER_DATABASE_STATS，收集整个库下所有表的统计信息

分布式接口：

ANALYZE TABLE

##   [6. Testcases（自测用例）](#6-testcases自测用例)  

```
create table test(c1 int, c2 varchar(10))
partition by range(c1)
subpartition by list(c2)
(partition p1 values less than(10)(subpartition sub1 values('a', 'b')),
 partition p2 values less than(20)(subpartition sub2 values('a', 'c')));

create index test_idx on test(c1) local;

-- 分布式下要建分布表和复制表测试一下，在CN下analyze
create duplicated table test(c1 int, c2 varchar(10))
partition by range(c1)
subpartition by list(c2)
(partition p1 values less than(10)(subpartition sub1 values('a', 'b')),
 partition p2 values less than(20)(subpartition sub2 values('a', 'c')));

-- 分布式暂不支持创建local index

insert into test values(1, 'a');
insert into test values(2, 'b');
insert into test values(10, 'a');
insert into test values(11, 'c');

exec dbms_stats.gather_table_stats(null, 'test', 'p1', 1); -- 报错
-- YAS-00004 feature "gather partition/subpartition statistics of composite partitioned table" has not been implemented yet
exec dbms_stats.gather_table_stats(null, 'test', 'sub1', 1); -- 报错
exec dbms_stats.gather_table_stats(null, 'test', null, 1); -- 成功
exec dbms_stats.gather_table_stats(null, 'test', null, 1, true, 'for all columns size auto', 1, 'partition'); -- 成功，但granularity无论填啥，都只有表级别的统计信息
exec dbms_stats.gather_index_stats(null, 'test_idx', null, 1); -- 成功
exec dbms_stats.gather_schema_stats(null, 1);
exec dbms_stats.gather_database_stats('GATHER');
-- analyze
analyze table test partition 'p1' estimate_percent 1 index_cascade true; -- 报错
analyze table test partition 'sub1' estimate_percent 1 index_cascade true; -- 报错
analyze table test estimate_percent 1 index_cascade true; -- 成功

select * from dba_tab_statistics where table_name=upper('test');
select * from dba_ind_statistics where index_name=upper('test_idx');

-- 动态采样
alter system set OPTIMIZER_DYNAMIC_SAMPLING=2;
select * from test where c1 &lt; 10;

```
