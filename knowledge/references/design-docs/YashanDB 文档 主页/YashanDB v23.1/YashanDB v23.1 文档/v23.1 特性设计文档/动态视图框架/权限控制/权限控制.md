# 设计概述

现有版本的动态视图是没有权限控制的，其所有权归属于SYS用户，为了让其他用户可见，通过内置硬编码的方式创建了动态视图的public同义词。

这种方式的局限性在于所有的用户都具备查询动态视图的权限，系统运行的关键信息，如sqlArea, sqlPlan等用户敏感的视图变得不再安全。当前设计主要解决在保证多用户视图可见性时，并提供对应的权限控制。

# 设计约束

- 仅针对需求涉及到的动态视图进行权限控制，SIT阶段会对所有的V$视图进行适配。
- DV$视图由于没有适配新的框架，暂时不考虑做权限控制，SIT阶段再评估。


# 方案设计

## 系统角色

在system_roles.sql中新增select_catalog_role角色。

```
CREATE ROLE SELECT_CATALOG_ROLE
/

GRANT SELECT_CATALOG_ROLE TO DBA
/
```

分布式不支持grant role to role语法，23.1暂不支持grant select_catalog_role to dba，且当前版本没做dba权限控制，因此默认dba有查询权限。

## 权限控制

通过创建v_$视图，并基于v_$视图创建对应的同义词。基于v_$视图做权限控制。

```
create or replace view v_$instance as select * from v$instance
/
create or replace public synonym v$instance for v_$instance
/
grant select on v_$instance to select_catalog_role
/

create or replace view gv_$instance as select * from gv$instance
/
create or replace public synonym gv$instance for gv_$instance
/
grant select on gv_$instance to select_catalog_role
/

create or replace view v_$fixed_table as select * from v$fixed_table
/
create or replace public synonym v$fixed_table for v_$fixed_table
/
grant select on v_$fixed_table to select_catalog_role
/

create or replace view gv_$fixed_table as select * from gv$fixed_table
/
create or replace public synonym gv$fixed_table for gv_$fixed_table
/
grant select on gv_$fixed_table to select_catalog_role
/

create or replace view v_$fixed_view_definition as select * from v$fixed_view_definition
/
create or replace public synonym v$fixed_view_definition for v_$fixed_view_definition
/
grant select on v_$fixed_view_definition to select_catalog_role
/

create or replace view gv_$fixed_view_definition as select * from gv$fixed_view_definition
/
create or replace public synonym gv$fixed_view_definition for gv_$fixed_view_definition
/
grant select on gv_$fixed_view_definition to select_catalog_role
/
```

通过创建v_$视图以及对应的同义词，普通用户查询的实际上是通过权限控制的v_$视图，其本质是个用户视图。

而SYS用户查询的是v$视图，其查询的是fixed view视图。

## 升级

由于历史版本都采用了旧的机制，在版本升级时会自动升级为新的动态视图框架，升级脚本会自动创建对应的系统角色以及同义词。

升级到23.1版本后再使用动态视图是带有权限控制的。
