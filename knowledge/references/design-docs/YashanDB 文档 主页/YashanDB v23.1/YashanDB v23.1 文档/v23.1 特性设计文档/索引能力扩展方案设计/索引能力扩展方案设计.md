#   [YDBRD-13993 : 索引能力扩展方案设计](#ydbrd-13993--索引能力扩展方案设计)  

SR链接：    [https://jira.yasdb.com/browse/YDBRD-13993](https://jira.yasdb.com/browse/YDBRD-13993)  

##   [1. Overview（概述）](#1-overview概述)  

本方案主要目的是扩展可使用索引的场景，提升查询性能。

##   [2. Features（功能特性）](#2-features功能特性)  

本方案主要包括两个子特性：

1. like param支持走索引的range scan
1. is null和is not null支持走索引range scan


##   [3. Interfaces（接口）](#3-interfaces接口)  

本方案无对外接口，只是扩展了支持使用index range scan的filter范围。

##   [4. Specification And Constraints（规格与约束）](#4-specification-and-constraints规格与约束)  

1. 原有like只支持like const，且const的第一个字符不为%或_，此特性合入后原支持情况不变，新增支持like ?，即like一个绑定参数。并且只能是单独的绑定参数，不能是绑定参数的运算。
1. is null和is not null支持所有支持index range scan的索引类型，包括reverse索引，函数索引，分区表的local索引；不支持的索引例如列式索引。


##   [5. Detail Design（详细设计）](#5-detail-design详细设计)  

1. RangeType新增两个类型RANGE_ISNULL和RANGE_ISNOTNULL 。


```
typedef enum EnRangeType {
    RANGE_EMPTY = 0,
    RANGE_POINT = 1,
    RANGE_LIST = 2,
    RANGE_SECTION = 3,
    RANGE_LIKE = 4,
    RANGE_ISNULL = 5,
    RANGE_ISNOTNULL = 6,
    RANGE_FULL = 7,
    RANGE_SKIP = 8,
} RangeType;

```

1. 提取filter生成rangeset过程中，对于FILTER_IS_NULL将生成一个RANGE_ISNULL的PlanRange；对于FILTER_IS_NOT_NULL将生成一个RANGE_ISNOTNULL的PlanRange；
1. PlanRange转RealRange过程中，RANGE_ISNULL生成的realrange的type也是RANGE_ISNULL，RANGE_ISNOTNULL生成的realrange的type也是RANGE_ISNOTNULL；在range的合并和排序中，RANGE_ISNULL大于任何range，而RANGE_ISNOTNULL则是左右都是无穷的区间。
1. 生成index scan key的过程中，RANGE_ISNULL设置左边界为MAX_VALUE，右边界为RIGHT_INFINITE；RANGE_ISNOTNULL走的是类似RANGE_SECTION的路径，左右边界分别为MIN_VALUE和MAX_VALUE。


##   [6. Testcases（自测用例）](#6-testcases自测用例)  

自测关注点：

1. like本表列，其他表列（index nl join），param，子查询会不会走rangescan
1. isnull和其他range的配合
1. reverse索引，函数索引，降序索引，分区表local索引
1. 有序性的利用，升序，降序
