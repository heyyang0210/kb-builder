#   [一.概述](#一概述)  

```
 * 单机创建表空间或向表空间添加数据文件时生成的数据文件都默认在YASDB_DATA下的dbfiles中，集群中数据文件需要存储在共享存储里，文件名称‘+DG0/dbfiles/***’，该需求对集群下创建数据文件进行适配，同时保证语法兼容和存储路径的正确性

```

#   [二.功能特性](#二功能特性)  

```
 保证集群下所有数据文件均存储在共享存储，不指定disk group时默认为DG0

```

#   [三.接口](#三接口)  

  `CREATE TABLESPACE SPC;`  

  `CREATE TABLESPACE SPC DATAFILE 'FILE' SIZE 100M;`  

  `ALTER TABLESPACE SPC ADD DATAFILE 'FILE_01' SIZE 100M;`  

  `ALTER TABLESPACE SPC ADD DATAFILE;`  

#   [四.功能限制](#四功能限制)  

- 数据文件名长度不能大于等于32个字符
- 创建数据文件时指定绝对路径进行报错
- 使用相对路径时将数据文件默认存储在+DG0/dbfiles
- 创建表空间或添加数据文件是不指定数据文件名称时，自动生成文件名为SPACENAME + FILE INTERID，存储在+DG0/dbfiles下
- 指定数据文件名为？或者.为起始字符时自动在该文件名前拼接YASDB_DATA路径并进行报错
- 指定数据文件名为YFS路径时直接进行创建，YFS会进行文件名合法性校验


#   [五.详细设计](#五详细设计)  

###   [数据文件名称适配步骤：](#数据文件名称适配步骤)  

- 1.根据原始文件名类型获取文件device name
- 2.如果原始文件名类型是FS，对原始文件名进行合法性校验，不指定名称时原始名为SPACENAME + FILE INTERID
- 3.通过合法性校验后将device name拼接为+DG0/dbfiles/origin_name
- 4.调用YFS创建数据文件接口,使用device name创建数据文件


#   [六.测试用例](#六测试用例)  

create tablespace spc;

create table space spc1 datafile 'file' size 100m;

alter tablespace spc1 add datafile 'file_01' size 100m;

alter tablespace spc1 add datafile;
