# 1. 概述

      分布式架构将数据和计算资源分布在不同节点，同时提供数据节点备份以提升系统的可靠性。在最大保护模式下当节点故障，可以做到数据零丢失。

常用判断指标：

**RPO**  （Recovery Point Objective）：恢复点指标，是指故障发生后，系统能把数据恢复到故障发生前的哪一个时间点的数据，指最多可能丢失的数据的时长。

**RTO**  （Recovery Time Objective）：系统恢复的时间（包含故障检测时间+故障倒换时间），指从故障到系统恢复正常时长。

RPO说明了备份的可靠性和完整性，RTO说明了恢复的可靠性与速度。

分布式在最大保护模式下规格：  **RPO=0， RTO < 30S**

# 2. 需求分析

数据库系统需要具有防错、容错和纠错的能力，对于数据库内部出现故障能够识别并恢复，同时不丢失数据；外部原因造成异常可预警并进行容错处理。

YashanDB-DP由以下主要组件组成：

|组件|描述|
|:---|:---|
|协调节点（CN）|CN负责对外提供接口，接收用户请求，生成分布式查询计划，向DN分发查询计划并汇总执行结果。|
|数据节点（DN）|DN负责存储数据，执行CN下发的查询计划。通过DN组提供高可用能力，组内节点具有主从关系，通过Raft协议实现节点间的数据一致性。|
|管理节点（MN）|MN负责集群的节点管理、元数据管理和分布式事务管理。MN组内节点具有主从关系，通过Raft协议实现节点间的一致性。|
|OM节点|OM服务对外提供集群运维管理的Web服务|
