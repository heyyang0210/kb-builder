# **一.**  ** **  **概述**

  [YDBRD-13449](https://jira.yasdb.com/browse/YDBRD-13449?src=confmacro)    **-**  **YFS支持客户端工具**  **完成**

YFS 不是常规文件系统，因此需要一组管理工具，实现对 YFS 基本的管理，如文件、目录的增删改查。

YFSCMD是参考 Oracle ASM 对应的工具 ASMCMD（  ASMCMD 是一个命令行实用程序，可用于管理 Oracle ASM 实例、磁盘组、磁盘组的文件访问控制、磁盘组内的文件和目录、磁盘组模板和卷  ）。

YFSCMD 提供 2 种操作模式

- 交互模式，自行实现一个简单的 Shell 环境；
- 非交互模式，直接调用 YFSCMD 中的工具（或指令）。


# **二.**  ** **  **需求分析**

YFSCMD 提供了丰富的特性，目前 YFS 处于开发初期，仅设计部分功能。     YFSCMD 实现基本的文件和目录管理功能。支持平台为Linux。

支持的指令如下：

- cd                            //用于切换目录
- cp                            // 复制文件，可在 ext4 和 yfs 之间交叉复制
- du                            //显示磁盘空间的使用情况
- help                         //用于显示YFSCMD的所有命令     
- ls                             //显示目录下的内容
- ls -l                         //  查看文件属性
- mkdir                      //创建asm目录，当前支持的目录层级深度最大为10层
- mv                          // 移动或重命名对象
- rm     -r -f                     //   递归删除目录、强制删除等，之前 rm 删除对象没有确认流程，升级后默认需用户确认才删除        
- pwd                        //显示当前目录的路径
- rm                          //删除目录或文件，如果是别名，会删除别名和别名所对应的文件 /只能删除空目录/
- touch                    // 创建空白文件
- vim                       // 编辑文件
- cat                        // 读取文件到标准输出，可通过管道重定向到其他工具
- md5sum              // 校验文件


其他规格限制：

>  目前支持的文件类型为文件和目录  ，文件大小上限为1G。

>文件/目录命名规则：名称除了"空格"和"Tab键"都支持；全路径以"+"开头（  加号 (+) 表示根目录  ）；长度小于等于31字节。

>  命令行最多接受 4095 个字符，超出部分截断。

>  yfscmd 递归删除和复制的最大深度由系统栈大小决定，考虑到 yfs 的目录深度上限为 10，yfscmd 的递归命令深度通常是足够的。

>  yfscmd 不限制文件名长度，但请遵守 yfs 自身的规格：文件、目录名称最长 31 字节。

>  yfscmd 支持任何除空格和 tab 外的字符作为参数，但这可能不符合 yfs 的要求，所以请使用数字、字符、下划线作为参数（如文件名），使用其他字符的行为未定义。

>  yfscmd 通过空白字符分割参数，不支持通过引号分割参数，引号会被识别为参数的一部分，如同字母、数字一样。

# **四.**  ** **  **详细测试设计**

## 启动参数

-D YFS_HOME_PATH 指定 YFS home 路径，必须与 yfssrv 的 -D 或者 ycs -H 参数一致。-d: yfscmd 是否显示当前路径。-H: 显示帮助信息，可以看到详细的参数说明-V: 显示版本号- *-L LOG_LEVEL: 打印 yfscmd 内部日志，保存在 -D 参数指定目录下 yfscmd.log


## 操作模式

- **交互模式**


yfscmd -D $PWD    //当前目录进入交互模式，如下：

[wtd@AchorBase node2]$ yfscmd -D $PWD    
  YAS File System CMD v0.1    
  try help or ?.

YFSCMD >

yfscmd -D $PWD -p   //  使用-p选项，将在YFSCMD提示符中包含当前路径，如下：

[wtd@AchorBase node0]$ yfscmd -D $PWD -p    
  YAS File System CMD v0.1    
  try help or ?.

YFSCMD [+] >

- **非交互模式**


yfscmd -D $PWD 【cmd】  //当前目录下非交互模式，如下：

[wtd@AchorBase node0]$ yfscmd -D $PWD ls    


DG0    
  arch_files    
  yfscmd_dir_mvdir_001

## 指令

所有路径参数都可以是：

- 绝对路径
- 或相对路径


但相对路径默认为 YFS 路径，如需指定操作系统文件路径，请使用 '/' 为第一个字符的绝对路径。

注意，文件对象指 YFS 支持的任何文件类型：

- 普通文件
- 目录

### 2 cp

复制文件。    
  **语法**

|1|  `cp`         `src_file tgt_file`  |
|:---|:---|


|Option|Description|
|:---|:---|
|src_file|源文件名|
|tgt_file|目标位置|


复制文件时，不允许覆盖已有文件对象（不得重名）。

所有相对路径一律被转换为 YFS 路径，操作系统文件路径仅支持绝对路径。

src_file、  tgt_file 至少 1 个为   YFS 对象，允许的复制方向：

- YFS → 操作系统；
- YFS → YFS;
- 操作系统 → YFS;


  
  **实例**

|1    
  2    
  3    
  4    
  5    
  6|  `YFSCMD > `      `cp`         `+data`      `/yas_db/datafile/EXAMPLE`         `/yas_backups/example`      `.bak`      
    `copying +data`      `/yas_db/datafile/EXAMPLE`         `--> `      `/yas_backups/example`      `.bak`      
    `YFSCMD > `      `cp`         `/yas_backups/example`      `.bak  +data`      `/yas_db/datafile/EXAMPLE`      
    `copying `      `/yas_backups/example`      `.bak  --> +data`      `/yas_db/datafile/EXAMPLE`      
    `YFSCMD > `      `cp`         `+data`      `/yas_db/datafile/EXAMPLE`         `+data`      `/yas_db/datafile/EXAMPLE2`      
    `copying +data`      `/yas_db/datafile/EXAMPLE`         `--> +data`      `/yas_db/datafile/EXAMPLE2`  |
|:---|:---|
