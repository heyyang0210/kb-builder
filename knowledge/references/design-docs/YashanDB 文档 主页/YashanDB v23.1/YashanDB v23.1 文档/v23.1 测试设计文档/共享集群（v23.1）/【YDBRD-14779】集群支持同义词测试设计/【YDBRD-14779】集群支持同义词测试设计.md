# 2. 需求分析

sr:       [YDBRD-14779](https://jira.yasdb.com/browse/YDBRD-14779)  

设计文档：    [复制从 Oracle 同义词 详解](https://conf.yasdb.com/pages/viewpage.action?pageId=115147420)  

- 集群支持为  表、视图、sequence、（暂不支持存储过程、自定义函数、物化视图）以及其他同义词等对象创建同义词
- 集群支持指定同义词所有者为public用户
- 创建同义词后可在如下系统表和视图中查到对应记录
