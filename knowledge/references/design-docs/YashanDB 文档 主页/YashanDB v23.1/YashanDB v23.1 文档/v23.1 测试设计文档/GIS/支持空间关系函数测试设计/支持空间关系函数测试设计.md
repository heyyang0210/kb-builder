2.1 函数功能

线的边界是两端点，闭合的线无边界。多边形的边界，是多边形的边框线。线是除边界点外的就是内点，多边形的是区域内的是内点，多多面形的内点是A多边形的内点+B多边形的内点-A与B的交集的内点。以ST_Contains为例：

    一、  ST_Contains：  当且仅当B中没有点位于A的外部，且B中至少有一个点位于A的内部时，A包含B，返回TRUE。

      B不能全是A的边界点，全是边界点，就返回FALSE，比如B点是A线的边界。（除外：是边界，是边界交点）。仅  含empty，无论跟谁比较，即使是自身，返回是false。

      点-》点

    （1）A是单点，B是单点，B要是跟A误差范围内的点，才返回TRUE;

      线-》点

    （2）A是线，B是单点，B是A的边界点--FALSE，线上的某个点（但是线里未明确写出），返回值  ？？？待确认，  线若是闭合的，无边界点。

             select ST_Contains(st_geomfromtext('LINESTRING(3 5, 4 6 ,4 5 )'), st_geomfromtext('POINT(4 5.5)'));  --TRUE    
               select ST_Contains(st_geomfromtext('LINESTRING ZM (-1 0.789 4 10,100 101.789 5 10)'), st_geomfromtext('POINT ZM (2 3.789 4 10)'));  --FALSE

             select ST_Contains(st_geomfromtext('LINESTRING(0 0 ,0 5, 5 5, 0 5 , 0 0 )'), st_geomfromtext('POINT(0 0)'));   --TRUE，闭合后是区域

             select ST_Contains(st_geomfromtext('LINESTRING(0 0 ,0 5, 0 0 )'), st_geomfromtext('POINT(0 0)'));  --TRUE，闭合后是线

      线-》多点

    （3）A是线，B是多点，B仅含起始点，返回FALSE，起始点+中间点（线里面明确写出或不明确写出）返回TRUE;

             select ST_Contains(st_geomfromtext('LINESTRING(3 5, 4 6 ,4 5 )'), st_geomfromtext('MULTIPOINT((3 5),(  4 5.5  ))'));

      线-》线

    （4）A是线，B是线的一部分或者等于A，返回TRUE。

      多线-》点

    （5）A是多线且不相交，B是点，B是线里面的任一起始点，都是返回FALSE。多线且相交，B是交点。

             select ST_Contains(st_geomfromtext('MULTILINESTRING((0 0, 2 0), (2 0, 2 2))'), st_geomfromtext('POINT(2 0 )'));   --TRUE,边界交点。

             select ST_Contains(st_geomfromtext('MULTILINESTRING((0 0, 2 1), (2 0, 2 2))'), st_geomfromtext('POINT(2 1 )'));   --FALSE,边界与内部的交点。

      多边形-》点（点是边界上的点、点是内点、点是多边形外部的点、特殊的empty）

      多边形-》多点（全是边界上的点、边界点+内点、全是内点、边界点+外部点、内点+外部点、特殊的empty）

      多边形-》线（边界上的线、内部的线、外部的线、边界线+内部的线、边界线+外部线、与多边形相交的线--交点2个，交点1个（1个交点的时候，点区分是线的边界点合不是线的边界点）

      多边形-》多线（多条线都含多边形的内点、仅其中1条线含其中的内点、多条线均不含多边形的内点）

      多边形-》多边形（包含、独立、相交：有内点的相关和无内点的相交--边界相交）

      多边形A-》多多边形B（A包含B、A与B中的均存在相交部分、A与B中的一个存在相交部分、A与B的均不存在相交部分，各自独立、A与B中的相切）

      多多边形-》点（点是内点、点是多多边形相交部分内部的点、点是多多边形外部的点、点是多多边形边界上的点）

      多多边形-》多点（内点  边界点  外部点（多边形外部、2个多边形相交的部分））

      多多边形-》线（多边形-》线的基础上 + 线在相交部分的内部）

      多多边形-》多线

      多多边形-》多边形

      。。。等其他组合情况。

     二、ST_Within是ST_Contains的逆。

     三、ST_Covers：如果几何B中没有点在几何A之外，则返回true。等效地，测试几何B的每个点是否都在几何A内部(即与几何A的内部或边界相交)。（  备注  ：跟postgis调用的结口不一样，有些数据我们会报错，pg不报错，有些pg会报错，我们不报错）

            等价于ST_Contains + 含边界

    四、ST_CoveredBy是ST_Covers的逆。

      备注：一、二、三、四可以公用一份数据。

    五、ST_Crosses：测试两个几何图形是否有一些(而不是全部)相同的内点。

           点与点、多点与点、其他类型与点永远是false；线与与线（两条线可以有公共的部分）、  多点与多点（可以部分公共点）  。

             任意empty间是false。

           select ST_Crosses(st_geomfromtext('MULTIPOINT ZM ((0 0 0 0), (3 0 0 0))'), st_geomfromtext('MULTIPOINT ZM ((0 0 0 0), (2 0 0 0))')); --多点与多点 

           线的内点：线上除边界点以外的点，即使是线构造的面，内点还是线上的所有点，不是面内的点。

           POLYGON的内点：比如两个面相交，最终的内点=A的内点 +B的内点-相交的内点。（线上的点，包括2个面相交的点，都不是内点）。

           MULTIPOLYGON跟POLYGON同理。

    六、ST_Equals：两个几何图形是否包含同一组点且几何结构相同（子类型一致，点与点，多点与多点等），点的顺序可以不同，  特殊的是empty都是相等的，比如POLYGON EMPTY与MULTIPOINT EMPTY，含empty但还含元素的进行比较，其他元素一致就相等。

--备注：子类型可以不一致，比如线跟多线等，只要后面的几何结构一样，是可以相等的。

   七、ST_Intersects：测试两个几何图形是否相交(它们至少有一个共同点)，相交则返回true，任意类型的empty是不相交的。

            select ST_Intersects(st_geomfromtext('MULTIPOINT EMPTY'), st_geomfromtext('POLYGON EMPTY'))； --false

          select ST_Intersects(st_geomfromtext('POLYGON EMPTY'), st_geomfromtext('POLYGON EMPTY'));   --false

          select ST_Intersects(st_geomfromtext('LINESTRING(1 0 9, 2 0 10, 3 0 11, 4 0 12)'), st_geomfromtext('LINESTRING(1 0 9, 2 0 10, 3 0 11, 3.5 0 12)'))；  --true,完全包含    


   八、ST_Disjoint：测试两个几何图形是否不相交(它们没有共同点), 如果不相交则返回true， 否则返回false。ST_Disjoint是ST_Intersects逆。

            select ST_Disjoint(st_geomfromtext('MULTIPOINT EMPTY'), st_geomfromtext('POLYGON EMPTY'))； --true

          select ST_Disjoint(st_geomfromtext('POLYGON EMPTY'), st_geomfromtext('POLYGON EMPTY'));   --true

   九、ST_Overlaps：测试两个几何图形是否相交  并具有相同的维度（点是0维、线1维、面2维）  且二者之间不完全包含。不等价于ST_Intersects-完全包含。（之前理解有误，未考虑到维度）

          select ST_Overlaps(st_geomfromtext('LINESTRING(1 0 9, 2 0 10, 3 0 11, 4 0 12)'), st_geomfromtext('LINESTRING(1 0 9, 2 0 10, 3 0 11, 4 0 12)'));   --false    


              select ST_Overlaps(st_geomfromtext('LINESTRING(1 0 9, 2 0 10, 3 0 11)'), st_geomfromtext('LINESTRING(1 0 9, 2 0 10, 3 0 11, 3.5 0 12)'))；     --false,算完全包含，其中一个完全是另外一个的一部分    


备注：七、八、九可以公用一份数据。

   十、ST_Touches：测试两个几何图形是否至少有一个共同点，但它们的内部不相交。如果geomA和geomB相交，但它们的内部不相交，则返回TRUE。同样地，A和B至少有一个共同点，并且这些共同点位于至少一个边界上。对于点/点输入，关系总是FALSE，因为点没有边界  ---这个公共点，是其中一个的边界点就可以，不是边界的相交，跟ST_Intersects相交（边界+内点）

# 3.   **测试设计方法**

等价类，边界值，场景分析。

入参为geometry类型。可以通过输入函数（st_geomFromText、st_geomFromWKB、st_geomFromEWKB、  ST_GeomFromGeoJson  ）传入,也可以是表中geometry类型的列。

- 支持2 （X  Y），3 (X Y Z)，4 (X Y Z M)维坐标的输入，此sr函数ZM不参与比较，仅比较X Y的关系。。
- 构造的数据误差范围：  小数点后面15位，  15位内没有差异，16位A比B多或者少，验证数据的关系（会识别差异）。
- srid：  使用常用的4326、4610、  4490、4214等。（    [SRID WKID 空间参考简介_srid和wkid_bigbigtree911的博客-CSDN博客](https://blog.csdn.net/bigbigtreewhu/article/details/52162277?ops_request_misc=%257B%2522request%255Fid%2522%253A%2522168197695316800188553300%2522%252C%2522scm%2522%253A%252220140713.130102334..%2522%257D&request_id=168197695316800188553300&biz_id=0&utm_medium=distribute.pc_search_result.none-task-blog-2~all~sobaiduend~default-1-52162277-null-null.142^v85^insert_down1,239^v2^insert_chatgpt&utm_term=%E5%B8%B8%E7%94%A8%E7%9A%84srid&spm=1018.2226.3001.4187)    ），数据在同一srid，不同srid作为容错。
- 第一个入参和第二个入参是目前支持的7个子类型中的一个，组合后是49种。（其中某一个函数对某种组合的处理永远是false等，简单覆盖，其他支持的组合，还可以根据实际，重点测试常用的组合）。
- 超长文本入参（geom）空间关系比较（某个数据存在允许的误差）
- null和空串，含empty
- nan inf -inf


因仍是函数，测试点仍可参考内置函数的通用测试点，主要在于是否构造针对函数的数据进行测试，会根据函数特点构造一部分数据，同时会复用postgis的数据（缺点：不确定数据具体测试到的是那种空间关系，结果跟pg比对），与已提供的其他gis相关函数结合测试。

备注：数据主要入表，通过查询2个表，进行数据的比对。
