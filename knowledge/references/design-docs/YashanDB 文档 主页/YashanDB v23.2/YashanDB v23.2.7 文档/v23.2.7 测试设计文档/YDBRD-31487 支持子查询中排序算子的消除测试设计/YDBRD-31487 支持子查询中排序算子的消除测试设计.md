# 1. 概述

from子查询 order by 优化的测试设计

# 2. 需求分析

## 2.1 功能点分析

 count(*) from子查询内带有order by场景下，查询慢。该需求实现 from子查询内的order by 优化

- 父查询包含汇聚算子，from子查询内的order by 可消除
- 父查询投影列全为常量，from子查询内的order by 可消除


  


## 2.2 应用场景

对from子查询内 order by进行优化

**支持的部署形态**  ：单机，分布式，集群  

## 2.3 规格约束

- 父查询/子查询中出现 rownum、 limt 、offset 、窗口函数时，from子查询的order by 不可消除
- 父查询的投影列为 汇聚函数或全常量时，from子查询的 order by 可消除
- 父查询的投影列包含 汇聚函数和正常列时，from子查询的 order by 可消除
- from子查询内 join，  子查询的 order by可消除
