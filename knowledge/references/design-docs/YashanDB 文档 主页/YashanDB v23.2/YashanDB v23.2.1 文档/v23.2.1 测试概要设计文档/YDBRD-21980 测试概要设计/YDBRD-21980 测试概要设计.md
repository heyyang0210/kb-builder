##   [2. 功能点](https://conf.yasdb.com/pages/viewpage.action?pageId=133568047#2-%E5%8A%9F%E8%83%BD%E7%82%B9)  

*从研发概要设计中获取，列出从IR层级对外可以感知的特性，对应提供的功能点、函数、语法图、配置参数、视图、接口等*

*结合调研文档，如有与友商实现的规格差异，要体现出来*

|命令|yasdb|oracle|差异点|
|---|---|---|---|
|set feedback|语法：  SET FEEDBACK { ON | OFF}|语法：  SET FEED[BACK] {6 | n | ON | OFF | ONLY} [SQL_ID]|（1）oracle支持数字设置，范围：[0,  50000]； 0代表关闭开关， 1至5000代表打开开关,（2）oracle支持only只显示返回行数,（3）oracle支持返回sql语句的sql_id， 并将sql_id赋值给预定义变量_sql_id|
|set heading|语法：  SET HEADING { ON | OFF}|语法：  SET HEA[DING] {ON | OFF}|无差异|
|show feedback/heading|show feedback/heading|show feedback/heading|无差异|

本次测试主要从以下方面考虑：

（1）基本功能：set feedback/heading on/off  和 show基本功能场景

（2）并发测试：因为是进程内生效，yasql退出后相关功能立即失效， 所以不涉及并发 

（3）可靠性测试：操作的过程中ctrl+c

（4）异常场景以及参数校验：主要考虑sql/plsql返回结果异常

（5）其它测试：不涉及

（1）功能测试, set feedback/heading 主要是对sql/plsql结果中的非数据部分进行处理，所以要考虑以下方面：

正常场景：

- sql/plsql类型：dql、dml、ddl、dcl等类型， 确保set feedback/heading处理结果正确； 跟sql语句复杂程度以及表类型无关
- 返回结果：


         1）set feedback 作用于  ‘Succeed.’  ‘PL/SQL Succeed.’ ‘ROW_NUM row/rows affected.’, 字符串和长度几乎是固定的， 唯一可变的是ROW_NUM，在构造数据时主要考虑ROW_NUM的变化

         2)  set heading 作用于表头， 表头可以由用户进行设置， 要考虑表头长度、内容、表头长度规格等

- set feedback/heading on/off完后， 使用show查看eedback/heading值
- 与其它特性交互：（1）yasql基本功能–sql执行方式 （2）yasql其它功能交互 （3）登录方式和连接方式 （4）客户端字符集编码


异常场景：

- sql/plsql语句返回异常结果


(2) 参数校验

- 有效参数：大小写、全称/简称等
- 无效参数：参数名称、值不正确等
