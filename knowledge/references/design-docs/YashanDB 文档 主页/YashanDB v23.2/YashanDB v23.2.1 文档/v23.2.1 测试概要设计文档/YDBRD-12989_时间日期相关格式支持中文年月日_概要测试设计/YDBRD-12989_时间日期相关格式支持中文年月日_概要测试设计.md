# YDBRD-12989 测试概要设计

IR链接：    [YDBRD-12989](https://jira.yasdb.com/browse/YDBRD-12989?src=confmacro)    -  时间日期相关格式支持中文年月日  完成

## 1. 需求概述

1、日期时间格式支持中文年月日：  'yyyy"年"mm"月"dd"日"'

2、部署形态：支持单机行表和集群行表，其他不支持

## 2. 功能点

1、在日期时间格式已经支持'yyyy-mm-dd'等格式基础上，新增支持中文年月日（  'yyyy"年"mm"月"dd"日"'）

2、范围：数据库（alter system set   date_format  ）,会话（  alter session set date_format  ），语句（to_char和to_date）

## 3. 规格约束

*从研发概要设计中获取*  **（暂无，未见开发的概要设计）**

## 4. 主要应用场景

新增的日期格式应用于日期格式输出，和当前已支持的范围、优先级等没有差异，范围包括数据库、会话和语句，优先级语句>会话>数据库

## 5. 概要测试设计

### 5.1 功能测试设计

主要考虑以下几个点：

1、部署形态：单机行表和集群行表，分布式和列表需要正确拦截报错

2、范围和优先级：数据库、会话和语句（to_char,to_date），每个需要单独设计测试用例，其中数据库和会话与data_format参数有关，用例可以共用。

3、格式字符串的使用方式遍历：

1）年月日中文本身的组合（包括出现的位置，出现次数）

2）年月日与其他格式符的组合（data format支持的格式符参考    [Yashan手册](https://cod-doc.yasdb.com/yashandb/23.1/zh/%E5%BC%80%E5%8F%91%E6%89%8B%E5%86%8C/SQL%E5%8F%82%E8%80%83%E6%89%8B%E5%86%8C/%E5%86%85%E7%BD%AE%E5%87%BD%E6%95%B0/TO_DATE.html)      [to_date函数](https://cod-doc.yasdb.com/yashandb/23.1/zh/%E5%BC%80%E5%8F%91%E6%89%8B%E5%86%8C/SQL%E5%8F%82%E8%80%83%E6%89%8B%E5%86%8C/%E5%86%85%E7%BD%AE%E5%87%BD%E6%95%B0/TO_DATE.html)    ），

最终按照设置结果可以分为有效和无效2大类，有效即是支持的格式串，设置成功，且能输出正确的格式化值（与格式化对应）；无效即是不支持的，设置不成功。

结果合理性判断规则：行为保持与未增加中文前一致，对之前规则有影响的场景，需要评估合理性，与oracle的对比作为参考。

4、涉及中文，需要关注与不同系统字符集编码、语言场景的关联关系
