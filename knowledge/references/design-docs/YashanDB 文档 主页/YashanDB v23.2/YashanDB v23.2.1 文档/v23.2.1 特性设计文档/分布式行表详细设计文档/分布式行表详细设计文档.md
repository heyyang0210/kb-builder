##   [2. 规格与约束](#2-规格与约束)  

###   [2.1 DDL功能约束](#21-ddl功能约束)  

|功能|补充说明|
|---|---|
|CREATE TABLE AS|不支持通过行表创建|
|CREATE AC|分布式不支持指定AC表空间，只支持复制表创建AC|
|MODIFY COLUMN|分布式不支持修改分布建类型|
|PARTITION TABLE|分布式一级分区只支持HASH分区，且不支持指定表空间创建分区表|
|OUTLINE / INLINE CONSTRAINT|分布式不支持外键， 唯一约束必须包含分布建|
|ADD/DROP/TRUNCATE TABLE PARTITION|增删分区以及清理分区数据只支持复制表|
|CREATE/REBUILD INDEX ONLINE|不支持|

##   [6.未来规划](#6未来规划)  

本方案只是针对分布式行表在当前版本最小粒度的支持，后续行表需要优先支持的需求基本此次需求开发。

1. create table as 功能实现
1. insert into select 支持
1. rowid/udt/bit 类型的支持
1. px 算子支持hash 分发
1. 内置函数：SCN_TO_TIMESTAMP/TIMESTAMP_TO_SCN的支持
1. planDataSet 的剥离其次的需求DML的约束中可见。
