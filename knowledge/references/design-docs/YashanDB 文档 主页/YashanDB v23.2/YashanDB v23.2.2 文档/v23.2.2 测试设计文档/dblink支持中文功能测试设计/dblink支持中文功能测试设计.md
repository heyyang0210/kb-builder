# 1. 概述

国信证券估值系统原来编码为GBK，库中大部分表有中文，周边系统是Oracle，需要通过DBlink访问估值系统（YashanDB）

# 2. 需求分析

## 2.1 功能点分析

- *ORACLE使用DBLINK连接崖山支持中文，包含查询*


## 2.2 应用场景

- Oracle创建dblink连接崖山单机数据库，可以正常增删改查包含中文的对象，中文显示正确


## 2.3 规格约束

- *支持UTF16编码，不支持UTF16范围外的字符*
