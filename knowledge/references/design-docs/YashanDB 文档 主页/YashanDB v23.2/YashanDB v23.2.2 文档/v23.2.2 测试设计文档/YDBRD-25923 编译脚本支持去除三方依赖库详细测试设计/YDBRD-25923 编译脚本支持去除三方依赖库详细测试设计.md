# 1. 概述

本文描述安装包去除第三方依赖库的测试设计，验证升级后不影响依赖包涉及的特性功能

如果升级前手动配置了第三方库（如gis，oracle的dblink驱动库），升级后会出现相关功能丢失

## 2.1 功能点分析

- 安装命令新增--deps，--plugin 参数，用于指定对应依赖包的地址
- 升级命令新增  ~~--deps，~~  --plugin 参数，用于指定对应依赖包的地址
- host add 命令新增--deps，--plugin 参数
- 安装包中去除依赖包，新增插件安装包yashandb-plugins-all-23.2.1.100-xx-linux-x86_64.tar.gz，新增额外依赖包yashandb-deps-23.2.1.100-xx-linux-x86_64.tar.gz
- 升级前启用gis、dblink，升级后gis、dblink功能正常
- 验证范围：单机、集群、分布式
- CI影响范围：部署后额外配置动态链接库，适配改动---工程组，升级


升级命令：yasboot package upgrade -t hosts.toml -p yashandb-23.2.1.100-linux-x86_64.tar.gz --deps yashandb-plugins-all-23.2.1.100-linux-x86_64.tar.gz

- 开发设计的主要原理


升级改造：

- 升级前检查：检查旧版本YASDB_HOME/lib目录下是否有第三方库（    [libyspi_geometry.so](http://libyspi_geometry.so)    和    [libdrv_oracle.so](http://libdrv_oracle.so)    ）存在
    - 如果存在列表中任意一项。
        - 检查是否有指定--deps参数，如果没指定，则直接报错。
    - 如果不存在列表任意一项。
        - 没有指定--deps参数，直接使用新的yashandb安装包升级，升级后没有第三方库；
        - 有指定--deps参数，自动在升级过程中将deps解压到新版本的lib目录下；


按照目录前的规划，deps包是包含上述列表所有的第三方库，plugins-all只包含了gis和oracle驱动库，升级命令是需要指定deps包的

**GIS何DBLINK使用**

GIS：

select ST_AsLatLonText(ST_GeomFromText('POINT (-3.2342342 -2.32498)')) from dual;

DBLINK：

create database link sr25923_link_orl_01 connect to system identified by 123456 using 'oracle:192.168.4.126:1521/orclcdb';    
  select count(*) from t1@sr25923_link_orl_01;

## 2.2 应用场景

- 升级后不影响gis、dblink功能


## 2.3 规格约束

- dblink：单机/集群支持、分布式不支持
- gis：单机支持
