**拓展分区的表现为：**

新数据存放在WRH$_SQLSTAT_3045944230_MXSN分区，当数据插入到到一定步长后，拓展出一个新分区存放原来的数据。

并且通过trace记录：

alter table WRM$_SNAPSHOT split partition WRM$_SNAPSHOT_1691321351_MXSN at (1691321351,7589) into (partition WRM$_SNAPSHOT_1691321351_7589, partition WRM$_SNAPSHOT_1691321351_MXSN tablespace SYSAUX) update indexes

因此确定：  **拓展分区的规则为，创建快照的存储过程里对于snap_id达到一定步长时，对WRH$_SQLSTAT_3045944230_MXSN分区划分为两个分区。步长和快照间隔时间、保存时间有关。**

**具体规则通过表现基本确定如下：**

（间隔时间，保存时间）=>分区步长

(60, ~) => 50; (120, ~) => 50;  (180, ~) => 50;

(40, 8) => 58; (40, 10) => 74; (41, 10) => 72; (40, 18) => 130; (40,15) => 110;  (40, 12) =>88; (40, 13) => 94; (40, 25) => 182; (40, 8*24*60+12*60)) => 62; (40, 7) =>52; 

(30, 8) => 78; (20, 8) => 116; (20,10) => 146; (10,8) => 232; (10, 2) => 58; (10, 1) => 50;

算法可推导为：大于(保存时间内的快照总份数 / 5 )的最小偶数，下限50
