#   [2. 需求分析](http://cod-conf.sics.com/pages/viewpage.action?pageId=59610608#2%E9%9C%80%E6%B1%82%E5%88%86%E6%9E%90)  

**2.1 功能点概述**

统计信息的导入导出是高级包DBMS_STATS的一个功能点，主要是为了方便将生产环境的统计信息导出然后导入到测试环境中，这样就不需要调用繁杂的    `SET_*_STATS`    函数或者导入生产端数据重新收集统计信息了。

统计信息的导入导出利用了一个暂存表staging table来存储导出的统计信息，然后通过exp/imp命令导入导出暂存表，最后导入暂存表的统计信息。流程如下：

![](https://pingcode.yasdb.com/atlas/files/public/67396d29a1ad9a3311dc8f26/origin-url?token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1aWRfZm9yX3B1YmljX2ltYWdlIjoiOTZjMTAxNTExNDIyNGNhNzhmOWM1YmZiZDYzY2QyNWIiLCJ0ZWFtX2Zvcl9wdWJsaWNfaW1hZ2UiOiI2NWQ2ZjRmZTZiM2U1NjI1MTZjZGU2YjciLCJibG9vbV9maWx0ZXIiOnsidHlwZSI6IkJsb29tRmlsdGVyIiwiX3NpemUiOjEwMjQsIl9uYkhhc2hlcyI6NSwiX2ZpbHRlciI6eyJzaXplIjoxMDI0LCJjb250ZW50IjoiQUFBQUFBQUFBUUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFFQUFBQUFBQUFBSUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUlBQUFBQUFBQUFBUUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBQUFBPSJ9LCJfc2VlZCI6NzgxODc0OTM1MjB9LCJpYXQiOjE3ODIzMDYzMTgsImV4cCI6MTc4MjMxNzExOH0.F_Q-7VJGHaz_aTzjEb6J337g2ocQFotgM1YC_OV8Cl0)

  


  


问题的需求是能在测试环境导入统计信息，方便测试cbo生成的执行计划，并且由于    `set_column_histogram`    在23.1版本中已经移除，需要有另一种方法也能设置直方图统计信息，于是提出了支持统计信息导入导出。统计信息导入导出列直方图相对于set_column_histogram来说更方便，更可控，防止用户设置非法的直方图。

  


## 2.    [2 接口](https://conf.yasdb.com/pages/viewpage.action?pageId=153002170#2-%E6%8E%A5%E5%8F%A3)  

|接口|接口表现|
|:---|:---|
|create_stat_table|创建统计信息表|
|drop_stat_table|删除统计信息表，非统计信息表drop不了|
|export_table_stats|导出表统计信息到统计信息表中|
|export_column_stats|导出列统计信息到统计信息表中|
|export_index_stats|导出索引统计信息到统计信息表中|
|export_schema_stats|导出schema下每张表统计信息到统计信息表中|
|import_table_stats|导入统计信息表中的表统计信息|
|import_column_stats|导入统计信息表中的列统计信息|
|import_index_stats|导入统计信息表中的索引统计信息|
|import_schema_stats|导入统计信息表中的schema下的每张表的统计信息|


  


2.3 规格约束

支持单机和共享集群。分布式部署下执行会报错。

与行列存无关。即行列都支持
