## 2.2 应用场景

本 SR 支持对称、非对称加解密函数

  


|函数|语法|规则|输入&输出|
|---|---|---|---|
|对称加密|select crypt_encrypt('abc', 'sm4', 'CBC', '12345678901234567890123456789012', '12345678901234567890123456789012') as xxxx from dual;,  
|第一个参数是明文，string类型,第二个参数是算法，仅支持SM4,第三个参数是模式，进支持CBC,第四个参数是密钥的HEX格式，长度32字符,第五个参数是IV（就是是初始化随机数）的HEX格式，长度是32个字符,  
,输出：hex|输入明文string类型的源数据,返回加密后的 hex数据。,  
,根据用户提供的算法、 key 和 iv，使用 SM4 对 string 数据进行加密|
|对称解密|select crypt_decrypt('6999FAA147DF311B3D90DF39307BCA1D', 'sm4', 'CBC', '12345678901234567890123456789012', '12345678901234567890123456789012') as xxxx from dual;|第一个参数是加密函数的输出，HEX格式。,第二个参数是算法，仅支持SM4,第三个参数是模式，进支持CBC,第四个参数是密钥的HEX格式，长度32字符,第五个参数是IV（就是是初始化随机数）的HEX格式，长度是32个字符,  
,输出：字符串。|输入加密后的 hex数据,返回解密后的string类型的源数据，与对称加密函数的输入一致,  
,根据用户提供的算法、 key 和 iv，使用 SM4 对 hex 数据进行解密|
|非对称加密|select crypt_asym_encrypt('abc', 'public...key...')|第一个参数是明文，string。,第二个参数是用于加密的公钥。,  
,输出：HEX格式的密文。,算法：SM2|输入明文string类型的源数据,返回加密后的 hex数据。,  
,根据用户提供的 key ，使用 SM2 对 string 数据进行加密|
|非对称解密|select crypt_asym_decrypt('abc', 'private...key...')|第一个参数是密文，总是HEX格式。,第二个参数是用于解密的私钥。,  
,输出：字符串。,算法：SM2|输入加密后的 hex数据,返回解密后的string类型的源数据，与非对称加密函数的输入一致,  
,根据用户提供的 key ，使用 SM2 对 hex 数据进行解密|
