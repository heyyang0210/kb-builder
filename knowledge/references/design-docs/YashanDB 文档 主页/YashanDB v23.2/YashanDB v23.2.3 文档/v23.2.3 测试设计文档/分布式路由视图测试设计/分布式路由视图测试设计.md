# 1. 概述

新增分布式路由视图，用于查询当前节点的路由信息，以便更好地运维YashanDB。

# 2. 需求分析

  [https://pingcode.yasdb.com/pjm/items/66174c0bfd997db58ad723de](https://pingcode.yasdb.com/pjm/items/66174c0bfd997db58ad723de)    ?    
  #YDBRD-26071 分布式支持路由视图

设计文档：    [分布式路由视图设计文档](150606480.html)  

## 2.1 功能点分析

分布式新增视图V$ROUTE, 目前只支持本地查询，无DV$视图。

- 视图实现方案


通过本地系统表ROUTE$实现视图内容查询：

SELECT DS_ID,CHUNK#,GROUP#,VERSION FROM ROUTE$;

  


- **V$ROUTE字段**


|字段|类型|说明|
|:---|:---|:---|
|DS_ID|BIGINT|表空间ID|
|CHUNK_ID|INTEGER|chunkID|
|GROUP_ID|BIGINT|chunk对应的组ID|
|VERSION|BIGINT|路由版本号|


## 2.2 应用场景

DN组扩缩容后，使用v$ROUTE查询路由信息, 显示每个CHUNK对应GROUP。

## 2.3 规格约束

- 目前只有本地视图，无DV$视图；
- CN、MN和DN查询结果相同；
- 只有分布式下查询出结果，单机和共享集群部署查询结果报错。
