##   [1. 总述](https://conf.yasdb.com/pages/viewpage.action?pageId=150625866&moved=true#1-%E6%80%BB%E8%BF%B0)  

用于生成更多的过滤条件，从而可能提前减少数据集。这里扩充的过滤条件是这2种：

1）is not null

2）cmp（链接列min和max的补充）

扩展之后的FilterNode属于 optional filter，  根据selectivity值判断是否使用该扩展条件。

filter相关的扩展：

```

CodResult   extOptFilterByFilterExpr(MemoryContext* mctx, Expr* expr, ObjectArray* isNotNullArray); 
//根据filterNode进行扩展
CodResult   extOptFilterByFilterNode(AnlStmt* stmt, MemoryContext* mctx, FilterNode* filterNode, ObjectArray** optFilters);
```

  


会话级参数：

OPT_FILTER_THRESHOLD，当扩展出来的谓词对应的selectivity< OPT_FILTER_THRESHOLD时，表明该谓词备选，OPT_FILTER_THRESHOLD默认值为0.3。

FILTER_EXTEND_MODE，MODE = NOTNULL时表示扩展NOTNULL谓词；MODE = IN时表示除了扩展NOTNULL以外，并扩展IN的minmax谓词。

语句参考：

```
select * from v$parameter where name like 'OPT_FILTER_THRESHOLD';
alter session set OPT_FILTER_THRESHOLD=0.3;

select * from v$parameter where name like 'FILTER_EXTEND_MODE';
alter session set FILTER_EXTEND_MODE=NOTNULL;
```

##   [3. 规格与约束](#id-谓词扩展设计方案-规格)  

1. 基于filterNode的扩展要求原filter仅包含以下类型：
    1.  表达式类型： EXPR_COLUMN/EXPR_QUERY/EXPR_ADD/EXPR_SUB/EXPR_MUL/EXPR_MOD/EXPR_DIV/EXPR_NEG/EXPR_EXPR_LIST/EXPR_REF/EXPR_FUNCTION    
  其中，EXPR_FUNCTION必须非空值敏感函数，且不可为AGGR类型的函数。具体可参考    [BIF_TRAIT_NULL_INS - 吴昊旻 - SICS-CoD Confluence (yasdb.com)](https://conf.yasdb.com/display/~wuhaomin/BIF_TRAIT_NULL_INS)     （e.g. where c1 = sum(c2) 无法推出c2 is not null; where c1 = nvl(c2, 1) 无法推出c2 is not null;)
    1. 数据类型： DTYPE_BOOL/DTYPE_TINYINT/DTYPE_SMALLINT/DTYPE_INTEGER/DTYPE_BIGINT/DTYPE_UTINYINT/DTYPE_USMALLINT/DTYPE_UINTEGER/DTYPE_UBIGINT/DTYPE_FLOAT/DTYPE_DOUBLE/DTYPE_NUMBER/DTYPE_DATE/DTYPE_SHORTDATE/DTYPE_SHORTTIME/DTYPE_TIMESTAMP/DTYPE_TIMESTAMP_TZ/DTYPE_TIMESTAMP_LTZ/DTYPE_YM_INTERVAL/DTYPE_DS_INTERVAL/DTYPE_CHAR/DTYPE_NCHAR/DTYPE_VARCHAR/DTYPE_NVARCHAR/DTYPE_UNKNOWN/DTYPE_RECORD
1. 基于filterNode扩展成min和max的场景仅支持col in const list; 例如col + 1 in (1,2,3)推不出1<= col + 1 < = 3; ExprRef in (1,2,3)也推不出 1<= ref <=3;
1. 当optional filter扩展上限为1024个，超过1024个不进行扩展。
1. 基于expr的扩展仅支持投影列仅存在简单聚合函数，且当前查询中不出现group by/window Func/limitoff set/connect by； 例如select sum(c1)+1 from t1无法推出c1 is not null; select sum(c1) from t1 group by c1 无法推出c1 is not null; 
1. 最终扩展出来的filter类型仅包含col is not null与subq is not null两种类型。

###   [4.2 根据FilterNode扩展](https://conf.yasdb.com/pages/viewpage.action?pageId=150625866&moved=true#41-%E7%89%B9%E6%80%A7%E8%AE%BE%E8%AE%A1)  

1. 基于FilterNode扩展的谓词可用于：
    1. outer转inner：is not null谓词具有空值拒绝作用，使outer join等价于inner join；例如 select * from t1 left join t2 on 1=1 where     [t2.id](http://t2.id)     in (1,2,3); 其中    [t2.id](http://t2.id)     in (1,2,3)可扩展出    [t2.id](http://t2.id)     is not null，对t2表有空值拒绝作用，则该语句等价于select * from t1 inner join t2 on 1=1 where     [t2.id](http://t2.id)     in (1,2,3);
    1. 生成选择率更低的谓词，combine到scanOp上。需要注意的是，expr cmp const选择率一定比expr is not null好，因此expr cmp const扩展出来的is not null永远不会combine到scanOp上；
1. filterNode扩展可扩出expr_column is not null 与 expr_query is not null。其中expr_query is not null用于生成子查询投影列中的col is not null，在当前op递归遍历子查询之后即删除该expr_query is not null。

|extFilterRLike,

|FILTER_IN|1. 单列：

###   [4.3 调整已有filter为optional filter](https://conf.yasdb.com/pages/viewpage.action?pageId=150625866&moved=true#41-%E7%89%B9%E6%80%A7%E8%AE%BE%E8%AE%A1)  

如果查询语句中，本身的自带的is not null已经被其他其他覆盖，则可以去掉。

```
select * from t1 where c1>6 and c1 is not null;
```

对于这条查询语句，等价于：

```
select * from t1 where c1>6;
```

  


###   [4.4 optional FilterNode的选择](https://conf.yasdb.com/pages/viewpage.action?pageId=150625866&moved=true#41-%E7%89%B9%E6%80%A7%E8%AE%BE%E8%AE%A1)

其中，

- 当filter选择率低于设定的系统阈值  OPT_FILTER_THRESHOLD时，该谓词备选；
- 若存在多个阈值内的备选谓词，仅选择选择率最优的，combine到scanOp上；
- in const list扩展出来的 min(list) <= expr and expr <= max(list)做为一个整体用来计算该谓词的选择率

  [4.6.1filterIn/filterAny的优化](#id-谓词扩展设计方案-test)
