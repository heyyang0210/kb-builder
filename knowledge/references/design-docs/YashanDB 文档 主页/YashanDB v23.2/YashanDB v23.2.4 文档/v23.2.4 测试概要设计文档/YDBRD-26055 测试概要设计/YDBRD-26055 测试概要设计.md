  #YASHAN-2858 分布式支持在PN组查询数据

##   [1. 需求概述](https://conf.yasdb.com/pages/viewpage.action?pageId=133568047#1-%E9%9C%80%E6%B1%82%E6%A6%82%E8%BF%B0)  

需求概述：  分布式支持alter user设置默认表空间集，DBA_USERS视图支持展示user的默认表空间集

需求来源：  产品化需求

部署形态：分布式

需求场景：  可以通过create user/alter user 指定用户的默认表空间集

##   [2. 功能点](https://conf.yasdb.com/pages/viewpage.action?pageId=133568047#2-%E5%8A%9F%E8%83%BD%E7%82%B9)  

- CREATE USER u DEFAULT TABLESPACE SET tss
- ALTER USER u DEFAULT TABLESPACE SET tss
- USER$ 系统表新增 DATATSS# 列 (INTEGER NULL)


涉及视图：  dba_user、v$tablespace,

tablespace_name

DBA_ACS
