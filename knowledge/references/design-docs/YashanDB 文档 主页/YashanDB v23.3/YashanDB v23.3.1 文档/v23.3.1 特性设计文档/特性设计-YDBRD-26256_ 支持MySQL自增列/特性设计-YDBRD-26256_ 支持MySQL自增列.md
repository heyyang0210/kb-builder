示例：mysql语法（自增列）

```
CREATE TABLE example (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50)
) AUTO_INCREMENT = 100;

```

对比：oracle语法（身份列 identity columns）

```
create table example (
    id INT GENERATED BY DEFAULT on null AS IDENTITY,
    name VARCHAR(50)
);
GENERATED ALWAYS AS IDENTITY: id总是自动生成的，insert指定id的值会报错；  
GENERATED BY DEFAULT AS IDENTITY: insert可以指定id的值，但是id的值不能为null；  
GENERATED BY DEFAULT ON NULL AS IDENTITY: insert可以指定id的值，id的值可以为null;  （auto_increment与此类型相对应，内置sequence，nextValue 用户不可查）
显式指定属性
create table example(
    id INT GENERATED BY DEFAULT on null AS IDENTITY(
    start with 1
    increment by 1
    maxvalue 65535
    nocycle),
    name VARCHAR(50)
);

```

  


alter table语句可以修改auto_increment的值。

##   [3. Interfaces（接口）](https://conf.yasdb.com/pages/viewpage.action?pageId=113972889#3-interfaces%E6%8E%A5%E5%8F%A3)  

新增系统表：IDNSEQ$    
  作用：记录identity列与sequence的对应关系（oracle也有同名系统表）    
  sequence信息查看SEQ$系统表

```
CREATE TABLE IDNSEQ$
(
    OBJ#                BINARY_BIGINT       NOT NULL,
    COL#                BINARY_INTEGER      NOT NULL,
    SEQOBJ#             BINARY_BIGINT       NOT NULL,
    STARTWITH           NUMBER              NOT NULL
) SYSTEM 92 ORGANIZATION HEAP
/
CREATE INDEX I_IDNSEQ1 ON IDNSEQ$(OBJ#, COL#)
/
CREATE INDEX I_IDNSEQ2 ON IDNSEQ$(SEQOBJ#)
/

```

OBJ# 为表的OBJ#    
  COL# 为列ID    
  SEQOBJ# 为sequence OBJ#    
  STARTWITH 默认为1

```
typedef struct StAnkColumn {
     ......
      union {
        CodUint32  flags;
        struct {
              ......
              CodUint32 defaultOnNull : 1;   //对应 DEFAULT ON NULL AS IDENTITY
              CodUint32 genAlways    : 1;   //对应 GENERATED ALWAYS 
              CodUint32 genByDefault : 1;   //对应 GENERATED BY DEFAULT 
              ......
        };
      };
      ......
} AnkColumn;

```

因此，autoIncrement就是：genByDefault + defaultOnNull =  GENERATED BY DEFAULT ON NULL AS IDENTITY

```
typedef struct StColumnDef {
      ......
      union {
          LangText   defaultText;
          SequenceDef* identityDef;   //identity定义
      };
      ......
      union {
        CodUint32  flags;
        struct {
              ......
              CodUint32 defaultOnNull : 1;
              CodUint32 generatedAlways : 1;
              CodUint32 generatedByDefault : 1;
              ......
        };
      };
      ......
} ColumnDef;

typedef struct StTableDef {
      ......
      ColumnDef*   idnColumn;  // 指针指向identity column，一个表上只有一个identity列。
      ......
} TableDef

新增函数：
myInitAutoColumnSeqDef  初始化自增列的sequence定义
myGetAutoColumnId   获取自增列列ID （判断依据：genByDefault）
myGetInsertValue    重载anlGetColumnValue， 
                    1.insert 没有指定，取自增值; 
                    2.insert 指定为null, 取自增值; 
                    3.insert 指定为0， 取自增值;  (mysql: sql_mode参数NO_AUTO_VALUE_ON_ZERO对主键ID为0的记录有影响。NO_AUTO_VALUE_ON_ZERO 禁用0，只有NULL可以生成下一个序列号)
                    4.insert 指定有效值，取有效值，并回填sequence的值（ankSetIdnSeqValue）。
tabCreateIdnSeq     系统表插入相关记录, 自增列不支持用户指定default, 系统表的default文本在此处拼接，用户不可查出具体值
kcbMakeIdnDefaultExpr 硬编码生成sequence表达式
dcLoadIdnColDefault   dc加载自增列的默认值，加载sequence

```

  


##   [4. Specification And Constraints（规格与约束）](https://conf.yasdb.com/pages/viewpage.action?pageId=113972889#4-specification-and-constraints%E8%A7%84%E6%A0%BC%E4%B8%8E%E7%BA%A6%E6%9D%9F)  

- auto_increment 只适用于数值类型的列，一般配合主键使用。
- 一个表只有一个自增列，该列必须定义了索引，且索引必须为第一列。


          there can be only one auto column and it must be defined as a key

- auto_increment和default不能共同设置。
