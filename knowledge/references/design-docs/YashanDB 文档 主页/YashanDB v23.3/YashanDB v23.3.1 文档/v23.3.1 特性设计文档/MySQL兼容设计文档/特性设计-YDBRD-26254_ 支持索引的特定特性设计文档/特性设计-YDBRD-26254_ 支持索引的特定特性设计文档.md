##   [2. Features（功能特性）](https://conf.yasdb.com/pages/viewpage.action?pageId=109601972#2-features%E5%8A%9F%E8%83%BD%E7%89%B9%E6%80%A7)  

【DROP索引】

（1）ALTER TABLE newtable DROP INDEX newtable_C1_IDX

         语法：ALTER TABLE table_name DROP INDEX index_name 

         注： 该方式不允许删除CONSTRAINT_INDEX （foreign key创建的索引允许删除）

              （cannot drop index used for enforcement of unique/primary key）

   (2)     DROP INDEX index_name on table_name; 

【索引变更】

（1）MODIFY

1.1 ALTER TABLE `test`.`test_table` MODIFY COLUMN `C1` varchar(100) CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci NOT NULL, ADD PRIMARY KEY (`C1`)   添加主键

（2）ADD COLUMN

（  3）ADD UNIQUE INDEX

3.1 ALTER TABLE `test`.`test_table` ADD UNIQUE INDEX `TEST_INDEX`(`C2`) USING BTREE

语法：ALTER TABLE table_name ADD UNIQUE INDEX index_name(index_column)...

           注：ADD UNIQUE INDEX 中的INDEX可以省略,  INDEX可以同义替换为KEY

【索引选项】

（1）USING BTREE

语法：CREATE INDEX index_name USING BTREE ON table_name(index_column)；

           CREATE INDEX index_name ON table_name(index_column) USING BTREE；

索引的存储类型有两种：BTREE和HASH  (当前只支持BTREE)

##   [5. Detail Design（详细设计）](https://conf.yasdb.com/pages/viewpage.action?pageId=113972889#5-detail-design%E8%AF%A6%E7%BB%86%E8%AE%BE%E8%AE%A1)  

问题创建索引： MYSQL 同一用户，不同表之间索引可以重名

                           YASHAN 同一用户，不同表之间索引不能重名

方案一：修改已有系统表OBJ$ 和索引     `I_OBJ3 定义`  

```
CREATE TABLE OBJ$
(
    ......
    COMPAT_NS#      BINARY_TINYINT,      --用于处理表与视图，或者存储过程等不同OBJECT TYPE之间的重名问题,yashan: 该值为空，mysql:记录ObjectNameSpace
    PARENT_OBJ#     BINARY_BIGINT        --用于处理MYSQL索引重名问题, yashan:该值为空，mysql:记录表的objId
)
CREATE UNIQUE INDEX I_OBJ3 ON OBJ$(OWNER#, NAME, NAMESPACE, SUBNAME, COMPAT_NS#, PARENT_OBJ#)  --新增COMPAT_NS#和PARENT_OBJ#
typedef struct StObjectMaker
{
   ......
   CodUint64  parentOid;
   CodBool    withParent;       --Yashan模式，withParent = FALSE; MYSQL模式 withParent = TRUE;
} ObjectMaker;

问题：升级场景
1.该方案升级后无法切mysql模式，索引还保留原始定义；
2.因为直接修改了索引定义，升级过程中不会升级这个索引，所以升级相关的ci会不通过，需要特殊处理。
不能删除索引重新建立的原因：删除需要用到索引。

```

方案二：新增MYSQL系统表 mysql.index$ 记录OBJID，原始索引名，MYSQL索引名，将索引进行重命名映射 (参考：mysql schema与yashan user的映射)

```
MYSQL系统表(oid,  org_index_name, mysql_index_name)

indexCreateByDesc 中调用ankAllocObjectId() 生成objectId， 令objMaker-&gt;objectId = oid;
callBackInCompatMode 返回新索引名，即：$MY_IDX_xxxx ,新索引名携带objectId, 这样即使org_index_name相同，新索引名也是不同的，从而解决重名问题。
dcLoadIndexNameAndOwner 调用callBackInCompatMode从mysql系统表里获取原始索引名称。

```
