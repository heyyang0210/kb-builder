##   [1. Overview（概述）](#1-overview概述)  

SQL语句中表达式支持输入超过32000字节的字符串字面量，本需求主要参照mysql数据库

##   [2. Features（功能特性）](#2-features功能特性)  

###   [2.1 mysql 字符串长度定义限制](#21-mysql-字符串长度定义限制)  

mysql varchar 的最大长度在MySQL中可以达到65535字节，定义时根据字符集不同有所限制，字符类型若为utf8，每个字符最多占3个字节，最大长度不能超过21845。

超过65535字节须用TEXT/LONGTEXT存TEXT 最大长度 65535 个字符    
  LONGTEXT 最大长度 4294967295 个字符

###   [2.2 mysql 字符串插入长度限制](#22-mysql-字符串插入长度限制)  

mysql表现：可以直接插入超过32000的常量字符串到LONGTEXT类型(CLOB)中，只有整SQL长度限制（max_allowed_packet 配置项 1M）

yashan表现：常量字符串限制16000，字符串计算值限制32000，整SQL长度限制为2M
