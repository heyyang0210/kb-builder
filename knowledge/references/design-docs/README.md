# 特性设计文档目录

本目录存放 YashanDB 各特性的设计文档，作为文档生成的**最高优先级**参考资料。

## 用途

- 提供功能规格、行为定义、参数说明
- 作为生成文档时最权威的内容来源
- 文档中的示例代码可直接引用

## 文件命名规范

```
[知识点编号]-[知识点名称]-设计文档.md
```

示例：`BP树索引-设计文档.md`
