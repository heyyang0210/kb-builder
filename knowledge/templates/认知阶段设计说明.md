# 认知阶段设计说明

## 一、什么是认知阶段

认知阶段描述读者对该知识点需要达到的**理解深度**，是文档元数据的重要组成部分。

## 二、五个认知阶段

| 阶段 | 符号 | 含义 | 典型场景 | 读者画像 |
|------|------|------|---------|---------|
| **感性认知** | `■感性认知` | 快速理解"是什么"，建立初步印象 | 入门概念、名词解释、快速概览 | 初学者、新入职员工 |
| **模型语言** | `■模型语言` | 掌握语法、API、使用方法 | SQL 语法、函数参考、配置参数 | 开发者、DBA |
| **内部机理** | `■内部机理` | 深入理解内部实现原理 | 索引原理、事务隔离、存储引擎 | 高级 DBA、架构师 |
| **架构生态** | `■架构生态` | 理解架构设计、生态集成 | 高可用方案、部署拓扑、技术选型 | 架构师、技术总监 |
| **实践调优** | `■实践调优` | 实战优化、性能调优 | 慢查询优化、参数调优、故障诊断 | 资深 DBA、运维专家 |

## 三、自动选择规则

大模型生成文档时，根据知识类型自动选择认知阶段：

| 知识类型 | 默认认知阶段 | 说明 |
|---------|------------|------|
| 通用基础 | `■感性认知` | 入门知识，快速理解概念 |
| 理论机制 | `■内部机理` | 深入理解内部原理 |
| 实战调优 | `■实践调优` | 实战优化场景 |
| 架构对比 | `■架构生态` | 架构设计与选型 |
| 运维 SOP | `■实践调优` | 标准化操作流程 |
| SQL/开发参考 | `■模型语言` | 语法与 API 参考 |
| 兼容性差异 | `■模型语言` | 功能差异与迁移方法 |

## 四、特殊情况处理

1. **跨阶段知识点**：如果知识点跨越多个认知阶段，选择**最主要的阶段**
2. **前置知识引导**：可在文档开头添加"前置知识"章节，引导读者先学习相关阶段内容
3. **读者自定义**：读者可根据自身水平选择不同认知阶段的文档

## 五、模板中的表示

### 未选中状态（通用模板）
```yaml
认知阶段：□感性认知 □模型语言 □内部机理 □架构生态 □实践调优
```

### 已选中状态（具体模板）
```yaml
认知阶段：■内部机理
```

## 六、设计价值

1. **知识分级**：帮助读者快速找到适合自己水平的文档
2. **学习路径**：支持按认知阶段构建学习路径（感性认知 → 模型语言 → 内部机理 → 架构生态 → 实践调优）
3. **内容组织**：指导作者按认知阶段组织内容深度
4. **质量评估**：作为文档质量评估的维度之一
