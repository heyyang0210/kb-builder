# 模板目录说明

本目录包含 7 套标准化的知识文档模板，用于指导 AI 生成结构化的 YashanDB 技术文档。

## 模板清单

| 序号 | 模板名称 | 文件名 | 适用场景 |
|------|---------|--------|---------|
| 1 | 通用基础模板 | `01-通用基础模板.md` | 通用概念、入门知识 |
| 2 | 理论机制类模板 | `02-理论机制类模板.md` | 索引原理、事务隔离、存储引擎等 |
| 3 | 实战调优类模板 | `03-实战调优类模板.md` | 慢查询优化、参数调优、性能诊断 |
| 4 | 架构对比类模板 | `04-架构对比类模板.md` | 高可用方案、部署拓扑、技术选型 |
| 5 | 运维SOP类模板 | `05-运维SOP类模板.md` | 部署规范、巡检规范、应急预案 |
| 6 | SQL/开发参考类模板 | `06-SQL开发参考类模板.md` | SQL语法、PL/SQL、函数参考 |
| 7 | 兼容性差异类模板 | `07-兼容性差异类模板.md` | 与Oracle功能差异、迁移指南 |

## 模板设计文档

- `模板设计思路.md` - 模板体系的设计原则和分类逻辑

## 使用方式

每个 Skill 文件（位于 `knowledge/skills/` 目录）会引用对应的模板：

| Skill | 对应模板 |
|-------|---------|
| `00-通用生成-skill.md` | `01-通用基础模板.md` |
| `01-理论机制-skill.md` | `02-理论机制类模板.md` |
| `02-实战调优-skill.md` | `03-实战调优类模板.md` |
| `03-架构对比-skill.md` | `04-架构对比类模板.md` |
| `04-运维SOP-skill.md` | `05-运维SOP类模板.md` |
| `05-SQL开发参考-skill.md` | `06-SQL开发参考类模板.md` |
| `06-兼容性差异-skill.md` | `07-兼容性差异类模板.md` |

AI 在生成文档时，会读取对应模板的章节结构，按照模板要求填充内容。

> 目录精简说明：当前目录位于 knowledge/ 下，资源引用以仓库根为基准。历史示例路径以 knowledge/README.md 与企业 manifest 为准。
