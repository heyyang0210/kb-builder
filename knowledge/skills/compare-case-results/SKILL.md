# 比对文档用例结果

只使用提取阶段固定的预期与执行阶段结果。比对 JSON 值类型及数组顺序，行对象字段顺序不影响匹配。结果截断不得通过；前提不满足为未执行，SQL 错误为失败。未声明预期只验证执行状态，比较状态记为 not_provided，不能宣称已确认结果正确。不得访问数据库或替换实际结果。

平台运行时由 `production-quality-service.js` 的同名受信任处理函数执行此确定性契约；本文件是能力说明与版本证据，不授权执行文档中指定的脚本。
