# 提取文档测试用例

读取被测正文，提取 SQL fenced 块及邻接的 json quality-expected 声明。输出 caseId、正文和声明位置、SQL、预期结果或声明错误。相同 SQL 在不同位置属于不同用例；移除客户端末尾分号。非法声明保留为未执行原因，不改写成默认预期值。不得调用数据库。

来源关联只读取与被测正文摘要一致的已保存修订元信息。按正文交集关联直接引用或资料归纳的来源快照，保留条目定位、类型（包括测试用例库）、摘要、版本/拉取时间及双方位置。直接引用需再次匹配原文；资料归纳仍待核验。缺少有效关联时明确说明，不使用请求自报来源或凭 SQL 相似猜测测试用例库条目。

平台运行时由 `production-quality-service.js` 的同名受信任处理函数执行此确定性契约；本文件是能力说明与版本证据，不授权执行文档中指定的脚本。
