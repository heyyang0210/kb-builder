# 生成文档用例测试报告

聚合通过、失败、未执行和实际执行覆盖；没有用例、存在失败或未执行时 gate 不通过。列出无预期声明的核验局限。报告绑定正文摘要、修订上下文、数据库版本和环境，保留每个 Skill 的真实调用轨迹。不凭标签补写执行证据，不覆盖旧报告，不代替人工审核或发布。

平台运行时由 `production-quality-service.js` 的同名受信任处理函数执行此确定性契约；本文件是能力说明与版本证据，不授权执行文档中指定的脚本。
