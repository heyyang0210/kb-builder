# 执行 YashanDB 文档用例

只通过服务端配置的 YashanDB 只读适配器执行，不从文档接受地址或凭据。非法预期声明或缺少测试库时不执行 SQL。逐例保留实际结果、受控错误码和执行次数；存储不可用、超时、只读范围拒绝记录前提未满足。不在此阶段推断结果是否正确，不重试写入，不修改文档。

平台运行时由 `production-quality-service.js` 的同名受信任处理函数执行此确定性契约；本文件是能力说明与版本证据，不授权执行文档中指定的脚本。
