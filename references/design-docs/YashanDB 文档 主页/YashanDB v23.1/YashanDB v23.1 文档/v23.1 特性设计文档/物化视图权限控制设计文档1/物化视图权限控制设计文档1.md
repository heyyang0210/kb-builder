##   [1. Overview（概述）](https://conf.yasdb.com/pages/viewpage.action?pageId=113972889#1-overview%E6%A6%82%E8%BF%B0)  

本次特性范围仅支持物化视图的基础权限功能，其他功能后续演进； 部署模式限制：

- 特性支持的部署形态为  主备(单机)     （其他部署形态视后续演进支持）
- 单机行执行 （列执行后续演进支持）


##   [2. Features（功能特性）](https://conf.yasdb.com/pages/viewpage.action?pageId=113972889#2-features%E5%8A%9F%E8%83%BD%E7%89%B9%E6%80%A7)  

(1) 功能按等价类划分子特性，将每个子特性对应的输出行为，尝试进行行为解释说明。等价类划分要证明全面。

|功能|设计表现|设计说明|
|:---|:---|:---|
|物化视图权限控制|物化视图能够通过给予对应的权限执行对应的操作|权限赋予正确，物化视图相关操作功能正常，缺少对应权限，物化视图相关操作报错显示 insufficient privileges,**物化视图权限不允许通过role传递**|


(2) SQL语法有关的功能特性设计，需要给出语法图或EBNF，说明各语法分支的具体含义。不支持的分支可以不提及，但只做了语法兼容的分支，要给出显著而且明确的说明。

添加system权限：① CREATE MATERIALIZED VIEW  

                             ② CREATE ANY MATERIALIZED VIEW

                             ③ ALTER ANY MATERIALIZED VIEW

                             ④ DROP ANY MATERIALIZED VIEW

(3) 

|场景|operator权限|owner权限|说明|
|---|---|---|---|
|在自己的schema下创建物化视图|① + CREATE TABLE/CREATE ANY TABLE +  对基表的访问权限|同operator|需要有CREATE MATERIALIZED VIEW  和 CREATE TABLE/CREATE ANY TABLE 系统权限；,需要有不在自己schema下所有基表的访问权限（    `READ`       or       `SELECT`       对象权限 或者   READ     ANY     TABLE     or     SELECT     ANY     TABLE 系统权限  ）|
|在其他的schema下创建物化视图|②  |  `CREATE`         `TABLE + 对基表的访问权`  |operator需要有物化视图的CREATE ANY MATERIALIZED VIEW 系统权限；,owner 需要有    `CREATE`         `TABLE系统权限和所有基表的访问权限（READ or SELECT 对象权限 或者 READ ANY TABLE or SELECT ANY TABLE 系统权限）`  |
|在自己的schema下修改物化视图|/|同operator|无特殊权限要求|
|在其他的schema下修改物化视图|③|/|operator需要有物化视图的ALTER     ANY     MATERIALIZED     VIEW   系统权限|
|在自己的schema下删除物化视图|/|同operator|无特殊权限要求|
|在其他的schema下删除物化视图|④ + drop 保存有物化视图数据的  internal table, views, and index 权限|/|operator需要有物化视图的DROP   ANY     MATERIALIZED     VIEW   系统权限 和drop   保存有物化视图数据的内部   table, views, and index 权限|
