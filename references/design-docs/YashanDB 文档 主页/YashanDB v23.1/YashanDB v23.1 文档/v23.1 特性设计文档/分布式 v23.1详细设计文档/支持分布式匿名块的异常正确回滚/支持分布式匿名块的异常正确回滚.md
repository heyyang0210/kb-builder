##   [](#1-overview概述)      [1. Overview（概述）](https://conf.yasdb.com/pages/viewpage.action?pageId=89083717#1-overview%E6%A6%82%E8%BF%B0)  

单机匿名块中如果出现失败，具有这个匿名块整体回滚的能力，分布式需要跟单机保持一致。

##   [](#2-features功能特性)      [2. Features（功能特性）](https://conf.yasdb.com/pages/viewpage.action?pageId=89083717#2-features%E5%8A%9F%E8%83%BD%E7%89%B9%E6%80%A7)  

*说明本方案的功能特性。*

匿名块被作为一个整体操作，如果中途出现失败，需要回滚整个匿名块。

例外的情况是如果匿名块中已经执行了提交，则已经执行提交的不会再被回滚，会执行提交的语句：commit，ddl。即在匿名块中执行了commit或ddl后，如果再出现失败，则回滚commit或ddl之后的部分。

###   [](#51-architecture架构)      [5.1 Architecture（架构）](https://conf.yasdb.com/pages/viewpage.action?pageId=89083717#51-architecture%E6%9E%B6%E6%9E%84)  

*说明方案的总体架构，优先考虑通过架构图进行描述。*

在匿名块开始执行的时候创建savepoint，cn将该savepoint挂载到stmt上，dn将该savepoint存到事务对应的savepoint链上，回滚时cn通过stmt上的savepoint拿到该savepoint的名字，dn根据名字回滚到该savepoint。

1. 如果匿名块中失败之前发生了提交，dn上的savepoint被清掉了，cn根据名字下发回滚的savepoint时dn发现找不到，则回滚当前未提交的全部事务。
1. 如果匿名块中失败前发生了回滚，则dn上的对应savepoint被清掉了，cn根据名字下发回滚的savepoint时dn发现找不到，则回滚当前未提交的全部事务。
1. 如果匿名块中失败前回滚到匿名块开始前的某个savepoint，则不清理内置名字的savepoint，防止后续回滚的时候找不到匿名块的savepoint。

savepoint中增加name字段专门用于存储分布式下匿名块中savepoint的名字

```
typedef struct StSavepoint {
    UndoRowId     ura;
    UndoRowId     tempUra;
    CodUint32     ssn;
    CodUint32     lockVersion;
    Xid           xid;
    LockSavepoint lockSavepoint;
    CodUint64     transPtt;
    CodChar       name[COD_NAME_BUFFER_SIZE]; //used for dstb anonymous block
} Savepoint;

```

执行匿名块之前生成savepoint

```
CodResult anlSavepoint(AnlStmt* stmt)
{
    if (COD_LIKELY(stmt-&gt;context-&gt;type != SQL_ANONYMOUS_BLOCK &amp;&amp; !isCoordExec(stmt))) {
        ankSavepoint(stmt-&gt;handler-&gt;khdlr, &amp;stmt-&gt;savepoint);
        return COD_SUCCESS;
    }

    (CodVoid) snprintf(stmt-&gt;savepoint.name, COD_NAME_BUFFER_SIZE, "SYS_S_%" PRIu16, stmt-&gt;attr.id);
    CodText spName;
    codStr2Text(stmt-&gt;savepoint.name, &amp;spName);

    if (anlDstbSavepoint(stmt, &amp;spName) != COD_SUCCESS) {
        return COD_ERROR;
    }
    return COD_SUCCESS;
}

```

回滚时从stmt上拿到名字发给各个节点回滚

```
CodResult anlRollbackSp(AnlStmt* stmt,CodText* spName) {
    if (ankRollbackSavepoint(stmt-&gt;handler-&gt;khdlr, spName) != COD_SUCCESS) {
        return COD_ERROR;
    }

    COD_ERR_SAVE
    COD_DSTB_ERR_SAVE(stmt-&gt;handler);
    if (anlSendSpMessageToDn(stmt, spName, ROLLBACK_SAVEPOINT) == COD_SUCCESS) {
        return COD_SUCCESS;
    }
    
    COD_DSTB_ERR_RESTORE(stmt-&gt;handler);
    COD_SET_ERROR(ERR_DSTB_ROLLBACK_ALL_DONE, "failure of rolling back to savepoint");
    anlSetErrToDataConn(stmt-&gt;handler);
    COD_ERR_RESTORE;
    anlDstbRollback(stmt-&gt;handler);
    
    return COD_ERROR;
}

```

基本功能测试

|序号|场景|预期结果|
|:---|:---|:---|
|1| 单层匿名块中只有一句时出现失败| 正确回滚，不影响此匿名块之前的部分（包括还未提交的）|
|2| 单层匿名块执行到中途时出现失败| 正确回滚整个匿名块，不影响此匿名块之前的部分|
|3| 单层匿名块中有commit，commit后出现失败| 正确回滚匿名块中commit之后的所有部分|
|4| 单层匿名块中有ddl，ddl执行成功后出现失败| 正确回滚匿名块中ddl执行成功之后的所有部分|
|5| 单层匿名块中有rollback| rollback回滚掉事务中未提交的语句，包括匿名块中和匿名块之前的，rollback之后的语句不受影响|
|6| 单层匿名块中有ddl，ddl执行失败，失败|  
|
|7| 单层匿名块中有rollback，rollback后出现失败| 回滚掉整个匿名块和匿名块之前未提交的语句|
|8| 单层匿名块执行失败之后执行rollback| 回滚掉事务中未提交的语句，包括匿名块中、前的|
|9| 单层匿名块执行成功之后执行rollback|回滚掉事务中未提交的语句，包括匿名块中、前的|
