###   [一、设计方案](#一设计方案)  

####   [一、父表检查](#一父表检查)  

当插入或者更新子表时要判断父表中是否存在插入或更新的外键值。

对于分区表，首先通过fkparent中的索引对cursor上的值和index上的partcolmap构建partkey定位一级分区。

若索引是二级分区索引，则再根据cursor上的值和index上的subpartcolmap构建subpartkey定位二级分区。

根据定位到的partnum获得对应的btree进行查询、

####   [二、子表检查](#二子表检查)  

在删除或更新主表时要判断子表中是否存在依赖于该值的row。

在加在fkchilddc时会比较dc上索引列和外键列获得与外键列匹配列个数最多的索引的slot和匹配的个数idxmatchcolcount。若子表不存在索引的索引列与外键列有交集则slot为invalid。

如果该子表上没有索引时使用表去查找对应row，若存在索引时则去索引上查找对应row

#####   [1、分区索引查找](#1分区索引查找)  

当fkchildDc的idxslot不为invalid时通过idxslot获得对应索引。

######   [1、一级分区查询](#1一级分区查询)  

通过比较索引的partcols和fkchild的columnId判断分区键是否是外键的子集。

若是则表示可以通过cursor构建partkey去locate分区。获得对应的partnum，并将fkpartInfo的isTargetPart置为true。后续通过partnum获得btree进行查询。

若不是则表示不能通过cursor构建partkey去locate分区，对于非range分区将partnum置为0，之后通过遍历所有分区获得btree去查找。

对于range分区会通过cursor去构建partkey，对于cursor上不存在列赋予该列minvalue和maxvalue从而分别找到对应的最小分区leftpartnum和最大分区rightpartnum。之后遍历leftpartnum和rightpartnum之间的分区去获得btree去查找。

######   [2、二级分区查询](#2二级分区查询)  

在定位一级分区或者遍历一级分区获得对应的part后去定位二级分区，与定位一级分区相同首先判断二级分区键是否是外键的子集。

若是则表示可以通过cursor去构建subpartkey去locate二级分区。获得对应的subpartnum，并将fkpartInfo的isTargetSubPart置为true。后续通过partnum和subpartnum获得btree进行查询。

若不是则表示不能通过cursor去locate二级分区，对于非range二级分区将partnum置为0，之后通过遍历该分区的所有二区分区获得btree去查找。

对于二级分区是range分区，通过cursor去构建subpartkey去locate分区，对于cursor上不存在列赋予该列minvalue和maxvalue从而分别找到对应的最小子分区和最大子分区，置fkpartInfo的leftpartNum的spnum为最小子分区的spnum，置fkpartInfo的rightpartNum的pnum和leftpartNum的pnum相同，spnum为最大子分区的spnum。

####   [2、分区表查找](#2分区表查找)  

与分区索引一致只是通过表定位对应的分区。

  


###   [三、数据结构](#三数据结构)  

在indexDict里面新增一个数组subPartColMap 存放所有是分区键的索引列的id

```
typedef struct StIndexDict {
    TableDict*   tableDict;
    AnkIndexDesc desc;
    IndexProc*   procs;
    List*        fkChildren;
    CodUint16*   partColMap;
    CodUint16*   subPartColMap;
    JtDcInfo*    jt;
    union {
        CodPointer handler;   // for nonpartition index
        PartDict*  partDict;  // for partitioned index
    };
} IndexDict;

```

在FkPartInfo里添加 FkLocateSubPartKey FkCalcSubPartRange存放二级分区定位函数指针，leftSubpartNum，rightSubpartNum存放二级分区的边界值

```
typedef struct StFkPartInfo {
    FkLocatePartKey    locate;
    FkLocateSubPartKey locateSubPart;
    FkCalcPartRange    calculate;
    FkCalcSubPartRange calculateSubPart;
    CodPointer         dc;
    PartDict*          partDict;
    CodUint64          leftPartNum;
    CodUint64          rightPartNum;
    CodUint64          leftSubpartNum;
    CodUint64          rightSubpartNum;
    CodBool            isTargetPart;
    CodBool            isTargetSubPart;
    CodBool            useIndex;
} FkPartInfo;

```
