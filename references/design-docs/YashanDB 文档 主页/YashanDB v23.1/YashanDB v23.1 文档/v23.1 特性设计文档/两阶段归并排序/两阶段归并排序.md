#   [YDBRD-13550 : 归并排序 Design](#ydbrd-13550--归并排序-design)  

IR链接：YDBRD-12241 / SR链接：YDBRD-13550

##   [1. Overview（概述）](#1-overview概述)  

sort merge主要用于并行时，语句中有order by,将order by 下推到每个子线程执行，然后再每个线程有序的情况下，通过归并排序使得最终结果有序。

##   [3. Interfaces（接口）](#3-interfaces接口)  

```
CodResult pxMergeInitList(AnlStmt* stmt, TabQueueReader* reader)：只执行一次，初始化堆

CodResult pxGetBlocksToCache(AnlStmt* stmt, TabQueueReader* reader, CodBool* isEof) ： 只执行一次，从tabQueue里取block，将对应block存放到每个wId的cacheList中，直至每个cacheList都有数据为止

CodResult pxGetWriterBlock(AnlStmt* stmt, TabQueueReader* reader, CodUint16 wId, CodBool* isEof)： 从tabQueue获取已经消费完的wport的block

CodResult pxFetchMergeRow(AnlStmt* stmt, TabQueueReader* reader, CodBool* isEof)：sortMerge进行fetch时的主函数，多次调用

CodResult pxFetchRowFromCache(AnlStmt* stmt, TabQueueReader* reader, CodUint16 writerId, CodBool* isEof)：从有效的cacheList的block中取出每行数据并decode

CodResult pxGetRowFromBlock(AnlStmt* stmt, TabQueueReader* reader, CodUint16 writerPort, CodBool* isBlockEof)：从block按slot取出对应row

CodResult pxHeapSortBuild(AnlStmt* stmt, TabQueueSubReader* readerCurrInfo, TabQueueHeapSort* heapSort,CodUint16 heapSize)：构建堆

CodResult pxHeapSortInsert(AnlStmt* stmt, TabQueueSubReader* readerCurrInfo, TabQueueHeapSort* heapSort, CodUint16 wPort)：往堆中插入数据

CodResult pxHeapSortDelete(AnlStmt* stmt, TabQueueSubReader* readerCurrInfo, TabQueueHeapSort* heapSort,CodUint16* wPort, CodUint16 heapSize):取堆顶数据


```

###   [5.2 Data Structures & Flow（数据结构与流程）](#52-data-structures--flow数据结构与流程)  

```
typedef struct StTabQueueMerge {
    TabQueueHeapSort heapSort;
    CodUint16        mergeListCount;
    CodUint16        writerPort;  // make sure the last output block;
    CodUint16        heapSize;
    CodBool          isHeapBuild;
    CodUint8         reserved;
} TabQueueMerge;

typedef struct StTabQueueSubReader {
    TabQueueEventList  cacheList;  //used for column Engine and sort Merge(store the blocks for every writer,release resources by tabQueue)
    TabQueueBlockHead* block;      //used for column Engine and sort Merge(store every writer current consumed block,release resources by tabQueue)
    CodChar*           row;        //store every writer current row
    CodUint16          slot;       //store every writer current row of current blocks
    CodUint8           reserved[6];
} TabQueueSubReader;

typedef struct StTabQueueReader {
    CodPointer         ctx; /* each reader set its own context */
    TabQueue*          queue;
    TabQueueBlockHead* block;
    CodUint16          endpoint;
    CodUint16          rPort;
    CodUint16          slot;
    CodUint16          reserved;
    CodChar*           row;
    MatColumnLocator   locator;
    TabQueueSubReader* currInfo;
    TabQueueMerge*     tabQueueMerge;
    SpinLock           colReaderLock; /* for col table px reader merge */
} TabQueueReader;


```
