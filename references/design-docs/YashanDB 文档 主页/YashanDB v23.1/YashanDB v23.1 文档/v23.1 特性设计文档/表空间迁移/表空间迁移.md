表空间迁移是由物理文件的迁移，以及元数据导入导出两部分组成的一个完成的功能

后续我们完整的迁移会通过工具来实现，本次转测只是将表空间迁移中的这两个功能通过通过SQL的方式进行测试，元数据导入导出部分的SQL已经集成在导入导出工具中。

完整的迁移流程是：

- 迁移表空间


```
duplicate tablespace (test_duplicate2, test_duplicate3) to 127.0.0.1:1601 '/home/lyq/anchor_regress/ha_regress/ha_home/node_1/data';
duplicate tablespace (test_duplicate2, test_duplicate3) to 127.0.0.1:1601;

```

- 从原库导出表空间下的元数据


```
exp sys/Cod-2022@127.0.0.1:1688  file=exp1.dmp  table_spaces=TEST_DUPLICATE2  transport_tablespace=Y

```

- 将元数据导入新库


```
imp sys/Cod-2022@127.0.0.1:1688  file=exp1.dmp

```
