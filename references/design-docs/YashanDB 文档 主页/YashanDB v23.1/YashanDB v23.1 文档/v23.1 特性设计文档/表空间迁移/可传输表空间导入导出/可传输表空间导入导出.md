##   [导出](#导出)  

针对表空间迁移，导出工具实现了表空间级别的导出

```
exp sys/Cod-2022@127.0.0.1:10011  file=exp1.dmp  table_spaces=TEST_DUPLICATE1, TEST_DUPLICATE2  transport_tablespace=Y

```

- table_spaces：指定space list，这些space必须是自包含的，自包含的意思是，表在这些表空间上，表上的索引，分区，lob都必须在这些表空间上，这样才能一起迁移，可不不在同一个表空间下，但是得在这个表空间List里
- transport_tablespace： 表示是不是可传输表空间


Y ：那就只导出表的定义，以及表的segment信息，表空间迁移里用到的是Y

N:  就是普通的导出，只是范围是表空间级别的。

##   [导入](#导入)  

```
imp sys/Cod-2022@127.0.0.1:1688  file=exp1.dmp

```

导入就只将导出的dump文件进行导入，可传输表空间的导入会先创建表，然后为表指定segment，建表失败，或者指定的segment不存在，都会失败。

##   [约束](#约束)  

不支持带AC的导出不支持分区索引的导出
