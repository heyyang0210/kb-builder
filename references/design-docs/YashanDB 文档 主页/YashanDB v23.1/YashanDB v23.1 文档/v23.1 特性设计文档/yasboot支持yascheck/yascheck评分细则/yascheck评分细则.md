|检查内容|计算规则|细则|告警等级计算|
|:---:|:---:|:---:|---|
|物理内存|两个评分综合得分：,1、剩余空间：权重 30%,2、使用率：权重 70%,  
,剩余空间 x 0.3 + 使用率 x 0.7 = 最终结果|  
||
|分数|剩余空间|使用率||
|100|大于等于8G|小于等于40%|
|90|小于8G并且大于等于4G|大于等于40% 并且 小于60%|
|75|小于4G并且大于等于1G|大于等于60% 并且 小于80%|
|50|小于1G|大于等于80%|
|分数|等级|
|[0,60]|紧急|
|[60,75)|警告|
|[75,90)|提示|
|[90,100]|安全|
|交换内存空间信息|两个评分综合得分：,1、交换空间占物理空间倍数,2、交换空间剩余率,交换空间占物理空间倍数 x 0.5 + 交换空间剩余率 x 0.5||
|分数|交换空间占物理空间倍数|交换空间剩余率|
|100|大于等于1倍|大于等于80%|
|75|大于等于0.5 小于等于 1倍|大于等于50% 小于 80%|
|50|小于0.5|小于 50 %|
