##   [4. Specification And Constraints（规格与约束）](#4-specification-and-constraints规格与约束)  

```
CodUint8 gOpenCsvColumnSplits[COD_MAX_UINT8] = {
    [','] = 1,  ['|'] = 1,  [';'] = 1,  ['\t'] = 1, [0x01] = 1, [0x02] = 1, [0x03] = 1, [0x04] = 1, [0x05] = 1,
    [0x06] = 1, [0x07] = 1, [0x08] = 1, [0x0B] = 1, [0x0C] = 1, [0x0D] = 1, [0x0E] = 1, [0x0F] = 1,
    [0x10] = 1, [0x11] = 1, [0x12] = 1, [0x13] = 1, [0x14] = 1, [0x15] = 1, [0x16] = 1, [0x17] = 1, [0x18] = 1,
    [0x19] = 1, [0x1A] = 1, [0x1B] = 1, [0x1C] = 1, [0x1D] = 1, [0x1E] = 1, [0x1F] = 1,
};

```

分隔符只允许一字节字符，这表名整体考虑范围在0~255之中，参照以上数组，对应值为1的表示当前可支持的分隔符，没列出的则不支持。

支持这个SR后，terminated by后面跟的分隔符，可以出现三种场景：

（1）单字节字符，例如',' '|' ';' '\t'

（2）十六进制数字表示，例如0x12 0x34 0x5。这里涉及到可见字符的概念。    [https://www.asciim.cn/](https://www.asciim.cn/)    ，中说到的32~127都是可见字符。大于127的情况会先拦截（主要是考虑到不给out文件打印出乱码字符的机会），为0也先拦截，为10也先拦截。其它的放行，等后面的gOpenCsvColumnSplits数组来判断,不符合要求的再报错。

（3）整型数字表示，例如12，34。    [https://www.asciim.cn/](https://www.asciim.cn/)    ，中说到的32~127都是可见字符。大于127的情况会先拦截，为0也先拦截，为10也先拦截。其它的放行，等后面的gOpenCsvColumnSplits数组来判断。

##   [5. Data Structures & Flow（数据结构与流程）](#5-data-structures--flow数据结构与流程)  

1.识别terminated by后面的十六进制表示，比如0X13

2.识别到之后由loader内部parse模块将0X13转成0x13字节表示，把此作为分隔符
