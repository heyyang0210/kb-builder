# **1.概述**

数据库服务由实例和数据库组成，数据库一般指控制文件，数据文件，重做文件等数据库文件的集合。实例指运行数据库的进程、线程、内存等资源组成。 集群由若干个数据库实例、一份数据库文件组成。

集群形态下数据库文件被多个实例共享访问，但是依然存在某些文件是实例独自拥有。比如UNDO表空间的文件、REDO文件等。集群数据库文件因为需要被多个实例访问，因此这些文件放置于（YFS）共享文件系统上。

**建库的3种模式：**

**1、指定实例数，默认方式建库**

```
create cluster database test instances 2;
```

**2、指定每一个实例的各个数据库文件信息，自定义方式建库**

```
create cluster database abc
system tablespace datafile 'system' size 64M
sysaux tablespace datafile 'sysaux' size 64M
default tablespace datafile 'users' size 64M
temporary tablespace tempfile 'temp' size 64M
swap tablespace tempfile 'swap' size 64M
instance(
logfile('logfile11' size 32M, 'logfile12' size 32M, 'logfile13' size 32M)
undo tablespace datafile 'undo1' size 64M
)
instance (
logfile('logfile21' size 32M, 'logfile22' size 32M, 'logfile23' size 32M)
undo tablespace datafile 'undo2' size 64M
);
```

  


# **3.规格/范围**

1、部署形态：集群

2、测试环境：磁阵环境+模拟器环境

3、建库语句中，指定datafile时支持"+DG"这种模式

4、自定义数据库语法，除undo和redo log的定义需要放在instance()里面，其它和单机保持一致

5、建库过程中故障，故障相关场景当前暂不支持，故障转测后需要考虑故障场景

# **4.约束限制**

1. 目前只支持4节点集群
1. instances关键字不能与instance关键字同时指定。
1. instances指定的值或者instance指定的列表个数不能大于maxInstances指定的值
