## 1.   **概述**

回收站开启的状态下，删除表和truncate表后，可以使用FLASHBACK TABLE命令将表恢复。

## 2.   **需求分析**

### 2.1 SR：  【23.1】集群支持回收站

链接：    [YDBRD-13512](https://jira.yasdb.com/browse/YDBRD-13512?src=confmacro)    -  【共享集群】集群支持回收站  完成

设计文档：    [复制从 集群支持回收站](https://conf.yasdb.com/pages/viewpage.action?pageId=119547152)      


场 景：  功能及并发场景

需求规格：

1. 进回收站(drop/truncate table)：单机下只有一个节点，在开启回收站配置参数的情况下drop table，本质上是更新obj$上table的名字等信息，以及将table涉及的segment信息写入RECYCLEBIN$，最后失效dc以及rename entry；truncate table相对于drop table而言，只需要把segment信息写入RECYCLEBIN$即可，无需更新obj$以及rename entry，只需要失效dc即可，在单机下drop/truncate table都上了latch X lock处理并发。而集群下存在多个写节点，需要上gls X lock处理实例间的并发，在执行实例写好相关的系统表后，失效dc以及rename entry的操作需要广播同步到其他实例
1. 出回收站(flashback table table_name to before drop/truncate)：单机下，flashback drop本质上是更新obj$上table的名字信息为drop前的名字，并把RECYCLEBIN$上记录的segment信息重新挂回dc，最后失效dc以及rename entry；flashback truncate相对于flashback drop，只需要把RECYCLEBIN$上记录的segment信息重新挂回dc即可，由于entry一直存在且没有变化，无需处理，只需要失效dc即可，单机下flashback drop/truncate会上latch X lock处理并发。而集群下需要上gls X lock处理实例间的并发，在执行实例更新好相关的系统表后，失效dc以及rename entry需要广播同步到其他实例


功能：

1. 支持flashback所有语法、支持开启回收站后的drop/truncate table所有语法


功能限制：

1. 闪回表不能恢复外键
1. 闪回表或者闪回分区时，总是找最新的版本。清理表或者分区时，总是找最旧的版本
1. flashback和truncate需要对应，如flashback全表 to before truncate只能使用truncate全表的数据，flashback分区to before truncate只能使用truncate分区的数据
1. 处于回收站中的表，仍然可以利用系统生成后的名称查询，但不可以做其他DML、DDL
1. 当表空间不够时，会自动触发表空间级别的清理


### **2.2 **  **语法：**

  


|语句|描述|
|:---|:---|
|DROP TABLE|删除表时，会将表以及相关的对象放入回收站，此时该表所占的segment并未释放|
|TRUNCATE TABLE|截断表时， 将表以及相关对象的segment放入回收站，此时该表所占的segment并未释放|
|ALTER TABLE table_name TRUNCATE PARTITION partition_name|截断表分区时，将分区以及相关对象的segment放入回收站|
|FLASHBACK TABLE table_name TO BEFORE DROP [RENAME TO new_name]|从回收站闪回被删除的表，需要保证回收站存在被删除表的信息|
|FLASHBACK TABLE table_name [PARITITION part_name] TO BEFORE TRUNCATE|从回收站闪回被截断的表或者表分区，需要保证回收站存在被截断的表或者表分区的信息|
|PURGE TABLE name|清理回收站的表，同时会删除依赖该对象的其他对象。指定的表名可以是原有表名，或者是表被删除后，系统生成的表名|
|PURGE index name|清理回收站的索引，指定的索引名可以是原有索引名，或者是被删除后，系统生成的表名|
|PURGE TABLESPACE tablespace [USER user]|删除回收站中属于该表空间（以及指定用户）的对象，同时会删除依赖该对象的其他对象|
|PURGE RECYCLEBIN|删除当前用户的回收站对象|
|PURGE DBA_RECYCLEBIN|清空系统回收站|
