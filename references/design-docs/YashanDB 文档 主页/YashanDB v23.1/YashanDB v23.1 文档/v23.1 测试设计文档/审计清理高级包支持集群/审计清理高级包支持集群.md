# 1. 概述

审计清理的高级包可以支持集群 

审计清理高级包   DBMS_AUDIT_MGMT，该高级包为内置高级包，在数据库创建时自动创建。

# 2. 需求分析

  [YDBRD-13353](https://jira.yasdb.com/browse/YDBRD-13353?src=confmacro)    -  审计清理高级包支持集群  完成

审计清理高级包   DBMS_AUDIT_MGMT 包含了：存储过程、函数、定时任务，没有专门的针对DBMS_AUDIT_MGMT的相关缓存，在集群支持高级包、函数、存储过程、定时任务job后即可正常使用审计清理高级包。

集群下某个实例执行清理 ，其他实例能感知到产生的影响
