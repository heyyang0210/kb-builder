# 1. 概述

本需求支持审计策略的元数据信息按集群改造，适用于任意一个节点的审计策略DDL改造，可以应用于所有节点内存

# 2. 需求分析

  [YDBRD-13352](https://jira.yasdb.com/browse/YDBRD-13352)       -     审计策略的元数据信息按集群改造     完成

### 2.1 功能特性

  [开发设计见：审计策略的元数据信息按集群改造](https://conf.yasdb.com/pages/viewpage.action?pageId=109595853)  

集群下某个实例执行  create audit、 audit policy、 alter audit policy 、noaudit policy , drop audit policy   其他实例能感知到ddl产生的影响

功能测试设计如下：



### 3.1 并发测试

并发场景：采用功能用例作为并发用例。

### 3.2 性能测试

开启/关闭审计：数据量较大的情况用例执行时间
