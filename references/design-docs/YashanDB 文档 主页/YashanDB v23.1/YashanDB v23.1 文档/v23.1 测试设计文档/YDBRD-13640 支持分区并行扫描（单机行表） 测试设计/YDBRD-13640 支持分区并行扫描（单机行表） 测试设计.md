# 1.   **概述**

分区并行是基于分区表进行并行，用来提升分区执行速度；包括按分区并行以及按block并行，按分区并行当前特指hash分区并行，方便后续实现hash group等算子并行时，提高执行效率。

SR链接：    [YDBRD-13640](https://jira.yasdb.com/browse/YDBRD-13640?src=confmacro)    -  支持分区并行扫描  完成

# 2.   **需求分析**

原本单机行表分区表不支持并行，现在开放并行，详见：    [分区表并行](https://conf.yasdb.com/pages/viewpage.action?pageId=113975946)  

  


需求范围：单机、行表
