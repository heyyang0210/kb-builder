# 2.   **需求分析**

1.外键约束是否能够正确地限制分区键和子表索引列之间的关系；

2.外键约束下，子表能否正确地引用主表中存在的记录；

3.当主表中的记录被删除或更新时，外键约束能否正确地处理子表中的相关数据；

4.当子表中的记录被删除或更新时，外键约束是否能够正确地维护主表的数据完整性；

5.外键约束对于数据插入的影响，是否能够限制插入无效的记录；

6.当分区键或索引列的值发生变化时，外键约束能否正确地处理相关数据；

# 3.  **测试设计方法**

(1) 主要采用场景法和错误推算法及边界测试法进行设计

1、对于语法上新增的字段，进行校验

2. 外键列是否搭配索引组合

3. 1级分区键和2级分区键相对于子表

4. 子表上有无索引列组合和外键以及分区键的关系，不同排列
