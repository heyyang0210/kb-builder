# **1. 概述**

开启二级分区回收站开关，能够闪回指定的二级分区表的分区和子分区

**SR:**    [[YDBRD-15284] 二级分区支持回收站 - SICS-CoD Jira (yasdb.com)](https://jira.yasdb.com/browse/YDBRD-15284)  

开发设计：    [FLASHBACK SUBPARTITION - YashanDB - SICS-CoD Confluence (yasdb.com)](https://conf.yasdb.com/display/YAS/FLASHBACK+SUBPARTITION)  

# **2.需求分析**

二级分区表里, 可以指定一、二级某个分区 进行tuncate/drop，恢复也可指定某个一、二级分区进行flashback;

# **3.测试设计方法**

(1) 主要采用场景法和错误推算法及边界测试法进行设计

1.回收站开关打开，Truncate/drop二级分区表/1、2级分区能够正常闪回

2.带不同约束的二级分区表，能够正常闪回

3.清空回收站，不能正常闪回

4.新增语法图做校验
