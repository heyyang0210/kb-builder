# 1. 概述

本需求产生是为了解决问题     [YDBRD-5376](https://jira.yasdb.com/browse/YDBRD-5376)    。由于绑定参数在执行阶段 exec 才明确具体的参数类型和参数值，因此在 parse 和 verify 阶段推导出的 parseTree 会出现和用户输入的绑定参数类型不匹配的情况，从而导致 fetch 阶段查找对应的行信息失败。

# 2. 需求分析

  [YDBRD-5904](https://jira.yasdb.com/browse/YDBRD-5904?src=confmacro)    -  【2023.1】单机SQL支持变量窥视  完成

### 2.1 功能特性

参见开发设计     [变量窥视 特性设计文档](95100148.html)  

通过占位符在 SQL 语句中预留位置，实际的参数值和参数类型在使用的时候决定。

绑定参数语法示例：

```
declare
    vc_name integer := 8 ;
begin
    execute immediate 'select id,name from tbl_job where id= :1' using vc_name;
    dbms_output.put_line(vc_name);
end;
/
```

```
PreparedStatement pstmt = con.prepareStatement("select count(*) from test1 where c1=?");
pstmt.setInt(1, 8);
ResultSet rs = pstmt.executeQuery();
```
