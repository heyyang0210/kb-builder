# 2. 测试设计

## 2.1  测试规格

### 2.1.1 场景分析

从驱动、数据库版本兼容性角度思考，用户会有以下常用场景：

（1）新驱动对应新数据库版本

（2）新驱动对应旧数据库版本，如：数据库版本未更新，用户应用程序升级，使用新驱动

（3）旧驱动对应旧数据库版本

（4）旧驱动对应新数据库版本，如：数据库版本升级， 用户应用程序未升级

（5）新旧驱动对应新数据库版本， 如：微服务场景，当有多个微服务接入时，各个服务使用驱动版本可能不一样

（6）新旧驱动对应旧数据库版本

### 2.1.1 兼容性分析和设计

主要从操作系统兼容性、新旧数据转换、应用软件兼容性等方面进行分析。

（1）操作系统兼容性主要验证各个驱动版本能在各个操作系统（操作系统版本）上运行

（2）新旧数据转换主要验证如果数据库底层存储格式改变（数据库版本），各个驱动版本表现是否一致

（3）应用软件兼容性主要验证使用数据库驱动的应用，当数据库驱动版本有变化时，是否影响到应用的运行

## 2.2 自动化分析和设计

### 2.2.1 主要场景分析

从驱动版本和数据库版本兼容性分析，主要有以下四种主要场景：

|  
|旧服务端|新服务端|
|---|---|---|
|旧驱动端|1|2|
|新驱动端|3|4|


分析这四种情况可能存在的问题：

场景1、4：属于正常情况

场景2：旧驱动端，新服务端，所有用例都能正常执行

场景3： 新驱动端，旧服务端，可能会出现旧服务端不支持新的接口，导致用例失败

### 2.2.2 自动化框架设计

#### 2.2.2.1 简单设计

针对2.2.1场景分析，自动化框架主要分为三层：

（1）部署层： 主要部署或者升级数据库

（2）用例准备层：主要安装驱动和准备用例

（3）业务层 （场景层）： 构造相关的业务场景

业务层跟用户场景有关，用户根据自己情况进行脚本编写

#### 2.2.2.2 详细设计

（1）部署层

目前支持的操作系统为：linux、windows、arm， 根据操作系统语言特性编写对应的脚本执行安装或者升级

针对支持的操作系统，分析实现难度：

x86：shell脚本

windows： 需要了解windows的语言特性

arm: 同x86

  


（2）用例准备层

用例准备层主要任务是下载驱动、安装驱动、下载对应版本用例集

下载驱动：按照命令进行下载

安装驱动： 需要了解各个驱动在各个操作上的安装命令

下载对应版本用例集： 主要利用git的版本控制能力，下载对应版本用例集

  


（3）场景层

用户按照自己场景进行编写config配置文件，如下

|[common_config]    
  #   服务端公共信息    
  server_system_type=arm    
  server_ssh_host=127.0.0.1    
  server_ssh_user=jenkins    
  server_ssh_password=citest@123    
  server_ssh_port=22    
  #   客户端公共信息    
  client_system_type=arm    
  client_ssh_host=127.0.0.1    
  client_ssh_user=jenkins    
  client_ssh_password=citest@123    
  client_ssh_port=22    
  testcase_download_url=git@git.yasdb.com:cod-x/yastest_driver.git    
  driver_type=jdbc    
  driver_testcase_name=yasdb_jdbc_test    
    
  #   服务端为  master  版本    
  [db_config]    
  db_download_url=https://jenkins.yasdb.com/packages/YashanDB/daily/master/latest/release/    
  db_branch=master    
  db_listen_addr=127.0.0.1:1688    
  db_home_path=/var/lib/jenkins/compatibility/YASDB_HOME    
  db_data_path=/var/lib/jenkins/compatibility/YASDB_DATA    
    
  #   驱动为  22.2  版本    
  [test1],driver_download_url=https://jenkins.yasdb.com/packages/YashanDB/daily/br22.2/latest/driver/    
  diver_branch=br22.2    
  git_branch=br22.2    
  #   期望用例集执行成功为  0  ，用例集执行失败为  1    
  expect_result=1    
  ...|
|---|


执行命令：

|python3 run.py -c ./config -e|
