# 1.     **概述**

支持使用yasboot命令  node config show/set/unset 查询、修改集群参数，补齐能力。

# 2.     **需求分析**

SR：    [YDBRD-13222](https://jira.yasdb.com/browse/YDBRD-13222?src=confmacro)    -  【OM】支持查看配置集群配置参数  完成

### **2.1 功能分析**

### 2.1.1 node config set

本命令用于手动更改/设置指定节点的配置。

|选项|含义|
|---|---|
|*-c, --cluster*|YashanDB的集群名（必传参数）|
|*-n,--node-id*|节点ID（例如1-1，可以通过cluster status命令查看，不需要冒号及后面的数字）（必传参数）|
|*-k, --key*|设置参数的名称（必传参数）|
|*-v, -value*|设置参数key对应的值（必传参数）|
|*-w, --nowait*|运行后不等待执行命令结果|
|*-d, --child*|展示任务以及子任务信息|
|*--disable*|屏蔽任务进度条展示|


### 2.1.2 node config show

本命令用于展示指定节点的配置信息。

|选项|含义|
|---|---|
|*-c, --cluster*|YashanDB的集群名（必传参数）|
|*-n, --node-id*|节点ID（例如1-1，可以通过cluster status命令查看，不需要冒号及后面的数字）（必传参数）|
|*-q, --query*|查询组配置中单个或多个参数（可以模糊匹配）|
|*--parameter*|配置的详情|
|*-a, -all*|查询所有参数，包括未设置的参数|


### 2.1.3 node config unset

本命令用于将指定节点的配置信息重设为初始默认值。

|选项|含义|
|---|---|
|*-c, --cluster*|YashanDB的集群名（必传参数）|
|*-n, --node-id*|节点ID（例如1-1，可以通过cluster status命令查看，不需要冒号及后面的数字）（必传参数）|
|*-k, --key*|重设参数的名称（必传参数）|
|*-w, --nowait*|运行后不等待执行命令结果|
|*-d, --child*|展示任务以及子任务信息|
|*--disable*|屏蔽任务进度条展示|


# 3.   **测试设计方法**

 1）通过等价类进行测试，选取参数进行验证包含立即生效和重启生效参数，目前参数超过一百多，无需全部覆盖；

 2）通过场景方法进行验证，覆盖节点正常场景验证，节点异常场景等验证。
