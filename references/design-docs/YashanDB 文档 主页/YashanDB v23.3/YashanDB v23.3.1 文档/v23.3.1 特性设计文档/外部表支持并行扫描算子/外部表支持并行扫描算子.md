##   [5. Detail Design（详细设计）](#5-detail-design详细设计)  

外部表只支持全表扫描，所以并行算子只对接全表扫描。

###   [5.1 外部表拆分扫描范围](#51-外部表拆分扫描范围)  

拥有segment的表（例如heap表），通过计算segment大小，划分scanRange。外部表其实就是划分外部文件的扫描区间，通过csvOpen指定并行度来拆分。计算好每一份的扫描区间，设置在range里。

```
typedef union StScanRange {
    struct {
        SegBlockLoc startLoc;
        SegBlockLoc endLoc;
    };
    struct {
        SliceBlockLoc startBlockLoc;
        SliceBlockLoc endBlockLoc;
    };
    struct {
        CodUint64 startRowId;
        CodUint64 endRowId;
    };
    struct {
        /* for external table */
        CodInt64 readStart;
        CodInt64 readEnd;
    };
} ScanRange;

```

###   [5.2 并行扫描执行](#52-并行扫描执行)  

子线程执行扫描，根据子线程id，设置对应的scanRange，执行扫描。设置scanRange过程：

- 通过并行度1打开csv 文件
- 重置csvCtrl chunks[0]的readStart，readOffset和readEnd
- 切分的slice个数可能会比并行度大，但是打开csv以及prepareExtTabScan一个子线程只需要执行一次


###   [5.3 csv文件拆分规则](#53-csv文件拆分规则)  

csvOpen的时候传入的chunkSize为0，则按照chunkSize拆分（外部表传0）：

- <=4G，chunkSize = 64M
- <=8G，chunkSize = 128M
- <=16G，chunkSize = 256M
- <=32G，chunkSize = 512M
- 大于32G，chunkSize = 1G


csvOpen的时候传入的chunkSize不为0，则按照传入的chunkSize（当前sql load会传入1G）。
