# 1. 概述

为了提升分布式行执行的能力，分布式行存查询中带有物化算子时，不在closePlan时关闭物化区，物化资源留着在释放执行资源时统一释放，实现一次物化重复扫描多次

另外本文大部分复用已有用例，故不单独输出文本用例

# 2. 需求分析

## 2.1 功能点分析

- 需要rescan的场景：  子查询、  nested loop join（分布式下做nested loop join时，右表需要加出物化算子，当且仅当执行的是全外连接，左表也加出物化算子）
- 可rescan的算子：Material、IndexScan、TableScan


|nb术语|描述|借鉴业界|参考|
|:---|:---|:---|:---|
|rescan|对于某个算子的重扫|-|  
|


  


物化区存储的数据量可能很大，为了应对内存不足的场景，物化区基于VM实现，物理内存大小由内核参数VM_BUFFER_SIZE控制

## 2.2 应用场景

- 典型场景：


子查询、  nested loop join

## 2.3 规格约束

- 分布式外部引用不能跨px
