# 1.   **概述**

       研发中心工程团队基于多年的分布式实践，在新型数据库系统中融合 shared-storage 架构和shared-nothing架构。新型数据库系统采用自研数据库引擎，基于全局 SCN 的可见性判断机制、基于页面内事务锁的并发控制机制、基于Block Level 的 MVCC 机制对多写的扩展都具备天然的优势，在面向存储这一层上，采用shared-storage 架构，通过集群方式突破单机处理瓶颈，单个集群处理能力倍数级提升，同时也提升了系统的可靠性与可用性，并使之能够适应云上部署，实现当前云厂商无法实现的多写集群技术。

    在集群之上通过shared-nothing架构将多个集群进行分布式部署，可以实现大规模的弹性伸缩，同时因为单集群处理能力和可靠性的提升，可以解决大规模分布式部署的可靠性问题，使得上层应用可以透明使用 shared-nothing 架构的部署，无需应用感知修改。

分布式支持共享集群来源于崖山立项规划，实现从无到有，满足第三方验收需求。

## 2.2 架构方案

### 2.2.1 DN实现共享集群架构

1. 只实现分布式DN组内做为一个共享集群；
1. 分布式DN组内实现不同程度的自治，CN、MN根据DN组自治程度进行适配；
1. 分布式协调（CN）原则上只管理到数据组级别。

### 2.2.2 内部通信实现

共享集群DN实例中使用两个ICS实例

- 一个是分布式模块中的ICS，进行组间通讯。通过从MN申请的全局endpoint，跟MN、CN等分布式组件通讯
- 一个是共享集群内核模块中ICS，进行组内（集群内）通讯。使用本地NodeId，跟组内其他实例通讯。


直接将两个ICS实例进行切割开有以下好处：

- 分布式模块和集群内核模块改动都不用很大
- 通讯管理变得简单，包括双方链路配置、管理比较直观


YCS不直接和DB（分布式模块或共享集群内核）通讯，基础的集群元数据信息由OM直接写入YCR。

## 2.3 安装部署

yasboot增加新的节点类型进行部署，一个DN组对应一个磁阵组。

yasboot命令package gen 新增参数--yac-dn, 如下：

```
# yasboot package de gen -h

Usages: yasboot package de gen [<flags>]

gen distributed type yasboot deploy config

Flags:
   -h,--help              Show detailed help information.
   -c,--cluster           yasdb cluster name
   -u,--username          host ssh username
      --groupname         host ssh groupname
   -p,--password          host ssh password
   -N,--no-password       ssh passwordless
      --ip                host ssh ipaddr
      --port              host ssh port
   -i,--install-path      package install path
  -su,--sudo-username     host ssh sudo username
  -sp,--sudo-password     host ssh sudo password
      --no-add-yasdba     no add user to YASDBA group(default: false)
      --boot-start-monit  boot start monit(append start command to /etc/rc.local), need sudo privilege(default: false)
      --host              host expression
   -L,--local             deploy in local host and no need install pkg(default: false)
      --ipv6              locally deploy with IPv6, default Ipv4.(default: false)
      --listen-cidr       listen cidr address, such as '0.0.0.0/0'
      --begin-port        begin port(default: 1688)
      --data-path         yasdb node data path
   -f,--force             do not check host info(default: false)
   -o,--output            output path
   -d,--deploy-mode       DE deployment mode, you can choose 'MINI' or 'NORMAL'
      --mn                distributed mn number(default: 1)
      --cn                distributed cn number(default: 1)
      --dn                distributed dn group & node number, such as '1-3'(default: 3-1)
      --yac-dn            distributed yac-dn group & node number, such as '2-2'
      --replica-cidr      replica cidr address, such as '0.0.0.0/0'
      --din-cidr          din cidr address, such as '0.0.0.0/0'
      --inter-cidr        inter connect cidr address, such as '0.0.0.0/0'
      --data              data disk path of ce
      --vote              vote disk path of ce
      --ycr               ycr disk path of ce
      --create-cgroup     create yasdb resource cgroup path(default: false)
      --cgroup-path       cgroup path(default: /sys/fs/cgroup)
      --recommend-param   enable recommend param
      --memory-limit      host memory use limit, unit is percentage(default: 80)
      --table-type        main table type, default HEAP in SE, LSC in DE
```

  


部署举例：

```
--生成部署文件
# yasboot package de gen -c yashan -u sxh -p sxh --ip 192.168.6.153,192.168.6.155 --port 22 -i /ssd_data/ --data-path /ssd_data/ --mn 3 --cn 2 --yac-dn 2-2 --data /dev/mapper/lun01-200G,/dev/mapper/lun04-200G --vote /dev/mapper/lun02-100M,/dev/mapper/lun05-100M --ycr /dev/mapper/lun03-100M,/dev/mapper/lun06-100M

--部署分布式集群环境
# yasboot package install -i ../yashandb-23.2.0.30-242-g24f7c1b-linux-x86_64.tar.gz -t hosts.toml
# yasboot cluster deploy -t yashan.toml --yfs-force-create
```
