支持sql语句中反引号的使用，与Mysql对齐

# 2. 需求分析

## 2.1 功能点分析

- 反引号（`），是为了区分MYSQL的保留字与普通字符而引入的符号。
- 常用于库名，表名，字段名（列名）
- 主要使用于：
-     1. 避免与SQL保留字冲突
    1. 当标识符包含空格、特殊字符或区分大小写的数据库中的混合大小写时

- 保留字列表：Mysql保留字列表 只要需要用到Mysql的保留字的，都需要使用反引号做区分
- 常用场景：建表的时候一般都会将表名，库名都加上反引号来保证语句的执行度


## 2.2 应用场景

- 对象名包含保留关键字以及特殊字符的场景


## 2.3 规格约束

*2.3.1 大小写敏感：*

- *MYSQL规格：MYSQL包含*  *lower_case_table_names参数，由该参数决定是否大小写敏感。使用*  *SHOW VARIABLES LIKE 'lower_case_table_names';*   查看当前取值
    - *Unix（包括Linux）下，默认值为0，表示对数据库名和表名的大小写是敏感的。*
    - *Windows下，默认值为1，表示不敏感，即在存储和查找时会将名称转换为小写。*
    - *macOS下，默认值为2，表示存储区分大小写，但在查询时会转换为小写。*
- *YASDB规格：无*  *lower_case_table_names参数，默认大小写不敏感且自动转换为大写*


*2.3.2  MYSQL sql_mode = 'ANSI_QUOTES'，SELECT @@sql_mode;查看当前取值*

- *MYSQL规格：MYSQL 设置参数  sql_mode = 'ANSI_QUOTES' 后，使用  " " 标识对象名，使用  ' ' 标识字符串*
- *YASDB 无该参数,,当前默认与MySQL  sql_mode = 'ANSI_QUOTES'时一致，后续迭代增加sql_mode参数*
