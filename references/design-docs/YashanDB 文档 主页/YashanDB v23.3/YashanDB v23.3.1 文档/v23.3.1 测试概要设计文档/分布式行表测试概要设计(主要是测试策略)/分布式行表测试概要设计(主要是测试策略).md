# 3. 规格约束

## 3.1 DDL功能约束

|功能|补充说明|
|:---|:---|
|CREATE TABLE AS|不支持通过行表创建|
|CREATE AC|分布式不支持指定AC表空间|
|MODIFY COLUMN|分布式不支持修改分布建类型|
|PARTITION TABLE|分布式一级分区只支持HASH分区，且不支持指定表空间创建分区表|
|OUTLINE / INLINE CONSTRAINT|分布式不支持外键， 唯一约束必须包含分布建|
|ADD/DROP/TRUNCATE TABLE PARTITION|增删分区以及清理分区数据只支持复制表|
|CREATE/REBUILD INDEX ONLINE|不支持|


【  **备注**  】其它对象支持能力与现有分布式下相同。

## 3.2 DML功能约束

|功能|补充说明|
|:---|:---|
|Merge into|不支持|
|Hint 指定 PARALLEL能力|不支持|
|INSERT INTO TABLE PARTITION|分布表不支持指定一级分区插入|
|INSERT ALL|多表插入|
|INSERT INTO VALUES(subquery)|不支持插入列带查询结果|
|ON DUPLICATE KEY UPDATE|不支持|
|INSERT INTO SELECT|不支持|
|INSERT INTO ... RETURNING|不支持|
|DELETE FILTER(SubQuery)|不支持Delete 跟子查询语法|
|DELETE 多表|不支持Delete 多表以及带多表关联查询|
|update 分布建|不支持|
|update 多表|不支持Update多表关联查询|
|update filter（subquery）|不支持update filter条件带子查询|
|分布式聚合操作|grouping, grouping_id, group id, grouping sets，cube，rollup|
|AC扫描|grouping, grouping_id, group id, grouping sets，cube，rollup|
|系统表和系统视图/分布式系统视图之间关联查询|不支持|
|并行查询|不支持并行查询（hash join，hash group）| 并行增强（sort）| 并行增强（窗口函数，connect by，集合操作， group concat， merge join，NL join）| Order by子查询|
|递归CTE|不支持|
|递归 [union | union all]|不支持|
|计算分布键支持多列|不支持|
|两阶段窗口函数|不支持|
|系统表或系统视图与普通表join|不支持|
|分布式系统视图与普通表join|不支持|
|条件下推（布隆过滤器）|不支持|
|ROWNUM|不支持|
|ROWID|不支持|
|CONNECT BY|不支持|
|INTERSECT | INTERSECT ALL|不支持|


## 3.3 表达式功能约束

|功能|补充说明|
|:---|:---|
|位移运算|不支持|


## 3.4 数据类型约束

|功能|补充说明|
|:---|:---|
|TIMESTAMP_TZ, TIMESTAMP_LTZ|不支持|
|BIT(n)|不支持|
|ROWID|不支持|
|UROWID|不支持|
|UDT | ADT|不支持|
|RECORD|不支持|
|ST_GEOMETRY|不支持|
