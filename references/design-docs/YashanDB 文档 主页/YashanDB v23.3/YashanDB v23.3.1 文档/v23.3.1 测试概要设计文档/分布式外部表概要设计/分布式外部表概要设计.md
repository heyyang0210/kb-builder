  #YASHAN-828 支持外部表，以外部表方式装载数据

  


复用单机：    [【YDBRD-941】外部表测试概要设计 - YashanDB - SICS-CoD Confluence (yasdb.com)](https://conf.yasdb.com/pages/viewpage.action?pageId=133580858)  

##   [1. 需求概述](https://conf.yasdb.com/pages/viewpage.action?pageId=133568047#1-%E9%9C%80%E6%B1%82%E6%A6%82%E8%BF%B0)  

需求概述：  分布式支持外部表

需求来源：长  亮

部署形态：分布式

需求场景：

长亮全都是使用外部表装载数据， 在MPP数仓模型下，使用外部数据源进行表查询和数据入库是场景操作，    
    
  （1）创建表及对应外部表    
  CREATE TABLE NATION (     
  N_NATIONKEY INTEGER NOT NULL,    
  N_NAME CHAR(25) NOT NULL,    
  N_REGIONKEY INTEGER NOT NULL,    
  N_COMMENT VARCHAR(152));

drop external table e_nation;    
  CREATE READABLE EXTERNAL TABLE e_NATION (LIKE NATION)    
  LOCATION ('    [gpfdist://10.22.82.218:8081/score1.csv](gpfdist://10.22.82.218:8081/score1.csv)    ') FORMAT 'csv';    
  （2）将外部表数据导入到对应表    
  INSERT INTO NATION SELECT * FROM e_NATION;

  


  


  


语法按照oracle语法    
    
  导入就是insert into xxx select * from    
  支持csv，text格式。分隔符按照当前支持的规格

  #YDBRD-26153 分布式支持创建外部表外部表|支持只读外部表，支持text，csv，parquet（后续），orc（后续）格式,- 外部表只读
- 外部表不支持约束
- 外部表不支持index
- 外部表不支持object type，varray，LONG类型（oracle还不支持invisible column）
- 外部表不支持lob
- 外部表不支持alter
- 外部表不能是临时表
- 外部表不支持分区表
- opaque_format_spec不会校验正确性，只有使用的时候才会校验正确性。当前版本，YashanDB不会真正去使用opaque_format_spec，也不会校验opaque_format_spec。解析外部文件使用默认行为（records delimited by newline fields terminated by ','）
- location_specifier也不会校验，只有真正使用的时候才会校验文件是否存在
- REJECT LIMIT integer， integer取值范围 [0, 100000] 
- 当数据库定义列数少于csv文件行列数，不会报错（前提是前几列对应数据类型转化不报错）。如果数据库定义列数大于csv文件行列数，会报错（增加reject limit）
