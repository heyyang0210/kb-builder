MySQL下影响charset, collation 系统参数：

字符集相关：

character_set_client

character_set_connection

character_set_results

character_set_server

character_set_database

字节序相关

collation_connection

collation_server

collation_database

### 1.2.1 charset 函数

charset 函数用来返回指定对象对应的字符集。

查看表对应的character set ： 从information.tables 表的 table_collation 字段 计算出来。

查看表的列对应的character set ：从information_schema.columns 表的  character_set_name 列获取。

### 1.2.1.1 charset 函数定义及说明

函数定义

```
CHARSET (str)

返回结果：
类型：VARCHAR ，最大长度64字节。
```

函数说明

- str 是字符串类型，则返回字符串对应的字符集，否则返回 “binary” 。
- str 是NULL时，返回“binary”。
- str是常量字符串，执行结果为 character_set_connection 参数对应的值。
- str为列名，则执行结果为列对应的字符集（不会区分具体值是否为NULL）。

使用charset

- 创建database指定charset, collation


CREATE DATABASE db_name CHARACTER SET charset_name COLLATE collation_name;

- 创建表指定charset, collation


CREATE TABLE table_name ( id int, name varchar(20) ) CHARACTER SET charset_name COLLATE collation_name;

- 创建表时指定列对应的charset, collation


CREATE TABLE table_name ( id int, name varchar(20) CHARACTER SET charset_name COLLATE collation_name) CHARACTER SET charset_name COLLATE collation_name;

- 字符串对应的charset, collation


select charset('abc'), collation('abc');

- 对字符串强制转化字符集


select charset(_utf8mb4'A'),  charset('A'),  charset(cast('A' AS CHAR CHARACTER SET gb2312)) from dual;

  


### 1.2.2 collation函数

collation 函数用来返回指定对象对应的字符序。

查看表对应的collation:  从information_schema.tables 表的字段 table_collation 获取。

查看表的字段类型对应的collation：从information_schema.columns 表的字段 collation_name 获取。

#### 1.2.2.1 collation 函数定义及说明

函数定义

```
COLLATION (str)

返回结果：
类型：VARCHAR ，最大长度64字节。
```

函数说明

- str 是字符串类型，则返回字符串对应的字符集的字符序，否则返回 “binary” 。
- str 是NULL时，返回“binary”。
- str是常量字符串，执行结果为 collation_connection参数对应的值（collation_connection 和 character_set_connection 两者是关联的，修改一个时另外一个会同步更改）。
- str为列名，则执行结果为列对应的字符序（不会区分具体值是否为NULL）。
