# 1. 概述

分区并行是基于分区表进行并行，用来提升分区执行速度；包括按分区并行以及按block并行，按分区并行当前特指hash分区并行，提高执行效率。原有并行执行拦截了带有二级分区的分区表的并行执行，本需求放开二级分区表按照一级分区并行。

## 2.1 功能点分析

- 放开二级分区并行限制
- 默认按照block并行，如果有分区，并且是hash分区，并且分区键是1列，就按照分区并行
- 支持表类型：
    - 单机列表：block并行及分区并行
    - 分布表：分区并行


## 2.2 应用场景

带二级分区大表提高查询效率

## 2.3 约束

行表二级分区不支持并行，复制表不支持并行
