# 2. 需求分析

## 2.1 功能点分析

高级包：

- HIST_CHECK.ENABLE_CHECK ：打开防篡改。
- HIST_CHECK.DISABLE_CHECK:     关闭防篡改。
- HIST_CHECK.ACHECK:   校验是否篡改(返回值:true 表示未篡改，false 表示已篡改)。


系统表：SYS.HIST_CHECK_INFO：记录表是否开启防篡改能力，及是否发生过篡改。

视图：

语法：

```
HIST_CHECK.ENABLE_CHECK (USER_NAME, TABLE_NAME);

HIST_CHECK.DISABLE_CHECK (USER_NAME, TABLE_NAME); 

HIST_CHECK.ACHECK (USER_NAME, TABLE_NAME) 
RETURN BOOLEAN; 

```

## 2.2 应用场景

- 对指定的表开启防篡改能力，会对重要数据的增删改操作记录篡改校验信息，并且可以通过接口校验是否被篡改。


## 2.3 规格约束

- 只支持单机heap表。
- 修改需求预期，接口预期和友商对齐，即校验接口返回TRUE，代表未发生篡改。
- 本需求中防篡改能力针对的是增删改操作，即INSERT DELETE UPDATE，校验仅针对这三种操作类型。
- 连续调用ENABLE_CHECK开启防篡改能力，会以第一次开启时为准。
- 当前只是先支持只读表，防篡改其他功能后续扩展。
