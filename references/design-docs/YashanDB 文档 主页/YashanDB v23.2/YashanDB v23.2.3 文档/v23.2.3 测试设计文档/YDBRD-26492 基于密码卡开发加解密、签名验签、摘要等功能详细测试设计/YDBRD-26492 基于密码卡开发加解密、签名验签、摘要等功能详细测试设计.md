# 1. 概述

加密引擎支持不同动态库/硬件加密，封装成统一的接口，对外提供统一的加解密能力

- 软件
    - openssl
    - GMSSL
- 硬件
    - PCIE

## 2.2 应用场景

用户对加密使用的动态库有需求，或者需要使用pcie密码卡加密

## 2.3 约束

- 密码卡
    - 仅在linux下可配置使用
    - 环境上必须有硬件环境
- 工具侧支持
    - c驱动及C系衍生工具
        - c驱动支持配置
    - yaspwd不可配–用不到，默认openssl

|||服务端  ENCRYPT_LIB设置为GMSSL，去除openssl库和密码卡，开启ssl|报错|
||客户端|客户端  ENCRYPT_LIB设置为openssl，去除openssl连接|报错|
|||客户端  ENCRYPT_LIB  设置为openssl，去除gmssl和密码卡连接|成功|
|||客户端  ENCRYPT_LIB设置为GMSSL，去除gmssl库连接|报错|
|||客户端  ENCRYPT_LIB设置为GMSSL，去除openssl库和密码卡连接|成功|
|||客户端  ENCRYPT_LIB设置为pcie card，不插入密码卡连接|报错|
|||客户端  ENCRYPT_LIB设置为pcie card，插入密码卡，去除openssl和gmssl库|成功|
|||客户端  ENCRYPT_LIB设置为pcie card开启ssl，插入密码卡，去除openssl和gmssl库连接|报错|
|||客户端  ENCRYPT_LIB设置为gmssl开启ssl，去除openssl库连接|报错|

||TDE|使用openssl库时插入数据，使用gmssl库时查询数据|数据查询正确|
|||使用gmssl库时插入数据，使用openssl库时查询数据|数据查询正确|
