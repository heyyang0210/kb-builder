# 2. 需求分析

## 2.1 功能点分析

1.  隐藏参数 _COLUMNAR_MAX_BULKLOAD_MEM_PERCENT调整为非隐藏参数 BULKLOAD_MAX_MEM_PERCENT

2.  新增参数 SESSION_BULKLOAD_MAX_MEM_PERCENT

3.  show parameter

v$parameter / dv$parameter

v$system_parameter / dv$system_parameter 做出对应修改

## 2.2 应用场景

场景一：

设置参数 BULKLOAD_MAX_MEM_PERCENT 较高

设置参数 SESSION_BULKLOAD_MAX_MEM_PERCENT 较高

大数据量低并发

场景二：

设置参数 BULKLOAD_MAX_MEM_PERCENT 较低

设置参数 SESSION_BULKLOAD_MAX_MEM_PERCENT 较低

大数据量高并发

## 2.3 规格约束

单任务内存配额太小，大数据量场景，内存换入换出增多

单任务内存配额太大，高并行度场景，导致总资源不足

修改参数不影响已经开始的任务

## 2.4 部署模式

单机、分布式
