# 2. 需求分析

## 2.1 功能点分析

增加 --sql 语法

|语法|作用|
|:---|:---|
|**exp --sql**   user/passward file=./out full=y|导出全库元数据信息为sql语句|
|**exp --sql**   user/passward file=./out user=user1|导出用户的元数据信息为sql语句|
|**exp --sql**   user/passward file=./out tables=user1.t1|导出指定表的元数据信息为sql语句|
|  
|  
|

1）数据迁移

2）

## 2.3 规格约束

1）权限中，对象权限，由于存在切换loginId，sql无法搞定，只能通过协议+权限。这个地方先不支持。 （角色/系统权限。可以支持）

2）导出是直接create，不是  **CREATE OR REPLACE**  ** **

3）导出用户的对象，  **是切换schema**  ，不是user.table1

4）不会补齐 相关的drop语句

5）行内外约束导出与mysql差异：     [差异](https://conf.yasdb.com/pages/viewpage.action?pageId=150633620#id-%5B23.2%5D4.1.2%E3%80%90%E6%B5%8B%E8%AF%95%E8%AE%B0%E5%BD%95%E3%80%91YDBRD19210-2%E5%AF%BC%E5%87%BA%E8%A1%8C%E5%86%85%E7%BA%A6%E6%9D%9F%E3%80%81%E8%A1%8C%E5%A4%96%E7%BA%A6%E6%9D%9F%E8%A1%8C%E4%B8%BA%E5%B7%AE%E5%BC%82)
