# 1. 概述

此文档为在过程体中嵌套声明子过程体功能详细测试设计。

# 2. 需求分析

## 2.1 功能点分析

- 子过程体可以是procedure或function，功能调研文档：    [https://conf.yasdb.com/x/JsTOC](https://conf.yasdb.com/x/JsTOC)  
- 开发设计文档：    [https://conf.yasdb.com/x/EtPOC](https://conf.yasdb.com/x/EtPOC)  
- SR:    [https://pingcode.yasdb.com/pjm/items/6611a209579a3edb84d83a3b](https://pingcode.yasdb.com/pjm/items/6611a209579a3edb84d83a3b)    ?


## 2.2 应用场景

- 过程体内定义的子过程体，在当前外场用到多处，包括procedure嵌套procedure，匿名块组合嵌套procedure等场景
- 需要关注内外层的变量调用，变量赋值，形参实参传递，类型继承等场景


## 2.3 规格约束

- 嵌套子过程的个数并没有限制，主要受资源控制。语句块的栈深度遵循过程体目前限制256层。
- 不支持嵌套子过程声明和定义分离（声明语句在PL中都还未支持）。
