# **1. 概述**

本文描述集群yasboot支持主备集群部署测试设计。

# **2. 需求分析**

共享集群已经支持一主一备甚至一主多备的场景，但是om部署的共享集群还是“单机”状态，故om需要支持共享集群的主备部署功能。

## **2.1 功能点分析**

SR链接：    [https://pingcode.yasdb.com/pjm/items/661f35a3fd997db58adb1f15](https://pingcode.yasdb.com/pjm/items/661f35a3fd997db58adb1f15)    ?    
  #YDBRD-26457 【OM】yasboot支持主备集群的部署

开发方案文档：    [OM支持集群主备部署设计方案](144137319.html)  

### 2.1.1 yasboot支持主备集群部署

通过以下命令实现：

- group参数为备集群数量


      .  /bin/y  asboot   package   ce gen --ip ip1,ip2 --cluster tt --data   /dev/  sde --vote   /dev/  sdc --ycr   /dev/  sdd --  group   N --node   1

## **2.3 规格约束**

- 1、支持一主多备集群的部署
- 2、支持同构集群复制，要求主集群和备集群的节点数对等，版本相同（非对称有另外的IR，暂无SR，先不考虑）
- 3、跟单集群保持一致


                1）备集群只有一个节点为open状态，其他节点都是started状态

                2）考虑到命令行不能太长，共享集群的ce gen命令格式跟之前保持一致，只能输入一套共享磁阵地址，其余备集群的磁阵地址需要手动修改配置文件。
