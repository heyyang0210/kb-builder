# 1. 概述

需求来源于商密认证需求，需要支持内置安全函数。

# 2. 需求分析

  [https://pingcode.yasdb.com/pjm/items/661fa0f7fd997db58adbca7d](https://pingcode.yasdb.com/pjm/items/661fa0f7fd997db58adbca7d)    ?    
  #YDBRD-26476 支持加解密内置函数

## 2.1 功能点分析

本需求实现下面接口功能。

|功能|设计表现|设计说明|
|:---|:---|:---|
|开机自测试|1）加密算法（签名验签SM2/SM3和加密解密SM4）自测试，,2）软件完整性自测试。,3）从开机日志和显示器打印出过程和结果|1. 新增  SMM_ENABLE 参数，重启生效；
1. 日志中打印检测过程和结果。
|
|条件自测试|select crypt_selftest('sm2') from dual;,select crypt_selftest('random',10000) from dual;|【原始需求】,第一个参数是类型，包括：'SM2', 'SM3', 'SM4', 'random', 'integrity', 'SM3-HMAC', 'sm2keypair'。,当第一个参数是'random'，第二个参数表示随机数的长度，单位是位（bit）;,当第一个参数是‘sm2keypair’，第二个是HEX格式的公钥（长短格式都行），第三个是HEX格式的私钥（长短格式都行）,【本次实现】,因为其它类型已经实现，本次只实现random,当第一个参数是'random'，第二个参数表示随机数的长度，单位是位（bit），最小8位，最长125000位。;,返回：字符串信息。|
|执行归零|通过sql命令 select SECURITY_CLEAR_CSP()  from dual，,安全的清除内存中的CSP参数|执行归零需要进行数据库安全管理员身份验证,返回：字符串信息。Clear all keys successfully|
|显示模块版本号|通过sql命令 select SECURITY_MOD_VERSION() from dual，,显示模块版本号（数据库版本号）|显示字符串格式：崖山数据库管理系统 密码模块 V23|
|显示状态|通过sql命令select SECURITY_MOD_STATUS() from dual，显示状态：,1）是否进入核准工作模式状态。|返回：字符串信息。“  核准模式状态”|

# 3. 详细测试设计

## 3.1 测试设计方法

采用遍历和等价类方法验证函数。

|测试对象|入参验证|预期结果|
|---|---|---|
|SMM_ENABLE参数|on，off|配置成功|
||null，'', 其它值|报错|
|crypt_selftest(参数1，参数2，参数3)|参数1：'random', 参数2：8位bit|输出正常|
||参数1：'random', 参数2：100位bit|输出正常|
||参数1：'random', 参数2：  125000  位bit|输出正常|
||参数1：'sm2',  参数2：100位bit|报错|
||参数1：'test1', 参数2：100位bit|报错|
||参数1：'random', 参数2：7位bit|报错|
||参数1：'random', 参数2：  125001  位bit|报错|
|SECURITY_CLEAR_CSP()|无入参|Clear all keys successfully|
||null，'' 空字符串|报错|
||其它任意值|报错|
|select SECURITY_MOD_VERSION()|无入参|崖山数据库管理系统 密码模块 V23|
||null，'' 空字符串|报错|
||其它任意值|报错|
|SECURITY_MOD_STATUS()|无入参|核准模式状态|
||null，'' 空字符串|报错|
||其它任意值|报错|
