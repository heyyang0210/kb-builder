##   [1. Overview（概述）](https://conf.yasdb.com/pages/viewpage.action?pageId=133584111#1-overview%E6%A6%82%E8%BF%B0)  

创建OBJECT类型时可以指定NOT FINAL选项，创建一个超类型（supertype，或者基类型）。然后可以通过UNDER创建超类型的子类型（subtype、承类型）。

子类型会继承超类型（父类型）的属性和方法，另外可以创建只属于自己的属性和方法，可以通过OVERRIDING语法重写超类型方法的实现。

（同名方法的重载不支持）

  


继承的一个特点是：可以在超类型实例上存储子类型的数据。（  **本次实现**  ）。但作为超类型时还是只能方法超类型本身的属性和方法。

比如对于下面的例子。A类型的变量，实际数据可能是A、AA、AC、ACA、ACB。即使实际数据类型不一样，因为都包含基类型的数据，都可以作为类型A使用。

如果想使用A变量实际的数据，可以用TREAT函数（  **本次实现**  ）。

如果想判断A变量的实际数据，可以用IS OF typAe Condition。  **不转测**

### 2.3 重写overloading

MEMBER方法默认是NOT FINAL的，可以进行重写。

调用方法时，优先当前定义类型的方法，方法的SELF变量是当前类型。

当调用父类型的方法时，SELF变量是对应的父类型，数据是当前类型。

  


### 2.4  特殊调用语句

发现oracle支持以下两种调用语法，计划不实现，外场遇到建议改写。

改写1：天然支持。

vperson person_typ;

vperson := myvar;

vperson.show();

  


改写2：需要验证。

TREAT(myvar AS person_typ).show

```
DECLARE
myvar student_typ := student_typ(100, 'Sam', '6505556666', 100, 'Math');
name VARCHAR2(100);
BEGIN
name := (myvar AS person_typ).show; --Generalized invocation
DBMS_OUTPUT.PUT_LINE(name);
DBMS_OUTPUT.PUT_LINE(myvar.show);
END;
/

DECLARE
myvar2 student_typ := student_typ(101, 'Sam', '6505556666', 100, 'Math');
name2 VARCHAR2(100);
BEGIN
name2 := person_typ.show((myvar2 AS person_typ)); -- Generalized expression
DBMS_OUTPUT.PUT_LINE(name2);
```

### 概要设计方案：

超类型数据结构。

数据结构不变。super类型中多的variant中保持真实数据的值。

  


子类型：

1. 子类型发生DDL时递归获取父类型的X锁，结束后会失效父类型的UdtDict。
1. 子类型CREATE时也递归获取父类型的X锁。
1. **UdtDict上记录subTypes的List，编译时递归编译子类型，子类型编译失败在list中删掉。**
1. **父类型DDL后，子类型因为依赖父类型失效UdtDict。**


  


子类型的并发：

本身还是type的并发，增加了父类型的失效，  代码上注意并发情况报错  。

  


  


赋值super := sub;

TREAT (super AS SUBTYPE)

  


方案1：super类型的variant中直接按sub类型存储  **。**   目前方案

单功能上没理论问题，类型定义和值分离。

赋值时直接按sub的格式copy。

TREAT时，理论也是SUBTYPE的值，也直接copy。

问题：pushBlockVar时中要push最大个数的内存。在keep、out、return时候可能出现未知问题。使用单独的appHeap内存。

  


函数适配：

绑定参数：把value换个内存复制一份。方案1下不需要处理。

anlCopyRecordValue、soCopyRecordValue

初始化：分配初始化内存。方案1下不需要处理，按定义进行分配。

soInitRecordReturn、soInitRecordArgument、

soPushRecordVar：标量有内存。

soInitPackageUdtVar、

soInitVarrayNullMember：标量无内存。

复制：存在子类型往父类型复制的过程，需要适配。如果是子类型复制场景，按子类型定义用动态内存重新初始化dst的内存。

soSetRecordDefaultVar、soSetRecordAdtValue：需要分配出标量最大长度。

soSetPackageRecordDefaultVar：需要分配出标量最大长度。

soSetVarrayMemberRecord：往varray成员复制，之前必然被初始化为NULL或正常值。参考varray初始化，按src定义重新只分配Variant内存。

soVarrayCopyRecordMember：整个varray复制，存在子往父场景。当此进行内存分配，且src必然是null流程或set流程设置过count的，所有可以直接按src的值进行copy，只需要把udtDef换成src的。

  


出参、返回值：    
  soPushReturnLenRecord

soApplyRecordReturn
