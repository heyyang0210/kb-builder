##   [1. 总述](#1-总述)  

该设计文档设计了在crab支持了GB18030字符集的基础上，对支持字符串参数的相关函数做GB18030字符集的适配与支持，主要包括字符串函数和时间日期函数，当然还有一些其他函数。

##   [3. 规格与约束](#3-规格与约束)  

规格方面是与行执行保持一致的，函数在GB18030字符集下的计算结果不应与行执行出现差异。

##   [4. 特性](#4-特性)  

###   [4.1 特性设计](#41-特性设计)  

1、关于transform中的代码，每个cast成字符串的地方，都需要调整代码，要cast成指定字符集的字符串。 

2、对于Clob而言，都是对[u8]进行的操作，不需要做额外的处理。

3、bind的时候可以对字符集进行match生成指定字符集的BoundExpr；也可以在evaluate的时候再进行match。

CodResult bifExecChr(AnlStmt* stmt, ExprNode* func, Variant* retValue)
{
    Expr*    arg = func->args->head;
    Variant  v1;
    CodChar* buf = NULL;
    CodInt64 n;
    EXEC_ARG_EXPR(stmt, arg, &v1);
    if (v1.isNull) {
        varAsNull(retValue, DTYPE_VARCHAR);
        return COD_SUCCESS;
    }
    COD_CALL(execVarConvertSafe(stmt, &v1, DTYPE_NUMBER));
    CodNumber temp = v1.vNumber;
    COD_CALL(codNumberToInt64FloorOrCeil(&temp, &n, COD_FALSE));
    if (n < 0 || n > COD_MAX_UINT32) {
        CodText errText;
        COD_SYNTAX_CALL(varInfoToText(stmt, &v1, &errText), func->pos);
        COD_SYNTAX_ERROR(func->pos, ERR_ANS_EXEC_ARUMENT_OUT_OF_RANGE, T2S(&errText));
        return COD_ERROR;
    }

    // make sure that n can be represented by one byte
    n &= COD_MAX_UINT8;
    // chr function do not support extended ascii code (128-255)
    if (n > ANL_MAX_BASIC_ASCII_CODE) {
        COD_SYNTAX_ERROR(func->pos, ERR_ANS_EXEC_PARTIAL_MULTIBYTE_CHAR);
        return COD_ERROR;
    }
    COD_CALL(anlPush(stmt, 1, &buf));
    buf[0] = (CodChar)n;
    retValue->type = DTYPE_VARCHAR;
    retValue->isNull = COD_FALSE;
    retValue->vText.len = 1;
    retValue->vText.str = buf;
    anlPop(stmt);
    return COD_SUCCESS;
}

CodInt64 gb18030TextInText(const CodText* subText, const CodText* text, CodInt64 startPos, CodUint64 nth)
{
    if (COD_UNLIKELY(subText->len == 0 || text->len < subText->len)) {
        return -1;
    }

    if (startPos < 0) {
        return gb18030TextBackIn(subText, text, startPos, nth);
    }

    CodUint32 tLen = (CodUint32)gb18030Length(text);
    CodUint32 sLen = (CodUint32)gb18030Length(subText);
    CodUint64 occurs = 0;
    CodUint64 pos = startPos;
    CodText   currText = *text;

    while (pos + sLen <= tLen) {
        CodUint64 offset = gb18030CharPos(text, (CodUint32)pos);
        if (offset >= COD_MAX_INT32) {
            return -1;
        }
        currText.str = text->str + (CodInt32)offset;
        currText.len = text->len - (CodInt32)offset;

        if (gb18030TextHeadMatched((&currText), subText)) {
            occurs++;
            if (occurs == nth) {
                return (CodInt64)pos;
            }
        }
        pos++;
    }

    return -1;
}

void gb18030Substr(const CodText* text, CodUint32 pos, CodUint32 size, CodText* subText)
{
    CodUint64 charCount = 0;
    CodUchar* subStrStart = NULL;
    CodInt32  mbLen;
    CodUchar* cur = (CodUchar*)text->str;
    CodUchar* end = (CodUchar*)text->str + text->len;

    if (COD_UNLIKELY(size == 0)) {
        subText->str = NULL;
        subText->len = 0;
        return;
    }

    while (cur < end) {
        if (charCount == pos) {
            subStrStart = cur;
        } else if (charCount == (CodUint64)pos + (CodUint64)size) {
            subText->str = (CodChar*)subStrStart;
            subText->len = (CodUint32)(cur - subStrStart);
            return;
        }
        mbLen = isGb18030Char(cur, end);
        if (COD_LIKELY(mbLen > 0)) {
            cur += mbLen;
        } else {
            cur++;
        }
        charCount++;
    }
    if (charCount == pos && subStrStart == NULL) {
        subStrStart = cur;
    } else if (charCount == (CodUint64)pos + (CodUint64)size) {
        subText->str = (CodChar*)subStrStart;
        subText->len = (CodUint32)(cur - subStrStart);
        return;
    }
    if (subStrStart == NULL) {
        subText->str = NULL;
        subText->len = 0;
        return;
    }
    subText->str = (CodChar*)subStrStart;
    subText->len = (CodUint32)((CodUchar*)(text->str + text->len) - subStrStart);
}

**时间日期函数：**

行执行的时间日期函数主要就是直接使用了convert来将字符串转成时间日期类型，而字符串转成时间日期类型时并没有用到特定字符集相关内容，除非用到了compare，才会有字符集，遇到那种trim的接口都是直接用的asciiTrim接口（去空格）。

列执行在将字符串解析成相应时间日期的时候，实际上本身也是对[u8]进行的操作，所以这块很统一，只需要增加parse的[u8]接口就可以了。（有些小地方需要用到trim和compare的，这些可以使用对应字符集接口）

##   [5. Testcases（自测用例）](#5-testcases自测用例)  

自测用例包括ut和regress，核心部分是ut，因为regress没法上库，但需要本地构造用例。

1.覆盖类型

- 对于一元表达式，则是覆盖StringType(GB18030)，FixedStringType((GB18030, len))。
- 对于二元及多元表达式，需要覆盖StringType(GB18030), FixedStringType((GB18030, len))，以及这两个类型的组合、与其他类型的组合。


2.字符覆盖

- 覆盖1、2、4字节字符。
- 不同字节字符的组合。
- 覆盖大小写的字符。
