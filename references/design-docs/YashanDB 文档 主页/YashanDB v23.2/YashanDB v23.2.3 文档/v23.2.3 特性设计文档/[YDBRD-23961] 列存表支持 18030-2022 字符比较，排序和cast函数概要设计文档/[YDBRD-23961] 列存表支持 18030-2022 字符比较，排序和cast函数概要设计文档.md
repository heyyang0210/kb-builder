##  1. 总述

YashanDB行存执行允许  服务端  和  客户端  的字符集设置为GB18030，且按照  GB18030-2022标准  实现达到  级别3  。

  [[YDBRD-19655] 分布式数据库内核支持字符集(GB18030-2022) - SICS-CoD Jira (yasdb.com)](https://jira.yasdb.com/browse/YDBRD-19655)  

现行存已支持GB18030字符集，列存目前只支持UTF8字符集，非UTF8字符集提前报错，现需要列存表支持18030-2022字符集。

本文档实现18030字符集的比较，排序以及对应字符集和其他类型的相互转换（cast）功能。

二元比较框架：BinaryScalarEvaluator。

```

    &self,
    left: L::Native<'a>,
    right: R::Native<'a>,
```

BinaryScalarEvaluator默认要为新增VarString和FixedString实现Order，而默认的实现有限定for<'a> L::Native<'a>: Order<R::Native<'a>, Error = std::convert::Infallible>, 而RStr并不带有字符集信息无法实现Order：

```
pub trait Order<Rhs: ?Sized> {
    type Error: Into<Error> + Debug;

    /// Less than
    fn lt(&self, other: &Rhs) -> std::result::Result<bool, Self::Error>;

    /// Less than or equal
    fn le(&self, other: &Rhs) -> std::result::Result<bool, Self::Error>;

    /// Greater than
    fn gt(&self, other: &Rhs) -> std::result::Result<bool, Self::Error>;

    /// Greater than or equal
    fn ge(&self, other: &Rhs) -> std::result::Result<bool, Self::Error>;

    /// Equal
    fn eq(&self, other: &Rhs) -> std::result::Result<bool, Self::Error>;

    /// Not equal
    fn ne(&self, other: &Rhs) -> std::result::Result<bool, Self::Error>;
}
```

解决方案如下：

1. 新增new_bound_string_scale_compare()以及对应表达式宏为VarString和FixedString单独实现比较。
1. 将StringType和FixedStringType的Native定义为新的类型，可以携带字符集信息。
1. 由于行存目前基本上都是使用字节排序，因此列存可以不用带字符集信息直接对RStr实现相关比较。
