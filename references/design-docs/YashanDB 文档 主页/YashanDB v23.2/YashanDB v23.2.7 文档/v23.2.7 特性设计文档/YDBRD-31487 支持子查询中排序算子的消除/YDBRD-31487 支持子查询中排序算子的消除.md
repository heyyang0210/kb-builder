  *#YDBRD-31487 支持子查询中排序算子的消除*

##   [1. 总述](https://conf.yasdb.com/pages/viewpage.action?pageId=150625866&moved=true#1-%E6%80%BB%E8%BF%B0)  

父查询存在属性不需要子查询投出来有序结果时，可将该属性传递给子查询，对子查询中的order by进行优化。即父查询不关心下层投上来的数据是否有序  。该需求优化以下两种场景：

1）父查询包含汇聚算子

2）父查询投影列全为常量

3）本需求主要优化from子查询，其余子查询中的order by优化参考    [子查询order by优化设计方案 - 谭思宇 - SICS-CoD Confluence (yasdb.com)](https://conf.yasdb.com/pages/viewpage.action?pageId=109585658)

##   [2. 接口](https://conf.yasdb.com/pages/viewpage.action?pageId=150625866&moved=true#2-%E6%8E%A5%E5%8F%A3)  

CodBool ignoreSort

```
typedef struct StLogiReqdProp {
ObjectArray* optFilter; // optional filter. for filters which are generated by other filters or exprs, only is not null, or and comparison.
CodBool ignoreSort; // optmz sort
CodUint8 unused[5];
} LogiReqdProp;
```

##   [3. 规格与约束](https://conf.yasdb.com/pages/viewpage.action?pageId=163003183#id-谓词扩展-规格)  

- 父查询/子查询中出现 rownum、 limt 、offset 、窗口函数时，from子查询的order by 不可消除
- 父查询的投影列为 汇聚函数或全常量时，from子查询的 order by 可消除
- 父查询的投影列包含 汇聚函数和正常列时，from子查询的 order by 可消除
- from子查询内 join，子查询的 order by可消除
