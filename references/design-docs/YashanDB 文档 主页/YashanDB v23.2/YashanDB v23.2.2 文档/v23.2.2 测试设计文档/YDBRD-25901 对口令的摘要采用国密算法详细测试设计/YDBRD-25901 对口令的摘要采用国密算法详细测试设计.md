# 1. 概述

口令加密算法满足国密算法，用户创建、登录和修改密码支持使用sm3国密算法

# 2. 需求分析

  #YDBRD-25901 【安全】对口令的摘要采用国密算法

设计文档：    [YDBRD-29781 口令加密算法满足国密算法设计文档](147776582.html)  

## 2.1 功能点分析

- yaspwd增加命令行参数password_hash_method


|参数|含义|取值范围|默认值|备注|
|---|---|---|---|---|
|password_hash_method|生成密码时采用哪种摘要算法|[sha256，sm3]|sha256|若指定为sm3时，则yaspwd在生成密码时，不仅生成sha256算法的摘要，同时生成sm3算法的摘要|


  


二者保存时使用分号分隔，类似如下：

S:D657791C7B9D7BB78D50AC08AD267A1107A1DE990B26F845A8AC673AB25E;G:AF6EE82A6044F3F1C2BF57C452E0C2F70C76544D3D3AC7282736D6513FC667A45FE8DB1C9DABEB0F59876421BA2CCAA

- yasdb新增配置参数  password_hash_method，password_login_min_version


password_hash_method  取值范围为[sha256, sm3]，默认为sha256。在用户配置了password_hash_method为sm3之后，在创建用户、修改用户密码等场景时，需要默认生成sha256和sm3两种方式的密码。

password_logon_min_version取值范围为[plain, sha256, sm3]，默认为plain。在用户配置了password_login_min_version为sm3之后，禁止使用sha256方式登录。  起库没有加载到ssl库是否报错：1.现有数据文件有ssl加密，重启实例时没有加载库会报错 2.可以通过参数设置没有加载ssl库也可以起库   ssl库是否加载交叉测试

- 创建用户


CRETAE USER XXX IDENTIFIED BY XXX： 使用明文密码创建用户，在用户配置了password_hash_method为sm3之后，此时需要对用户密码生成SHA256和SM3两种算法格式的密码。

CRETAE USER XXX IDENTIFIED BY VALUES XXX： 使用密文密码创建用户，此时按照指定的格式存储。需要对密码进行格式的合法性效验。

- 修改用户


ALTER USER XXX IDENTIFIED BY XXX： 使用明文密码修改用户密码，此时需要对用户密码生成SHA256和SM3两种算法格式的密码。

ALTER USER XXX IDENTIFIED BY VALUES XXX： 使用密文密码修改用户密码，此时默认用户指定的密文密码是SM3格式的。

修改密码后会将原密文清空然后储存新密文

- 创建数据库


使用create database创建数据库时，  如果指定了USER SYS选项  ，需要为SYS用户生成SHA256和SM3两种算法的密码摘要。

会覆盖系统表，会覆盖密码文件。

- 登录协议


登录协议交互过程中的AckLoginKey新增一种加密类型，用来表示服务端要求客户端加密密码使用的算法。

  


## 2.2 应用场景

需要使用国密算法对口令加密，提高安全性
