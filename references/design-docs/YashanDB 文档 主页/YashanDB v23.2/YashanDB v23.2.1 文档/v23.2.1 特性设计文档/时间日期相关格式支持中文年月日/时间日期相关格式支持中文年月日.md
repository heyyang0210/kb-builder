#   [YDBRD-14171: DATE_FORMAT支持中文](#ydbrd-14171-date-format支持中文)  

IR链接：    [https://jira.yasdb.com/browse/YDBRD-12989](https://jira.yasdb.com/browse/YDBRD-12989)     SR链接：    [https://jira.yasdb.com/browse/YDBRD-14171](https://jira.yasdb.com/browse/YDBRD-14171)  

##   [1. Overview（概述）](#1-overview概述)  

时间日期相关格式支持中文年月日，支持to_date、to_char函数把字符类型'yyyy年mm月dd日'转为日期类型，支持date_format包含中文。

##   [2. Features（功能特性）](#2-features功能特性)  

默认时间日期格式date_format可以设置为 'yyyy"年"mm"月"dd"日"'，to_date和to_char如果没有输入日期格式，则匹配默认时间日期格式；to_date和to_char函数时间日期格式参数也可以使用双引号括起年月日字符。

|SQL|解释说明|
|---|---|
|alter session set date_format = 'yyyy"年"mm"月"dd"日"';|会话级别设置时间日期格式|
|alter system set date_format = 'yyyy"年"mm"月"dd"日"';|数据库级别设置时间日期格式|
|select to_char(sysdate,'YYYY"年"MM"月"DD"日"') from dual;|sysdate按照date_format格式输出并和第二个format参数匹配后转化为字符串输出|
|select to_date('2021年','YYYY"年"') from dual;|todate的srcStr和format格式匹配并输出|


###   [2.1基本场景](#21基本场景)  

```
 alter session set nls_date_format = 'yyyy"年"mm"月"dd"日"'
SQL&gt; select sysdate from dual;

SYSDATE
--------------
2023年07月27日


SQL&gt; select to_char(sysdate,'YYYY"年"MM"月"DD"日"') from dual;

TO_CHAR(SYSDATE,'YYYY"年"MM"月"DD"
----------------------------------
2023年07月27日


SQL&gt;  select to_date('2012年','yyyy"年"') from dual;

TO_DATE('2012
--------------
2012年07月01日

SQL&gt;

```

###   [2.2 set date_format 其他场景](#22-set-date-format-其他场景)  

|SQL|sysdate值|结论|
|---|---|---|
|alter session set nls_date_format = 'yyyy"年""月"dd"';|2023年月27|在最后只有一个双引号也没关系，双引号内容原样输出|
|alter session set nls_date_format = 'yyyy"年""月dd"';|2023年月dd|月前面的双引号跟最后双引号括起来内容原样输出|
|alter session set nls_date_format = 'yyyy"年"dd"mm';|2023年27mm|最后只有一个双引号时，后面内容也原样输出|


###   [2.3 to_char其他场景](#23-to-char其他场景)  

|SQL|结果|结论|
|---|---|---|
|select to_char(sysdate,'YYYY"年"MM""DD""') from dual;|2023年0727|双引号都是空串，内容原样输出|
|select to_char(sysdate,'YYYY"年"MM"aaaa"DD""') from dual;|2023年07aaaa27|双引号内容原样输出|
|select to_char(sysdate,'YYYY"年"MM"aaaa"DD"aaaa') from dual;|2023年07aaaa27aaaa|最后只有一个双引号时，后面内容也原样输出|

##   [4. Limitations（功能限制）](#4-limitations功能限制)  

- 双引号内侧存在空格，anchorbase在比较前trim掉格式中前后的空格，trim掉srcStr左侧的空格。oracle会trim格式前侧空格，保留后侧空格并比较。


|SQL|oracle结果|yasdb结果|
|---|---|---|
|select to_date('2021年','yyyy"年 "') from dual;|报错|执行成功|
|select to_date('2021 年','yyyy"年"') from dual;|报错|执行成功|
|select to_date('2021年 ','yyyy"年    "') from dual;|报错|执行成功|
|select to_date('2021  年 ','yyyy"年 "') from dual;|报错|执行成功|


- 双引号外侧的分隔符互相兼容，和没有双引号时处理逻辑一样。


|SQL|oracle结果|yasdb结果|
|---|---|---|
|select to_date('202101-01日/','yyyymm\dd"日"-') from dual;|报错|2021-01-01|
|select to_date('20210101日','yyyymmdd-"日"') from dual;|报错|2021-01-01|
|select to_date('20210101','yyyymmdd-') from dual;|2021-01-01|2021-01-01|
|select to_date('2021年','yyyy"年" ') from dual;|报错|2021-07-01|


- fmt多余部分的分隔符和双引号括起的内容以及单个双引号后面所有的字符都可以兼容


|SQL|oracle结果|yasdb结果|
|---|---|---|
|select to_date('2021年0101日','yyyy"年"mmdd"日""123"') from dual;|报错|2021-01-01|


- 双引号外侧空格处理，oracle处理逻辑和在双引号内部的逻辑保持一致，fmt字符后侧空格需要和srcStr匹配；anchorbase对于双引号外侧空格当作分隔符处理，允许fmt有多余分隔符。


|SQL|oracle|yasdb|
|---|---|---|
|select to_date('2021年','yyyy"年" ') from dual;|报错|执行成功|
|select to_date('2021年','yyyy  "年"') from dual;|执行成功|执行成功|


- yy后跟双引号，对应srcStr有效长度取2和当前连续数字长度的最小值。


|SQL|oracle|anchorbase|
|---|---|---|
|select to_date('112021年', 'mmyy"21年"') from dual;|2020-11-01|2020-11-01|
|select to_date('1120233年', 'mmyy"3年"') from dual;|2023-11-01|报错|
|select to_date('11203年', 'mmyy"年"') from dual;|0203-11-01|报错|
