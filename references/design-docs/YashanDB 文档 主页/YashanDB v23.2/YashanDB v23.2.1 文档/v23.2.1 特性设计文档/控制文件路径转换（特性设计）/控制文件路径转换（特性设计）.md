#   [1.概述(OverView)](#1概述overview)  

```
  数据库整体拷贝到其它路径后，需要修改控制文件中存储的文件绝对路径，使得数据库可以在新的路径正常启动、运行

```



#   [2.功能特性(Features)](#2功能特性features)  

```
  数据库处于nomount状态时修改控制文件中的数据文件、重做日志文件、bucket文件以及归档日志文件的绝对路径

```

#   [3.接口(InterFaces)](#3接口interfaces)  

```
` ALTER&nbsp; DATABASE CONVERT FILENAME [INCLUDING ARCHIVELOG]; `

指定INCLUDING ARCHIVELOG后会转换归档日志路径，默认不转换归档日志路径

```

#   [4.功能限制(Limitations)](#4功能限制limitations)  

- 必须在NOMOUNT状态下执行路径转换语句
- 控制文件参数可以不配置或配置为新的控制文件路径
- 三个文件路径转换参数都需要正确配置


#   [5. 详细设计(Detail design)](#5-详细设计detail-design)  

- 加载控制文件
- 根据是否开启双写转换双写文件路径，使用数据文件转换参数进行转换
- 根据是否指定INCLUDING ARCHIVELOG对归档日志进行路径转换，先获取归档日志的相对路径，将该路径拼接到默认的归档路径下
- 根据数据文件路径转换参数转换数据文件路径
- 根据REDO文件路径转换参数转换REDO文件路径
- 根据BUCKET路径转换参数转换BUCKET路径
- 释放内存中加载的控制文件内容
- 所有文件路径转换都会立即进行持久化，打开数据库时会重新加载最新的、转换过所有文件路径的控制文件
