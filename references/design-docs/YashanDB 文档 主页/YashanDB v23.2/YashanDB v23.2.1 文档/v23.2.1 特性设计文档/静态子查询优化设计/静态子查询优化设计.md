##   [2. Features（功能特性）](#2-features功能特性)  

实现子查询的shared算子，实现同一节点多处使用一个子查询的结果。

- 只计算一次，将结果保存在共享位置
- 各个地方通过自己的position设置要读取的位置


支持场景包括并行的子查询。

（之前并行子查询内部是通过broadcast来改写的，通过channel来发送给各个线程，可能出现阻塞）

实现阻塞的ColumnSetStore读写。

###   [5.1 Data Structures & Flow（数据结构与流程）](#51-data-structures--flow数据结构与流程)  

####   [结构设计](#结构设计)  

相同id的shared子查询算子共享child cursor和结果column set（或者column set store）；

相同id的shared子查询算子内部有一个引用计数，用来确定子查询是否是共享的；

每个算子有本地的结束标志和位置，共享资源也有结束标志和位置；

####   [适配流程](#适配流程)  

在转换子查询时，创建新的shared子查询算子，引用计数设为当前并行数，并且和子查询表达式一并存入PlanContext中；

再次转换相同id的子查询时，从PlanContext中找到表达式和引用计数，如果不是投影，则引用计数增加当前并行数；

如果引用计数不为1，则当前子查询是shared子查询；

####   [执行流程](#执行流程)  

plain子查询

- 第一个拿到锁的线程执行
    - 从child cursor拿数据
    - 拿到超过一行的数据则报错
    - 执行完成后将结果保留下来
    - 本地标记为结束，资源标记为结束
- 其它线程执行时
    - 直接拿结果
    - 本地标记为结束


exists子查询

- 第一个拿到锁的线程执行
    - 从child cursor拿数据
    - 如果有column set存在有效行，则保留下来
    - 本地标记为结束，资源标记为结束
- 其它线程执行时
    - 直接拿结果
    - 本地标记为结束


any/all子查询

- 拿到锁的线程执行
    - 如果本地当前位置小于远程资源的位置，则从当前远程资源的本地当前位置中直接获取数据，增加本地的位置
    - 否则本地当前位置等于远程资源的位置
        - 如果远程资源标记为结束，则本地标记为结束
        - 否则从child cursor中拿数据
            - 拿到数据存到远程资源中，增加本地的位置和远程资源的位置
            - 拿到空则结束，本地标记为结束，资源标记为结束


####   [rescan](#rescan)  

将本地的结束标志和位置恢复到默认。

####   [finish](#finish)  

因为涉及物化，如果远程资源未标记为结束，则继续执行直到远程资源标记为结束。

####   [部分代码](#部分代码)  

```
#[derive(Debug, Clone, PartialEq)]
struct SharedSubqueryOperator {
    subquery_id: u16,
    child: BoxedOperator,
    cursor: SharedSubqueryCursor,
    material_quota_id: MaterialId,
}

impl SharedSubqueryResource {
    fn try_new(
        cursor: Box&lt;dyn Cursor&gt;,
        ctx: Arc&lt;dyn Context&gt;,
        material_quota_id: usize,
    ) -&gt; crab::error::Result&lt;Self&gt; {
        let operator_quota = ctx.stage_quota().get_operator_quota(material_quota_id)?;
        let col_set_store = ColumnSetStore::new(ctx, cursor.schema().clone(), operator_quota);
        Ok(Self {
            cursor,
            col_set: None,
            col_set_store,
            col_set_num: 0,
            finish: false,
        })
    }
}

struct SharedSubqueryCursor {
    resource: Arc&lt;Mutex&lt;Option&lt;SharedSubqueryResource&gt;&gt;&gt;,
    schema: Arc&lt;Schema&gt;,
    is_shared: Arc&lt;AtomicBool&gt;,
    position: usize,
    finish: bool,
    is_one_row: bool,
}

impl Cursor for SharedSubqueryCursor {
    ...

    #[inline]
    fn next(&amp;mut self) -&gt; crab::error::Result&lt;Option&lt;ColumnSet&gt;&gt; {
        let mut resource = self.resource.lock();
        let resource = resource
            .as_mut()
            .ok_or(crab::error::Error::OperatorBindError(
                "shared subquery have no child".try_to_string()?,
            ))?;
        if !self.is_shared.load(Ordering::SeqCst) {
            resource.cursor.next()
        } else if self.is_one_row {
            if resource.finish {
                Ok(resource.col_set.clone())
            } else if resource.col_set.is_some() {
                Err(crab::error::Error::ExprEvaluateError(
                    "plain subquery returns multiple rows".try_to_string()?,
                ))
            } else {
                loop {
                    match resource.cursor.next() {
                        Ok(None) =&gt; {
                            resource.finish = true;
                            break;
                        }
                        Ok(Some(col_set)) =&gt; {
                            let valid_count = col_set.valid_count();
                            match valid_count {
                                0 =&gt; continue,
                                1 if resource.col_set.is_none() =&gt; resource.col_set = Some(col_set),
                                _ =&gt; {
                                    return Err(Error::ExprEvaluateError(
                                        "plain subquery returns multiple rows".try_to_string()?,
                                    ))
                                }
                            }
                        }
                        Err(e) =&gt; {
                            resource.finish = true;
                            return Err(e);
                        }
                    }
                }
                Ok(resource.col_set.clone())
            }
        } else {
            ...
        }
    }

    ...
}

```
