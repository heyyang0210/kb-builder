# 场景

1. 分区表
1. 分区数量多
1. 各个分区内数据多
1. 没统计信息或者统计信息失效，且开启动态收集OPTIMIZER_DYNAMIC_SAMPLING


# 原因

若开启动态采样，分区表在每个分区下都会采集对应的block数。

例如OPTIMIZER_DYNAMIC_SAMPLING=2，整体上整个分区表应该采集64个block，但实际上是每个分区都至少采了64个block（如果分区block数小于128个还会全采）。

# 修改

1.根据动态采样级别确定要采样的block数target_blocks

2.遍历每个分区

  2.1 如果剩余采样的block数为0，则退出

  2.2 如果该分区block小于剩余采样的block，则全采

  2.3 否则采剩余block数

# 例子

```
drop table t2;
create table t2(c1 int, c2 number(25,6), c3 varchar(100), c4 bigint, c5 char(100)) partition by list(c1) (partition p1 values(1), partition p2 values(default));

BEGIN
  for i in 1..10000 LOOP
    insert into t2 values(1, i, i, i, i);
  end loop;
  commit;
end;
/

SET SERVEROUTPUT ON

BEGIN
  for i in 2..128 LOOP
    for j in 1..10000 LOOP
      insert into t2 values(i, j, j, j, j);
    end loop;
    commit;
    DBMS_OUTPUT.PUT_LINE('alter table t2 split partition p' || i || ' values(' || i || ') into (partition p' || i || ', partition p' || i+1 || ')');
    EXECUTE IMMEDIATE 'alter table t2 split partition p' || i || ' values(' || i || ') into (partition p' || i || ', partition p' || i+1 || ')';
  end loop;
end;
/

set timing ON
alter system set OPTIMIZER_DYNAMIC_SAMPLING=2;

-- dynamic gather statistics
explain select count(*) from t2 where c4=1;
```
