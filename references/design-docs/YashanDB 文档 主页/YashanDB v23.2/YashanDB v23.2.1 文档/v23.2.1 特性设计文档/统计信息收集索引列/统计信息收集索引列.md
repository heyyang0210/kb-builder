YDBRD-21459: 收集统计信息method_opt支持FOR ALL INDEX COLUMNS size_clause项功能

SR链接：    [[YDBRD-21459] 收集统计信息method_opt支持FOR ALL INDEX COLUMNS size_clause项功能 - SICS-CoD Jira (yasdb.com)](https://jira.yasdb.com/browse/YDBRD-21459)  

##   [1. 总述](https://conf.yasdb.com/pages/viewpage.action?pageId=91780307#1-%E6%80%BB%E8%BF%B0)  

收集统计信息method_opt选项增加FOR ALL INDEXED COLUMNS size_clause项功能，功能为在收集表的统计信息时只收集索引列的统计信息，非索引列的统计信息不收集

##   [2. 接口](https://conf.yasdb.com/pages/viewpage.action?pageId=91780307#2-%E6%8E%A5%E5%8F%A3)  

加粗为新增选项

|选项名|含义|default|
|---|---|---|
|METHOD_OPT|统计信息收集选项    
  1. FOR ALL   **[INDEXED]**   COLUMNS [size_clause]：收集所有列/索引列的统计信息    
  2. FOR COLUMNS [column_clause] [size_clause]：收集指定列的统计信息    
  column_clause：(col1,col2,col3)    
  size_clause：SIZE {integer | AUTO}用于指定直方图信息    
  1. integer：直方图的bucket数量，范围为[1, 2048]    
  2. AUTO：由数据库决定是否生成直方图    
  SET_SCHEMA_PREFS、SET_DATABASE_PREFS、SET_GLOBAL_PREFS只能设置FOR ALL   **[INDEXED] **  COLUMNS [size_clause]。|FOR ALL COLUMNS SIZE AUTO|


##   [3. 规格与约束](https://conf.yasdb.com/pages/viewpage.action?pageId=91780307#3-%E8%A7%84%E6%A0%BC%E4%B8%8E%E7%BA%A6%E6%9D%9F)  

列的统计信息可以查看dba_tab_col_statistics，dba_part_col_statistics获取

统计信息选项可以查看dba_stat_prefs获取

```
select TABLE_NAME,COLUMN_NAME,LOW_VALUE from DBA_TAB_COL_STATISTICS where owner = upper('user');
select TABLE_NAME,COLUMN_NAME,PARTITION_NAME,LOW_VALUE from DBA_PART_COL_STATISTICS where owner = upper('user');
```

函数索引的列将不会计入索引列，如create index INDEX_TEST1 on table(a, a+b)，列a会被收集统计信息，列b不会被收集

create index on table(a,b) ,列a和b会被收集统计信息

空间索引、列式索引判断，跳过

##   [4. 特性](https://conf.yasdb.com/pages/viewpage.action?pageId=91780307#4-%E7%89%B9%E6%80%A7)  

###   [4.1](https://conf.yasdb.com/pages/viewpage.action?pageId=91780307#41-%E7%89%B9%E6%80%A7%E8%AE%BE%E8%AE%A1)     数据结构

```
typedef enum EnColumnGather {
    ALL_COLUMNS         = 0,  //for all columns or columns
    ALL_INDEXED_COLUMNS = 1,  //for all indexed columns
} ColumnGather;
```

在StatsManager中增加字段CodUint8    columnGather，标识本次收集是收集指定列/全部列还是收集索引列

在GatherDatabaseDef、GatherSchemaDef、GatherTableDef中也同步添加该字段

在bipinitDatabaseDef等添加初始化columnGather = ALL_COLUMNS

### 4.3 详细设计

statsGetColumns新增获取索引列的功能

1.ankGetIndexCount获取表的索引数量，ankGetColumnCount获取表的列数量，维护一个usedColId数组来标识该列是否已被获取

2.通过IndexSlot遍历表的index，判断索引列是否为函数索引列，是则跳过，否则遍历索引列，通过usedColId数组判断该列是否被获取，否的话将AnkColumn添加到stm→columns中

3.在收集时会根据stm→columns中的内容对指定列进行收集

##   [5. Testcases（自测用例）](https://conf.yasdb.com/pages/viewpage.action?pageId=91780307#5-testcases%E8%87%AA%E6%B5%8B%E7%94%A8%E4%BE%8B)  

```
drop user zyk cascade;
create user zyk identified by 123456;
grant dba to zyk;
conn zyk/123456;
create table TEST1(id int,c1 int,c2 int,c3 int,c4 int);
insert into TEST1 values(1,2,3,4,5);
insert into TEST1 values(11,12,13,14,15);
insert into TEST1 values(13,23,33,43,53);
insert into TEST1 values(41,24,34,44,45);
insert into TEST1 values(31,20,32,47,58);
create index INDEX_TEST1 on TEST1(id);
create index INDEX_TEST2 on TEST1(id,c4);
create index INDEX_TEST3 on TEST1(c3,c4);
create index INDEX_TEST4 on TEST1(c1+c2);

exec dbms_stats.gather_table_stats('zyk', 'TEST1', null, null, null, 'FOR ALL INDEXED COLUMNS SIZE 1024', null, null, null);
select table_name, column_name, high_value, last_analyzed from dba_tab_col_statistics where owner = 'ZYK';   //正确结果为收集到id、c3、c4列的统计信息

exec dbms_stats.set_table_prefs('user', 'table', 'method_opt', 'for all indexed columns size 1024');
```
