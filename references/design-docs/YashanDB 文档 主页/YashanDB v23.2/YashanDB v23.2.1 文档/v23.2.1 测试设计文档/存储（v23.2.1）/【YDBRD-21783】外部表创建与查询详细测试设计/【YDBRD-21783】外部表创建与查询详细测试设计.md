# 1. 概述

当前在华润数科-迁移平台会议系统适配过程中，发现原ORACLE系统中有用到外部表(External Tables)功能，为了兼容ORACLE，崖山需要支持外部表功能。

外部表，顾名思义就是存储在数据库外部的表。它不占用数据库内部资源（不会产生segment），数据库仅存储外部表的元数据信息。

外部表有一下特点：

- 不需要将数据装载入数据库，就可以通过sql语句访问外部表数据（sql语句与内部表的select一样）
- 对于外部表的查询，可以像内部表一样（可以做内部表与外部表的join）
- 外部表数据只读，仅提供查询能力，不提供修改能力（insert、update、delete），同时外部表也不能创建索引
- 外部表的数据存储在文件系统中


  


并且在生产环境中，外部表具有许多优势，尤其在大规模数据处理和分析场景中。如下是部分优势和价值。

- 数据的隔离和分离：将数据存储在独立的存储系统中，而不是将数据存储在数据库的表中。这种隔离可以减轻数据库的存储负担，同时允许更大规模的数据存储，降低了数据存储和查询的成本 
- 大数据处理和分析：当涉及大规模数据处理和分析时，外部表可以直接在存储系统上执行查询，避免了数据传输的开销。这在数据量巨大的情况下可以显著提高查询性能
- 节约存储成本：外部表不会在数据库中存储数据副本，因此可以减少数据库的存储需求
- 数据共享和合作： 外部表可以供多个数据库或应用程序访问，不同的团队或项目可以共享同一份数据，而不必在每个数据库中复制数据，从而减少了数据冗余和一致性问题

#### TYPE access_driver_type

指定外部表驱动，oracle支持4种驱动：ORACLE_LOADER、ORACLE_DATAPUMP、ORACLE_HDFS、ORACLE_HIVE，不指定默认为ORACLE_LOADER。

YashanDB计划支持YASDB_LOADER，同时语法兼容ORACLE_LOADER。

#### REJECT LIMIT (integer | UNLIMITED)

指定外部表数据错误容忍度，在interger次数内的数据错误不报错给前端，只有超过后才报错。 UNLIMITED为永远容忍数据错误。默认值为0.

#### DEFAULT DIRECTORY directory

指定外部表默认目录，当其他路径参数没有指定directory的时候，使用default directory

#### ACCESS PARAMETERS ( opaque_format_spec )

指定外部表访问参数，例如：records delimited by newline fields terminated by ',' 指定csv文件解析参数。

#### LOCATION [directory :] ('location_specifier')

指定外部表文件位置，如果没有指定directory，则使用默认directory

## 2.2 应用场景

*需求本身的主要应用场景*

- 应用于数据的存储和表隔离的场景，外部表允许我们将数据存储在独立的存储系统中，而不是将数据存储在数据库的表中。这种隔离可以减轻数据库的存储负担，同时允许更大规模的数据存储，降低了数据存储和查询的成本
- 数据导入和导出：外部表使得数据导入和导出变得更加方便，可以通过简单的文件操作来加载或导出数据。
- 跨平台兼容性：外部表使得数据在不同数据库系统之间迁移变得更加容易。你可以在不同数据库中创建外部表，从而在不同系统之间共享和访问相同的数据
- 数据共享：外部表可以供多个数据库或应用程序访问，实现数据共享和合作。不同的团队或项目可以共享同一份数据，而不必在每个数据库中复制数据，从而减少了数据冗余和一致性问题


需求与其他特性的关联场景：

- 统计信息：对外部表做统计信息收集
- 导入导出：对外部表做元数据导出、数据导出、get_ddl导出
- 逻辑复制：创建、修改外部表后，查看逻辑复制日志
- 备份恢复：创建外部表后，做备份，使用备机集恢复，可以恢复出DIRECTORY和外部表，恢复后可以正常查询
- 用户视图、物化视图：以外部表做基表创建用户视图、物化视图
- 同义词：给外部表创建同义词，通过同义词查看外部表
- 回收站：开启回收站，drop\truncate外部表
- DDL：跟表操作的相关ddl，create table as select , alter table 、flashback等
- 并行扫描：查询时开启并行


## 2.3 规格约束

- 外部表只读
- 外部表不支持约束
- 外部表不支持index
- 外部表不支持object type，varray，LONG类型（oracle还不支持invisible column）
- 外部表不支持lob
- 外部表不支持alter
- 外部表不能是临时表
- 外部表不支持分区表
- opaque_format_spec不会校验正确性，只有使用的时候才会校验正确性。当前版本，YashanDB不会真正去使用opaque_format_spec，也不会校验opaque_format_spec。解析外部文件使用默认行为（records delimited by newline fields terminated by ','）
- location_specifier也不会校验，只有真正使用的时候才会校验文件是否存在
- REJECT LIMIT integer， integer取值范围 [0, 100000] 
- 当数据库定义列数少于csv文件行列数，不会报错（前提是前几列对应数据类型转化不报错）。如果数据库定义列数大于csv文件行列数，会报错（增加reject limit）
