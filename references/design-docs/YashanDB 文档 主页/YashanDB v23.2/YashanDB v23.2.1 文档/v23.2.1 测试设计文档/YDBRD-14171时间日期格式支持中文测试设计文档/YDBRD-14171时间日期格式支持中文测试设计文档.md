# 2.   **需求分析**

- 时间日期支持中文
- alter  session/system DATE_FORMAT =      'yyyy"年"mm"月"dd"日"';
- to_date函数支持中文，格式如：to_date('2023年10月24日','yyyy"年"mm"月"dd"日"')
- to_char函数日期格式支持中文，格式如：  to_char(sysdate,'YYYY"年"MM"月"DD"日"')，to_char(systimestamp, 'yyyy"年"mm"月"dd"日" hh:mi:ss.ff')，按照fmt参数格式输出字符串
- 日期格式fmt双引号内字符的前面允许有空格，后面的空格不允许比Str匹配字符后面的空格长
- 出现双引号括起的字母中文后，该位置后面紧跟着的分隔符就是不兼容的（oracle）YASDB不严格匹配
- fmt双引号的空格会被trim掉，然后再匹配，srcStr和fmt的空格都会被trim掉
