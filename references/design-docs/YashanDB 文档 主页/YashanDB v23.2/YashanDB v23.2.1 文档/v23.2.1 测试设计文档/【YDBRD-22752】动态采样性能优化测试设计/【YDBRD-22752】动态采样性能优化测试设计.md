# 1. 概述

若开启动态采样，分区表在每个分区下都会采集对应的block数。

例如OPTIMIZER_DYNAMIC_SAMPLING=2，整体上整个分区表应该采集64个block，但实际上是每个分区都至少采了64个block（如果分区block数小于128个还会全采）。

# 2. 需求分析

## 2.1 功能点分析

- 根据动态采样级别确定要采样的block数target_blocks
- 遍历每个分区：如果剩余采样的block数为0，则退出；如果该分区block小于剩余采样的block，则全采； 否则采剩余block数


## 2.2 应用场景

- 开启动态采样后的语句执行性能


## 2.3 规格约束

转测范围：单机
