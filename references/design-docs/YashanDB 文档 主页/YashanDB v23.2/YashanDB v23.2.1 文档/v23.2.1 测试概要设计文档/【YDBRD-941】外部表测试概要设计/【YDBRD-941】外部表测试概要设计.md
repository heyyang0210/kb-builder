##   [1. 需求概述](#1-需求概述)  

当前在华润数科-迁移平台会议系统适配过程中，发现原ORACLE系统中有用到外部表(External Tables)功能，为了兼容ORACLE，崖山需要支持外部表功能。

并且在生产环境中，外部表具有许多优势，尤其在大规模数据处理和分析场景中。如下是部分优势和价值。

- 数据的隔离和分离：将数据存储在独立的存储系统中，而不是将数据存储在数据库的表中。这种隔离可以减轻数据库的存储负担，同时允许更大规模的数据存储，降低了数据存储和查询的成本
- 大数据处理和分析：当涉及大规模数据处理和分析时，外部表可以直接在存储系统上执行查询，避免了数据传输的开销。这在数据量巨大的情况下可以显著提高查询性能
- 节约存储成本：外部表不会在数据库中存储数据副本，因此可以减少数据库的存储需求
- 数据共享和合作： 外部表可以供多个数据库或应用程序访问，不同的团队或项目可以共享同一份数据，而不必在每个数据库中复制数据，从而减少了数据冗余和一致性问题
- 支持的部署形态为 主备(单机)，外部表仅支持csv格式


##   [2. 功能点](#2-功能点)  

功能点包含：

- 新增创建外部表语法、同时需要对查询、修改、删除外部表功能进行验证
- 新增系统表和系统视图 EXTERNAL_TAB$、EXTERNAL_LOCATION$、DBA_EXTERNAL_TABLES、DBA_EXTERNAL_LOCATIONS


规格差异：

- oracle LOCATION可以指定多个，当前版本yashan只支持一个
- 当前版本yashan文件格式只支持csv
- 外部表访问参数当前只是语法兼容，不做校验，只支持逗号作为列分隔符


##   [3. 规格约束](#3-规格约束)  

- 外部表可以做以下alter操作：
- add column
- modify column
- drop column
- 修改并行度
- 修改external_table_data_props
- 修改 REJECT LIMIT
- PROJECT COLUMN (ALL | REFERENCED) 是否处理所有列，ALL表示处理所有列，REFERENCED表示只处理select的列。默认是ALL


规格与约束

- 外部表只读
- 外部表不支持约束
- 外部表不支持index
- 外部表不支持object type，varray，LONG类型（oracle还不支持invisible column）
- 外部表不支持lob
- 外部表不支持alter
- 外部表不能是临时表
- 外部表不支持分区表
- opaque_format_spec不会校验正确性，只有使用的时候才会校验正确性。当前版本，YashanDB不会真正去使用opaque_format_spec，也不会校验opaque_format_spec。解析外部文件使用默认行为（records delimited by newline fields terminated by ','）
- location_specifier也不会校验，只有真正使用的时候才会校验文件是否存在
- REJECT LIMIT integer， integer取值范围 [0, 100000]


##   [4. 主要应用场景](#4-主要应用场景)  

需求本身的主要应用场景

*1.应用于数据的存储和表隔离的场景，外部表允许我们将数据存储在独立的存储系统中，而不是将数据存储在数据库的表中。这种隔离可以减轻数据库的存储负担，同时允许更大规模的数据存储，降低了数据存储和查询的成本*

*2.数据导入和导出：外部表使得数据导入和导出变得更加方便，可以通过简单的文件操作来加载或导出数据。*

*3.跨平台兼容性：外部表使得数据在不同数据库系统之间迁移变得更加容易。你可以在不同数据库中创建外部表，从而在不同系统之间共享和访问相同的数据*

*4.数据共享：外部表可以供多个数据库或应用程序访问，实现数据共享和合作。不同的团队或项目可以共享同一份数据，而不必在每个数据库中复制数据，从而减少了数据冗余和一致性问题*

需求与其他特性的关联场景：

*1.统计信息：对外部表做统计信息收集*

_2.导入导出：对外部表做元数据导出、数据导出、get_ddl导出

*3.逻辑复制：创建、修改外部表后，查看逻辑复制日志*

*4.备份恢复：创建外部表后，做备份，使用备机集恢复，可以恢复出DIRECTORY和外部表，恢复后可以正常查询*

*5.用户视图、物化视图：以外部表做基表创建用户视图、物化视图*

*6.同义词：给外部表创建同义词，通过同义词查看外部表*

##   [6. 测试策略](#6-测试策略)  

*1、测试覆盖策略*

- 对语法的各个路径进行，各个参数的有效值和无效值，不同参数的组合进行验证

- 对新增系统表和系统视图，结合不同参数创建的外部表，观测系统表和系统视图的值是否正确
- 外部表只读，对于查询语句覆盖DQL的以下内容    [https://conf.yasdb.com/pages/viewpage.action?pageId=117080628](https://conf.yasdb.com/pages/viewpage.action?pageId=117080628)  
- join场景考虑外部表和外部表join，外部表和普通表join，行列混合的场景
- 外部表的查询执行计划的正确验证
- 外部表dml、创建索引、创建约束、不支持的数据类型、不支持的表类型等操作进行拦截验证
- 外部表的ddl验证
- 集群、分布式不支持，需要拦截
- 数据类型和csv数据类型不能转换可以识别
- 只支持csv格式，其他文件格式报错，csv是否带标题列
- 从oracle、mysql导出的cvs文件可以在yashandb上进行查询
- 外部表和依赖的directory删除顺序不同进行验证
- 对上面描述的关联特性，结合外部表进行验证
