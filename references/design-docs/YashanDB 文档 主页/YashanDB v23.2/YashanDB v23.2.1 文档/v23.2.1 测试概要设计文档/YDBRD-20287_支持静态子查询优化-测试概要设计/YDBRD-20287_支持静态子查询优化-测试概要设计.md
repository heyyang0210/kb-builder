# YDBRD-20287 测试概要设计

IR链接：    [YDBRD-20287](https://jira.yasdb.com/browse/YDBRD-20287?src=confmacro)    -  支持静态子查询优化  完成

## 1. 需求概述

列存支持同一静态子查询在同一stage被多处使用，不支持被多stage使用。

范围：单机列存，分布式列存

## 2. 功能点

1、性能优化，同一静态子查询在同一stage被多处使用场景下，性能提升（无明确性能指标，子查询数据量越大，优化越明显）

2、预期走该优化的查询语句，通过autotrace确定走该优化

## 3. 规格约束

无

## 4. 主要应用场景

静态子查询场景

## 5. 概要测试设计

### 5.1 功能测试设计

1、静态子查询场景：子查询出现位置全部覆盖，CTE；构造触发优化的场景，需要重点覆盖all、any、exist、标量子查询

2、表的类型：分区表，复制表，分布表

3、并行

4、修改负向影响：子查询类的SQL

### 5.2 DFX测试设计

1、长稳：涉及

2、CT/KT：涉及

## 6. 测试策略

1、测试设计：覆盖不同子查询的位置、CTE+触发优化

2、测试执行：1）功能，通过autotrace观察是否走优化，且查询结果数据正确；2）对于负向影响，使用库上存量用例覆盖（提前跑上车工程）
