# 1. 需求概述

需求描述：

支持执行计划选择诊断（对标Oracle 10053事件），开启后，记录SQL生成执行计划过程，例如索引选择，JOIN顺序，算子选择。

类似oracle中10053事件，是用于跟踪sql语句成本计算的内部事件，记载CBO模式下优化器如何计算sql成本，生成相应的执行计划。

**该特性支持的产品形态：单机（行存+列存），集群，分布式**

# 2. 功能点

2.1 支持设置TRACE文件标识符

2.2 支持开启和关闭10053事件

2.3 支持查询TRACE文件所在路径

# 4. 主要应用场景

1、应用场景：数据库执行计划、性能出现问题，开发、dba分析定位时，作为分析定位的入口，解析执行计划生成原因

2、实现机制：对SQL进行硬解析时，  跟踪sql语句成本计算的内部事件，记载CBO模式下优化器如何计算sql成本，生成相应的执行计划。

基于上述场景考虑，该特性需要重点保证SQL trace信息的正确性。
