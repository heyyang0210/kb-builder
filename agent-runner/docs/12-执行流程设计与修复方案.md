# 执行流程设计与修复方案

## 一、当前流程分析（存在断裂）

### 1.1 当前实际流程

```
用户操作                        前端                              后端
─────────────────────────────────────────────────────────────────────────

① 选择知识点 → 填写表单
        │
        ▼
② 点击 [🔨 生成提示词]
        │
        ├─→ generatePrompt()
        │       └─→ assemblePrompt()
        │             ├─ 读取表单数据
        │             ├─ 匹配 Skill 文件
        │             ├─ 匹配模板文件
        │             └─ 拼接 Markdown 提示词
        │
        ├─→ 显示在 #outputBox 中                    ← 仅展示，未发送！
        │
        ▼
③ 点击 [🚀 执行 Agent]
        │
        ├─→ executeAgent()
        │       ├─ 重新读取表单数据                  ← 重复读取！
        │       ├─ 构建 knowledge_point 对象
        │       └─→ POST /api/agent/execute
        │              └─ 发送 knowledge_point       ← 提示词未发送！
        │
        │                                           ┌─→ 收到 knowledge_point
        │                                           │
        │                                           ├─→ WorkflowEngine
        │                                           │     ├─→ Planner Agent
        │                                           │     │    └─ 重新规划   ← 重复工作！
        │                                           │     ├─→ Retriever Agent
        │                                           │     ├─→ Generator Agent
        │                                           │     └─→ Validator Agent
        │                                           │
        │                                           └─→ WebSocket 推送进度
        │
        ▼
④ 进度面板（应该显示但实际不显示）
```

### 1.2 核心问题

| 问题 | 说明 |
|------|------|
| **断裂 1** | "生成提示词"产出的 Markdown 提示词仅在前端展示，**未发送给后端** |
| **断裂 2** | "执行 Agent"重新从表单读取数据，**完全忽略了已生成的提示词** |
| **断裂 3** | 后端 Planner Agent 重新规划文档结构，**与前端 assemblePrompt 的工作重复** |
| **断裂 4** | 进度面板不显示，WebSocket/polling 链路存在问题 |

### 1.3 问题根因

前端存在**两条独立的功能路径**，彼此不关联：

- **路径 A**（原始功能）：生成提示词 → 用户手动复制到 Codex CLI 执行
- **路径 B**（新增功能）：直接调用后端 Agent 自动执行

路径 B 没有复用路径 A 的产出，而是重新构建了一套独立的执行逻辑。

## 三、需要修复的问题清单

### 3.1 前端问题

| 编号 | 问题 | 修复方案 |
|------|------|---------|
| F1 | executeAgent 未发送已生成的提示词 | 从 outputBox 读取提示词文本，放入请求体 |
| F2 | 进度面板不显示 | 确保 showProgressPanel 正确调用，面板可见 |
| F3 | WebSocket 连接后无进度更新 | 增加连接状态日志，确保 subscribe 正确发送 |
| F4 | 缺少"查看提示词"入口 | 在进度面板中增加提示词折叠展示区 |
| F5 | 缺少步骤详情展示 | 每步完成后展示 output_preview 内容 |

### 3.2 后端问题

| 编号 | 问题 | 修复方案 |
|------|------|---------|
| B1 | 未接收前端传来的 prompt | API 路由增加 prompt 字段处理 |
| B2 | Planner 未使用前端提示词中的信息 | 将 prompt 作为 Planner 的上下文输入 |
| B3 | 进度推送可能未到达前端 | 确保 WebSocket room 订阅正确 |
