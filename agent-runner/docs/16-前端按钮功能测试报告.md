## 四、发现的问题与修复

### 4.1 问题描述

**问题编号**: 35  
**问题名称**: `saveOutputAsDocument` 函数缺失  
**严重程度**: 高  
**发现时间**: 2026-07-09 12:30

**现象**:  
前端页面中存在"📄 保存为文档"按钮（第 1213 行），绑定了 `onclick="saveOutputAsDocument()"` 事件，但对应的 JavaScript 函数未定义，导致点击按钮时无响应。

**根本原因**:  
在实现文档管理功能时，添加了按钮但未实现对应的函数。

### 4.2 修复方案

在 `frontend/prompt-generator.html` 文件中添加 `saveOutputAsDocument` 函数：

```javascript
// 保存输出内容为文档
async function saveOutputAsDocument() {
  const content = (window._currentPromptMarkdown || getCurrentContent() || '').trim();
  if (!content) {
    showToast('⚠️ 没有可保存的内容');
    return;
  }
  const title = document.getElementById('kpName')?.value || '未命名文档';
  try {
    const outputPath = typeof getOutputPath === 'function' ? getOutputPath({
      part: document.getElementById('kpPart')?.value,
      chapter: document.getElementById('kpChapter')?.value
    }) : '';
    const resp = await fetch(BACKEND + '/api/document/save', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        content: content,
        path: (outputPath || '') + title + '.md',
        title: title
      })
    });
    const result = await resp.json();
    if (result.success) {
      showToast('✅ 文档已保存 (v' + result.data.version + ')');
    } else {
      throw new Error(result.message);
    }
  } catch (err) {
    showToast('❌ 保存失败: ' + err.message);
  }
}
```

### 4.3 修复验证

修复后重新运行测试，所有 93 个测试用例全部通过。
