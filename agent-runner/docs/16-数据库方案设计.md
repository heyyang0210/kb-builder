# 数据库方案设计文档

> 状态：历史设计，仅描述演示阶段文件存储现状
> 演进说明：本文原拟的 SQLite 目标方案已失效。知识中心目标业务数据库已确定为 YashanDB，现有 Linux 文件存储的分批迁移路线以 [知识中心建设平台总体概要设计](../../.codex/知识中心建设平台/02-概要设计/知识中心-平台-总体架构-概要设计文档.md) 为准。本文中的文件适配器、SQLite 表结构、脚本和配置均不得直接作为新平台实施依据。

## 1. 概述

### 1.1 设计目标

为 Agent Runner 系统提供数据持久化能力，支持：
- 大纲数据管理
- 生成文档管理
- 工作流方案管理
- 执行历史记录
- 配置管理

### 1.2 技术选型

**当前阶段：文件系统存储**
- 使用 JSON 文件存储元数据
- 使用文件系统存储实际内容
- 简单、无需额外依赖

**历史设想：SQLite 数据库（已失效）**
- 轻量级嵌入式数据库
- 单文件，易备份
- 支持 SQL 查询
- 适合单机部署场景

### 1.3 设计原则

1. **接口抽象**：数据库层提供统一接口，底层实现可替换
2. **渐进迁移**：从文件系统平滑迁移到数据库
3. **向后兼容**：保持现有 API 不变
4. **性能优先**：读多写少场景优化

### 3.2 表结构设计

#### 3.2.1 大纲表 (outlines)

```sql
CREATE TABLE outlines (
  id VARCHAR(64) PRIMARY KEY,
  name VARCHAR(255) NOT NULL,
  type VARCHAR(32) NOT NULL,  -- 'db' | 'biz'
  content TEXT NOT NULL,       -- JSON 格式的大纲内容
  kp_count INTEGER DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_outlines_type ON outlines(type);
CREATE INDEX idx_outlines_created ON outlines(created_at);
```

**示例数据：**
```json
{
  "id": "outline_001",
  "name": "YashanDB 基础教程",
  "type": "db",
  "content": {
    "part": "第一部分：数据库基础入门",
    "chapters": [...]
  },
  "kp_count": 120,
  "created_at": "2026-07-07T10:00:00Z",
  "updated_at": "2026-07-07T10:00:00Z"
}
```

#### 3.2.2 知识点表 (knowledge_points)

```sql
CREATE TABLE knowledge_points (
  id VARCHAR(64) PRIMARY KEY,
  outline_id VARCHAR(64) NOT NULL,
  kp_id VARCHAR(64) NOT NULL,      -- 原始知识点 ID，如 C1.1.1
  name VARCHAR(255) NOT NULL,
  description TEXT,
  level VARCHAR(16),               -- 难度等级
  part_name VARCHAR(255),
  chapter_name VARCHAR(255),
  path VARCHAR(512),               -- 完整路径
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (outline_id) REFERENCES outlines(id) ON DELETE CASCADE
);

CREATE INDEX idx_kp_outline ON knowledge_points(outline_id);
CREATE INDEX idx_kp_kpid ON knowledge_points(kp_id);
CREATE FULLTEXT INDEX idx_kp_search ON knowledge_points(name, description);
```

#### 3.2.3 文档表 (documents)

```sql
CREATE TABLE documents (
  id VARCHAR(64) PRIMARY KEY,
  title VARCHAR(255) NOT NULL,
  outline_id VARCHAR(64),
  kp_id VARCHAR(64),
  content TEXT NOT NULL,           -- Markdown 内容
  file_path VARCHAR(512),          -- 文件存储路径
  file_size INTEGER DEFAULT 0,
  word_count INTEGER DEFAULT 0,
  metadata TEXT,                   -- JSON 格式的元数据
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (outline_id) REFERENCES outlines(id) ON DELETE SET NULL

CREATE INDEX idx_docs_outline ON documents(outline_id);
CREATE INDEX idx_docs_kp ON documents(kp_id);
CREATE INDEX idx_docs_created ON documents(created_at);
CREATE FULLTEXT INDEX idx_docs_search ON documents(title, content);
```

### 5.1 接口定义

```javascript
// lib/db/repos/OutlineRepository.js
class OutlineRepository {
  constructor(adapter) {
    this.adapter = adapter;
  }
  
  async findAll() {
    return await this.adapter.getOutlines();
  }
  
  async findById(id) {
    return await this.adapter.getOutline(id);
  }
  
  async save(outline) {
    return await this.adapter.saveOutline(outline);
  }
  
  async delete(id) {
    return await this.adapter.deleteOutline(id);
  }
  
  async search(keyword) {
    // 全文搜索知识点
  }
}

// lib/db/repos/DocumentRepository.js
class DocumentRepository {
  constructor(adapter) {
    this.adapter = adapter;
  }
  
  async findAll(filter = {}) {
    return await this.adapter.getDocuments(filter);
  }
  
  async findById(id) {
    return await this.adapter.getDocument(id);
  }
  
  async save(document) {
    return await this.adapter.saveDocument(document);
  }
  
  async delete(id) {
    return await this.adapter.deleteDocument(id);
  }
}

// lib/db/repos/WorkflowRepository.js
class WorkflowRepository {
  constructor(adapter) {
    this.adapter = adapter;
  }
  
  async findAll() {
    return await this.adapter.getWorkflows();
  }
  
  async findById(id) {
    return await this.adapter.getWorkflow(id);
  }
  
  async save(workflow) {
    return await this.adapter.saveWorkflow(workflow);
  }
  
  async delete(id) {
    return await this.adapter.deleteWorkflow(id);
  }
  
  async getDefault() {
    const workflows = await this.findAll();
    return workflows.find(w => w.is_default);
  }
}
```

## 6. 迁移方案

### 6.1 从文件系统迁移到 SQLite（历史示例，不再执行）

**迁移脚本：**
```javascript
// scripts/migrate-to-sqlite.js
async function migrate() {
  // 1. 读取文件系统数据
  const fileAdapter = new FileAdapter({ dataDir: './data' });
  await fileAdapter.initialize();
  
  // 2. 创建 SQLite 数据库
  const sqliteAdapter = new SQLiteAdapter({ dbPath: './data/agent-runner.db' });
  await sqliteAdapter.initialize();
  await sqliteAdapter.createTables();
  
  // 3. 迁移数据
  const outlines = await fileAdapter.getOutlines();
  for (const outline of outlines) {
    await sqliteAdapter.saveOutline(outline);
  }
  
  const documents = await fileAdapter.getDocuments();
  for (const doc of documents) {
    await sqliteAdapter.saveDocument(doc);
  }
  
  // 4. 验证
  console.log('Migration completed');
}
```

### 6.2 配置切换

```javascript
// .env

// lib/db/database.js

  : new FileAdapter(config);
```

## 7. 性能优化

### 7.1 文件系统优化

- **元数据缓存**：启动时加载 metadata.json 到内存
- **懒加载**：大纲内容按需读取
- **批量写入**：合并多次写入操作

### 7.2 SQLite 优化

- **连接池**：复用数据库连接
- **索引优化**：为常用查询字段创建索引
- **事务处理**：批量操作使用事务
