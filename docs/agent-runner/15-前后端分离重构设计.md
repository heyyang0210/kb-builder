# 前后端分离重构设计文档

## 1. 概述

### 1.1 背景

当前前端为单文件 HTML（6157 行），存在以下问题：
- 代码臃肿，难以维护
- Markdown 渲染能力有限
- 文件管理功能缺失
- 配置管理分散

### 1.2 重构目标

1. **前端模块化**：拆分为多页面 + 组件化
2. **后端 API 完善**：新增文件管理、大纲管理等 API
3. **数据库预留**：为后续持久化做准备
4. **功能增强**：Markdown 预览、大纲上传、执行方案、文档查看

### 1.3 技术选型

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端框架 | 原生 JS + 模块化 | 保持轻量，无需构建工具 |
| Markdown 渲染 | marked.js + highlight.js | CDN 引入，完美渲染 |
| 样式 | CSS Variables + BEM | 主题化，易维护 |
| 后端 | Node.js + Express | 保持现有架构 |
| 数据库 | SQLite（预留） | 轻量级，单文件数据库 |
| 文件存储 | 本地文件系统 | 同机部署，简单方案 |

## 2. 架构设计

### 2.0 局域网访问与后端地址解析

前端统一访问 Windows 宿主机 `192.168.130.180` 上的后端服务。HTTP API 和 WebSocket 均使用固定的 `4100` 端口，不再依赖前端页面的当前主机名。

接口：

```javascript
getBackendBaseUrl(): string
```

伪代码：

```text
backendHost = "192.168.130.180"
backend = "http://" + backendHost + ":4100"
所有前端组件、HTTP API 和 WebSocket 统一使用 backend
```

前后端服务均监听 `0.0.0.0`；Socket.IO 允许来自实际前端访问地址的跨域连接。Windows 宿主机需要将 TCP 3500 和 4100 转发到当前运行环境，并在防火墙中放行这两个端口。

## 3. 后端 API 设计

### 3.1 新增 API 总览

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/outline/list | 获取大纲列表 |
| POST | /api/outline/upload | 上传大纲文件 |
| GET | /api/outline/:id | 获取大纲详情 |
| DELETE | /api/outline/:id | 删除大纲 |
| GET | /api/document/list | 获取文档列表 |
| GET | /api/document/:id | 获取文档详情 |
| GET | /api/document/:id/content | 获取文档内容 |
| DELETE | /api/document/:id | 删除文档 |
| GET | /api/workflow/list | 获取工作流方案列表 |
| POST | /api/workflow | 创建工作流方案 |
| PUT | /api/workflow/:id | 更新工作流方案 |
| DELETE | /api/workflow/:id | 删除工作流方案 |

### 3.2 大纲管理 API

#### 3.2.1 获取大纲列表

```http
GET /api/outline/list
```

**响应：**
```json
{
  "success": true,
  "data": [
    {
      "id": "outline_001",
      "name": "YashanDB 基础教程",
      "type": "db",
      "created_at": "2026-07-07T10:00:00Z",
      "updated_at": "2026-07-07T10:00:00Z",
      "kp_count": 120
    }
  ]
}
```

#### 3.2.2 上传大纲文件

```http
POST /api/outline/upload
Content-Type: multipart/form-data

file: <大纲文件>
name: <大纲名称>
type: db|biz
```

**支持格式：**
- JSON：标准大纲格式
- Markdown：层级标题格式
- CSV：表格格式

**响应：**
```json
{
  "success": true,
  "data": {
    "id": "outline_002",
    "name": "上传的大纲",
    "kp_count": 50
  }
}
```
