## 审核定位维护项（2026-09-11）

- 当前按用户确认的交互规格固定审核面板 320px、折叠入口 48px；后续纳入统一布局 token。选区上下文长度暂沿用 120 字符，若需跨产品调整再配置化。
- 缺失引用文本和路径映射的历史意见无法保证自动定位，保持人工确认提示，不回填猜测锚点。

## 后续优化建议

1. **流式输出**：Generator Agent 支持流式输出，前端实时显示生成进度
2. **Markdown 预览增强**：集成 marked.js 进行前端 Markdown 渲染
3. **批量执行**：前端支持选择多个知识点批量执行
