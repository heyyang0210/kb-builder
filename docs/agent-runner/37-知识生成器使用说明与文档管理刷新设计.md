# 知识生成器使用说明与文档管理刷新设计

## 1. 目标

补充知识生成器使用说明的总览、流程图、文档预览与编辑说明，并修复文档保存后文档管理页必须刷新整个浏览器才能看到新文档的问题。

## 2. 设计方案

### 2.1 使用说明结构

使用说明按以下顺序组织：

1. 总览与适用范围
2. 端到端流程图
3. 使用前准备和配置
4. 知识点填写、提示词生成和 Agent 执行
5. 结果预览、编辑、保存和下载
6. 文档管理中的搜索、预览、编辑、保存、下载和删除
7. 常见问题与验证记录

流程图使用现有 Markdown/Mermaid 渲染能力；同时保留编号文字步骤，避免图形渲染失败时信息丢失。截图链接使用文档服务 `/preview/` 地址，避免被前端页面根路径错误解析。

### 2.2 文档管理刷新

新增 `refreshDocumentManagement()`，统一刷新文档列表、目录树和统计信息。

伪代码：

```text
refreshDocumentManagement():
    并行加载 list、tree、stats
    docMgmtLoaded = true

switchTab('doc-mgmt'):
    显示文档管理视图
    refreshDocumentManagement()

saveOutputAsDocument() 成功:
    显示保存版本提示
    若当前已打开文档管理视图，则 refreshDocumentManagement()
    不自动切换页面、不自动打开新文档
```

该方案不改变后端 API，不新增依赖，也不改变保存路径和版本语义。

## 3. 验收标准

- 使用说明开头有总览和流程图。
- 文档管理章节明确说明预览、编辑、保存、下载和删除。
- 关键按钮截图有红框和简短中文说明。
- 保存文档后切换到文档管理页，无需整页刷新即可看到新文档。
- 文档管理的列表、目录树和统计数字同步更新。
- 真实浏览器链路验证通过，保留与现有脏工作区无关的改动。
