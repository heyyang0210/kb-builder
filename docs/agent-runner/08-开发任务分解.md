## 9. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 大模型 API 不稳定 | 执行失败 | 重试机制 + 多厂商支持 |
| MCP Server 不可用 | 检索失败 | 降级处理 + 缓存 |
| 前端兼容性问题 | 界面异常 | 多浏览器测试 |
| 性能瓶颈 | 响应慢 | 并发控制 + 缓存优化 |
