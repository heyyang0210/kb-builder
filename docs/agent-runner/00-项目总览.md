# Agent Runner 项目总览

## 项目简介

Agent Runner 是 YashanDB 知识库文档生成器的执行引擎，通过 Workflow Agent 多步骤协作，实现从知识点选择到文档自动生成的完整流程。

## 核心特性

### 1. Workflow Agent（多步骤协作）

默认 4 步流程，支持用户自定义：

```
Planner → Retriever → Generator → Validator
 (规划)     (检索)      (生成)      (验证)
```

### 2. 数据传递

- Markdown 为主：适合文档类内容
- JSON 为辅：强规格约束的结构化数据

### 3. MCP 全局配置

配置一次，全局共享，所有 Agent 都可以使用。

### 4. 错误处理

- 自动重试 3 次
- 失败后暂停，用户可选择强制继续或终止

### 5. 进度反馈

- 实时显示执行进度
- 中间结果预览（默认折叠）

## 技术栈

| 组件 | 技术 |
|------|------|
| 后端 | Node.js + Express |
| 实时通信 | Socket.IO |
| 大模型 | OpenAI SDK（支持多家厂商） |
| 配置存储 | JSON 文件（AES-256 加密） |
| 日志 | Winston |

## 快速开始

### 1. 安装依赖

```bash
cd agent-runner
npm install
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 文件，设置 AGENT_RUNNER_KEY
```

### 3. 启动服务

```bash
npm start
```

### 4. 访问前端

打开 `prompt-generator.html`，点击配置按钮进行设置。

## 开发计划

以下为早期 Workflow Agent 历史计划。当前任务状态以 `.codex/workflow/PROGRESS.md` 和各模块 `PROGRESS.md` 为准。

3. **Phase 3**: Workflow 引擎（8天）
4. **Phase 4**: 工具模块（4天）
5. **Phase 5**: 前端集成（6天）
6. **Phase 6**: 测试优化（7天）

## 设计决策记录

| 决策 | 选择 | 原因 |
|------|------|------|
| Agent 方案 | Workflow | 多步骤协作，高质量文档 |
| 步骤定义 | 默认4步，可自定义 | 灵活性和易用性平衡 |
| 数据传递 | Markdown + JSON | 适合文档生成场景 |
| MCP 配置 | 全局共享 | 配置一次，多处使用 |
| 错误处理 | 重试3次 + 用户干预 | 平衡自动化和用户控制 |
| 进度反馈 | 中间结果预览（折叠） | 信息丰富但不干扰 |
