# 20 - 质量分析页面关键词过滤收敛设计

> 版本：v1.0
> 日期：2026-08-05
> 状态：已实施并完成聚焦验证

## 一、背景与目标

质量分析页面曾同时使用审批状态、业务准入状态、业务注入标记和 L1/L2 层级，导致过滤建议、应用结果、统计和图谱展示采用不同口径。本次将页面收敛为单一关键词过滤流程：分析建议、人工调整、应用决策、查看图谱变化、基于保留关键词构建正式知识。

目标不变量：

```text
过滤前关键词 = 保留关键词 + 排除关键词
过滤后关键词 = 保留关键词
```

## 二、范围边界

保留：

- 关键词过滤 Skill 读取和编辑；
- 非流式预览与 SSE 流式分析；
- 人工切换保留/排除和统一应用决策；
- 过滤前、过滤后、发生变化三个图谱视图；
- 基于保留关键词构建正式知识；
- 数据集发布所需的内部质量审计和基础质量门禁。

删除：

- 业务准入、业务排除、待业务确认和业务注入；
- 单关键词业务状态/准入操作；
- L2 术语创建、关联和展开；
- 质量评价报告、质量问题明细和对应公共 API；
- 前端质量评价卡片、筛选、预览和请求逻辑。

历史数据中的 `approvalStatus`、`businessStatus`、L2 和质量字段允许继续存在，仅用于读取旧产物；新流程不再根据这些字段决定关键词是否生效。

## 三、状态与统计契约

### 3.1 单一状态源

关键词节点只使用 `admissionStatus`：

| 值 | 含义 | 下游行为 |
|---|---|---|
| `admitted` | 保留 | 展示在过滤后图谱，参与正式知识构建 |
| `excluded` | 排除 | 不展示在过滤后图谱，不参与正式知识构建 |

历史关键词缺少 `admissionStatus` 时按“过滤前保留”迁移为 `admitted`，避免升级后无决策数据被全部隐藏。迁移后同时写入节点顶层和 `properties.admissionStatus`。

### 3.2 统计响应

```json
{
  "beforeTotal": 43,
  "afterTotal": 30,
  "retained": 30,
  "excluded": 13
}
```

`graph/summary` 的 `keywordFilterState` 和 `filter-apply` 的 `summary` 使用同一计算函数。前端只读取该状态；若不变量不成立，显示中文一致性错误，不静默拼接多个旧统计字段。

## 四、图谱投影

完整 `nodes.json`、`edges.json` 和 `keyword-chunk-index.json` 作为审计事实保留，应用决策不删除证据、不重建索引、不调用模型。

展示投影伪代码：

```text
admitted_ids = ids of Keyword where admissionStatus == admitted
visible_ids = admitted_ids
for each edge:
  when one endpoint is admitted keyword and the other is ProcessingUnit/Chunk:
    add the ProcessingUnit/Chunk endpoint to visible_ids
visible_nodes = nodes whose id is in visible_ids
visible_edges = edges whose source and target are both in visible_ids
```

该规则保证：

- 排除关键词不展示；
- 只与排除关键词关联的文档块不展示；
- 不返回悬空边；
- 恢复关键词为 `admitted` 后，原始证据边可重新进入展示投影。

## 五、接口设计

保留接口：

| 接口 | 作用 |
|---|---|
| `POST /api/datasets/{id}/keywords/filter-by-skill` | 非流式分析建议 |
| `GET /api/datasets/{id}/keywords/filter-by-skill/stream` | SSE 流式分析建议 |
| `POST /api/datasets/{id}/keywords/filter-apply` | 应用保留/排除决策 |
| `GET /api/datasets/{id}/graph/summary` | 过滤统计和投影摘要 |
| `GET /api/datasets/{id}/graph/nodes` | 过滤后节点投影 |
| `GET /api/datasets/{id}/graph/edges` | 过滤后边投影 |
| `POST /api/datasets/{id}/formal-knowledge/tasks` | 基于保留关键词构建正式知识 |

删除的业务三态、准入、L2、质量报告和质量问题接口不提供兼容别名，调用返回 404。

SSE 和非流式路径使用同一模型网关配置，不在业务代码中硬编码模型名称。

## 六、前端交互

页面顺序：

1. 选择数据集；
2. 执行关键词智能过滤并查看实时进度；
3. 在建议列表中调整保留/排除；
4. 点击“应用决策”；
5. 查看四项统计和过滤前/后/变化图谱；
6. 在存在保留关键词且通过基础质量门禁时构建正式知识。

应用决策前保存当前图谱快照；应用成功后重新读取后端摘要、节点和边。前端投影仅作为防御性校验，后端投影是展示事实源。

## 七、验收标准

1. 临时 fixture 应用决策后统计满足两条不变量；
2. 运行目录和数据集目录中的关键词状态一致；
3. `keyword-chunk-index.json` 字节不变，模型网关调用次数为零；
4. 图谱只返回 30 个保留关键词及其上下文时，不存在悬空边；
5. 正式知识输入只包含 `admitted` 关键词，遗留业务状态不影响结果；
6. 已删除接口不在 OpenAPI 注册并返回 404；
7. 前端生产构建通过，不再请求已删除接口；
8. 指定批次只进行只读核对，写入测试使用隔离数据。
