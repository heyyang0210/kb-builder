# 生成日志目录

本目录记录每次文档生成的日志，用于溯源和审计。

## 日志文件格式

`batch-[YYYY-MM-DD].md` 或 `single-[YYYY-MM-DD]-[知识名称].md`

## 日志内容

每份日志包含：

| 字段 | 说明 |
|------|------|
| 生成时间 | 文档生成的时间戳 |
| 知识点 | 输入的知识点信息（JSON） |
| 使用Skill | 调用的 Skill 文件名 |
| 使用模板 | 调用的模板文件名 |
| 引用资料 | 引用的参考资料列表 |
| 输出文件 | 生成的文档路径 |
| 自检结果 | 结构完整性检查结果 |
| 审阅状态 | 当前审阅状态 |

## 溯源查询

通过日志可以追溯：
- 某篇文档是何时、由哪个 Skill 生成的
- 生成时引用了哪些参考资料
- 生成后的自检结果
- 当前的审阅状态
