# 大纲管理模块工作区

本目录是大纲管理模块的项目执行入口，供 Project Manager、Planner、Worker 和 Reporter 查看路线、门禁、状态与证据。

| 文档 | 用途 |
|---|---|
| [PLAN.md](PLAN.md) | 路线图、RACI、门禁、依赖、并发边界和风险 |
| [PROGRESS.md](PROGRESS.md) | 阶段状态、里程碑证据、阻塞项和下一步 |

产品需求事实源位于 `../../../requirements/modules/outline-management/REQ-OUTLINE-COMPATIBILITY.md`，任务卡位于 `../../tasks/outline-management/`，开发设计位于 `../../../../agent-runner/docs/modules/outline-management/development/`。
