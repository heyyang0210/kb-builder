## 一、模块目标

将当前“直接铺开大量节点和关系”的知识图谱展示升级为一条可观察、可诊断、可取证、可审计的质量治理闭环：

```text
质量概览
  -> 问题定位
  -> 局部图谱
  -> 原文证据
  -> 人工决策
  -> 正式发布
  -> 版本趋势与审计
```

目标架构为“一套图谱事实源、一个诊断上下文、三层业务能力”：

1. REQ-29：质量观测层，解决范围不清、指标不可见和图谱不可读；
2. REQ-30：问题诊断层，解决全局搜索、稳定投影和问题到证据的联动；
3. REQ-31：版本治理层，解决正式版本、差异、趋势和发布检查。
4. REQ-32：原文核验层，解决证据来源解析、原文定位和缺失原因诊断。
