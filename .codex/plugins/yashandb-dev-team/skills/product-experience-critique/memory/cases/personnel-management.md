# 人员管理工作台案例

- 类型：平台管理员使用的管理工作台。
- 证据：真实页面、页面代码、真实 API 和响应式验收。

## 已验证原则

当页面的高频任务是搜索、筛选、编辑和状态维护，低频的新增表单不应长期占据主工作区。弹窗、抽屉或独立流程可以降低干扰，但必须保留预检、冲突提示、导入结果和与已有引用关系相关的风险信息。

## 不适用

- 创建是当前页面唯一核心任务的引导式流程。
- 临时或一次性的导入向工具。
- 用户主要需要批量处理，且常驻新增无法稳定表达风险。
