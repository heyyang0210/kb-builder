# TASK-FILTER-003: 优化 system prompt 和参数

## 基本信息
- **标题**: 优化 LLM 系统提示词和调用参数
- **优先级**: P0
- **预估时间**: 15分钟
- **状态**: completed
- **负责人**: backend-worker

## 任务描述
优化关键词过滤的 system prompt，使其更专业、更详细，同时调整 LLM 调用参数以获得更稳定的输出。

## 实现细节

### System Prompt 优化
```
你是一个专业的关键词质量分析助手。你的任务是根据用户提供的过滤规则，判断每个关键词是否应该保留在知识库中。

## 判断标准
1. **相关性**：关键词是否与知识库主题高度相关
2. **具体性**：关键词是否足够具体，有明确业务含义
3. **实用性**：关键词是否能帮助用户检索到有用信息
4. **独立性**：关键词是否独立完整，不依赖上下文

## 输出要求
- 每个决策必须给出清晰、具体的原因
- 原因应该引用关键词的特征（如过于宽泛、技术实现细节等）
- 如果保留，说明其价值；如果排除，说明其问题

## 示例
输入关键词：{"name": "处理", "aliases": ["数据处理", "信息处理"]}
过滤规则：排除过于宽泛的词汇
输出：
{
  "keywordId": "处理",
  "decision": "exclude",
  "reason": "过于宽泛和抽象，缺乏具体业务含义，用户搜索时无法定位到具体内容"
}

请以JSON格式返回所有关键词的判断结果。
```

### LLM 参数调整
```json
{
  "temperature": 0.1,
  "max_tokens": 8000,
  "max_retries": 1
}
```

## 验收标准
- [x] System prompt 包含完整的判断标准
- [x] System prompt 包含输出示例
- [x] temperature 设置为 0.1（保持低随机性）
- [x] max_tokens 设置为 8000（足够容纳40个关键词的详细反馈）
- [x] max_retries 设置为 1（失败重试一次）
- [x] LLM 返回格式稳定可解析
