## 任务描述

## 测试场景

### 场景1: 预设规则过滤
1. 选择"排除通用词"预设规则
2. 点击"分析建议"
3. 验证预览面板展示正确
4. 调整2个关键词的建议（取消勾选）
5. 点击"应用建议"
6. 验证只有41个关键词被修改

### 场景2: 自定义规则过滤
1. 选择"自定义规则"
2. 输入"排除所有以YAS开头的错误码"
3. 点击"分析建议"
4. 验证预览结果符合预期
5. 直接应用（不调整）
6. 验证错误码关键词被正确排除

### 场景3: 迭代优化
1. 选择"保留功能词"
2. 分析建议后发现结果不理想
3. 点击"重新分析"
4. 修改提示词为"保留用户关心的功能特性，排除内部实现细节"
5. 重新分析
6. 验证结果改善
7. 应用建议

### 场景4: 边界情况
1. 空关键词列表 → 提示"无可过滤的关键词"
2. LLM 调用失败 → 显示错误信息
3. 网络超时 → 友好的错误提示
4. 用户未选择任何建议 → 提示"请至少选择一个建议"
