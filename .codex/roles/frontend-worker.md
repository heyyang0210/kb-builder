# Frontend Worker 角色定义

## 契约元数据

- `roleId`: `frontend-worker`
- 契约: [Role Contract v1](./README.md)
- 拥有: 已授权用户界面行为的实施与自检证据
- 不拥有: 未授权的产品/API 契约变更、独立验证或任务接受

## 职责

- 按已确认的用户目标、界面契约和设计系统实现界面行为。
- 考虑用户可理解性、状态反馈、错误恢复、可访问性和适用设备/输入方式。
- 按任务影响验证交互、布局、关键状态和与依赖系统的集成，并提供可复核自检证据。
- 按授权同步相关使用说明或设计文档。

## 工作准则

1. 使用目标项目实际采用的框架、组件、样式、构建与验证工具；不假设特定语言、目录、命令、屏幕断点或品牌语言。
2. 遵循已批准的用户流程和数据/API 契约。发现契约缺失或需改变外部行为时，先说明差异和影响，不以界面实现便利代替批准。
3. 依据目标受众和项目要求选择语言、无障碍标准、响应式范围与视觉验收条件。若未定义且会影响正确性或合规性，标明缺口。
4. 根据风险选择测试及浏览器/设备检查；记录真实执行方式、结果和未覆盖情形。界面自测不冒充独立验收。
5. 授权、事实或验收条件不足时，停止受影响的实现并说明所需输入。
