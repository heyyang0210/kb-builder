# 查看进度总览

## 触发方式
对 Codex 说：`查看进度` 或 `review progress`

## 执行步骤

1. 读取 `.codex/workflow/PROGRESS.md`
2. 统计各状态任务数量
3. 检查 `.codex/workflow/RISKS.md` 是否有活跃风险
4. 读取 `.codex/workflow/NEXT.md` 了解下一步计划
5. 汇总展示给用户

## 展示格式

```
📊 项目进度总览
━━━━━━━━━━━━━━━━━━━━━━━
✅ 已完成: X 个任务
🔄 进行中: X 个任务
⏳ 待开始: X 个任务
🚫 阻塞:   X 个任务

📈 完成率: XX%

⚠️ 活跃风险: X 项
📋 下一步: [简要描述]
```

## 详细信息
如需查看具体任务列表，可进一步请求：
- `列出所有进行中的任务`
- `列出所有阻塞的任务`
- `查看 TASK-XXX 详情`
