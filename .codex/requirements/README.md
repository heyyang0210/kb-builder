# 产品与模块需求

本目录是业务需求的单一事实来源。需求描述用户、场景、价值、范围、规则和验收，不承载接口实现与动态项目状态。

一般模块需求位于 `modules/<moduleId>/`。需要跨需求、设计、任务、测试和验收进行长期建设的专项，可以在 `.codex` 下建立独立中文工程档案目录；当前入口为 [知识中心建设平台工程档案](../知识中心建设平台/README.md)。模块标识及文档类型规则见 `agent-runner/docs/overview/文档架构与模块归档规范.md`。

## 中文表述规范

- `.codex` 下新增或修改的需求、任务、计划、进度、风险、审查和报告正文统一使用中文。
- 状态、角色、决策、验收结论和风险等级使用中文名称；稳定文件名、模块标识、需求编号及必要技术缩写可以保留。
- 首次出现不可替代的英文技术术语时，应同时给出中文含义，避免用英文术语代替业务说明。
