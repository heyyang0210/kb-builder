# 开发任务目录

本目录保存知识中心建设平台的规划、设计、开发、测试准备、缺陷修复和文档同步任务。

本目录文档统一采用“知识中心-模块名-具体功能特性-开发任务文档.md”命名。

| 任务 | 状态 | 用途 |
|---|---|---|
| [知识中心-平台-建设需求规划-开发任务文档](./知识中心-平台-建设需求规划-开发任务文档.md) | 已完成 | 规划总体需求结构、能力地图、决策边界和交付路径 |
| [知识中心-平台-总体概要设计-开发任务文档](./知识中心-平台-总体概要设计-开发任务文档.md) | 已完成（设计交付，待评审） | 形成总体模块划分、手册目录编排流程与前端一级业务导航设计 |
| [知识中心-平台-AI协同开发与设计基线-开发任务文档](./知识中心-平台-AI协同开发与设计基线-开发任务文档.md) | 待执行（P0） | 规定全局架构基线、模块关系、垂直切片、AI 任务上下文、真实验证和设计反哺流程 |
| [知识中心-审核发布与GitLab授权-未完成任务交接文档](./知识中心-审核发布与GitLab授权-未完成任务交接文档.md) | 待接手（3 项高价值需求，工程保障与外部依赖另列） | 聚焦数据库专项 AI 审核证据、修改意见与版本血缘追溯、发布前风险确认与版本门禁，并保留工程实施明细 |

任务必须使用中文文件名和中文正文，并声明责任角色、依赖、文件归属、确认门禁和可验证验收标准。代码任务必须先引用已批准的详细设计。

本目录保留已完成任务作为执行追溯，不移动到其他阶段目录；后续决策与冲突修订以 `07-决策与风险` 为准，并在任务正文补充对账说明。
