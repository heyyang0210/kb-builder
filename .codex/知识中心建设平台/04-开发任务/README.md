# 开发任务目录

本目录保存知识中心建设平台的规划、设计、开发、测试准备、缺陷修复和文档同步任务。

| 任务 | 状态 | 用途 |
|---|---|---|
| [知识中心建设需求规划任务](./知识中心建设需求规划任务.md) | 已完成 | 规划总体需求结构、能力地图、决策边界和交付路径 |
| [知识中心总体概要设计任务](./知识中心总体概要设计任务.md) | 已完成（设计交付，待评审） | 形成总体模块划分、手册目录编排流程与前端一级业务导航设计 |

任务必须使用中文文件名和中文正文，并声明责任角色、依赖、文件归属、确认门禁和可验证验收标准。代码任务必须先引用已批准的详细设计。
