# 平台管理 MCP 服务管理后续优化

2026-10-23。本轮已交付平台单共享服务管理，复用原生成器配置、加密和客户端。以下未实现项不冒充现有能力。

| 优先级 | 优化项 | 当前限制与验收条件 |
|---|---|---|
| P0 | 统一旧生成器配置入口权限 | 新平台接口有管理员保护，原 `/api/config/*` 沿用旧部署边界。统一鉴权或关闭兼容写入口后，所有入口验证未登录401、非管理员403；迁移前确认兼容调用者。 |
| P0 | 生产密钥治理 | ConfigManager 仍有默认加密密钥回退。要求受管密钥、轮换和失败封闭；迁移应验证旧密文可回读并可回退，不直接改写当前真实密文。 |
| P1 | 多服务与业务引用绑定 | 单共享服务无法同时独立配置设计、测试、知识库等MCP。新增服务ID、用途/权限/工具映射后，验证不同引用来源不会串用端点或凭据。 |
| P1 | 跨进程原子版本与历史审计 | 当前进程内排队，版本检查与文件写入不构成跨进程事务；只记录最后操作者/时间。引入共享事务/文件锁及脱敏变更历史，验证竞争写仅一方成功、可追溯回退。 |
| P1 | 现有配置重复标头整理 | 真实配置有同名条目；客户端原来最后一项覆盖。管理员按目标知识库确认保留项，重填并先测试再保存，不自动猜测其他条目的用途。 |
| P1 | 工具目录与文档适配扩展 | 当前目录为首批 tools/list；AI引用仍使用既有 get_ku_detail/search_ku。补充分页、工具schema/业务映射、兼容性检查和经授权的最小文档读取验收。 |
| P2 | MCP传输与可观测性 | 当前沿用 HTTP POST、单段SSE和既有协议版本；不支持stdio或完整流。补协商/完整SSE、取消、限流、目录大小上限及脱敏错误分类，验证对应协议和故障场景。 |
| P2 | 连接状态与兼容体验 | 测试结果仅本次页面展示；保存可以未测试。按配置版本记录测试摘要，展示过期状态；提供重复标头迁移向导、精确字段错误及更细的异常恢复提示。 |

新增表单数值和数量规则均在 `content-rules.json#/platformMcp`，无新增业务提示词硬编码。HTTP字段、JSON-RPC消息名及协议禁止标头为协议实现常量；原客户端固定协议版本的限制已列入优化。
