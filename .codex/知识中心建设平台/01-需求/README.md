# 知识中心建设平台需求目录

本目录保存 YashanDB 知识中心建设平台的总体需求、模块需求、需求变更和验收口径，描述从文档生成演示工具向单企业、多知识空间、多人协作和全生命周期治理平台演进的业务目标与能力边界。

本目录文档统一采用“知识中心-模块名-具体功能特性-需求文档.md”命名。

本目录中的“能力域”是产品需求分组，不直接等同于代码模块。技术模块拆分、公共 API、存储选型、安全和性能方案需在后续架构阶段单独设计并审批。

| 文档 | 状态 | 用途 |
|---|---|---|
| [YashanDB 知识中心-平台-总体需求-需求文档](./知识中心-平台-总体需求-需求文档.md) | 评审中（0.7.2） | 知识中心总体需求；覆盖资产目录、多人生产、CAS、业务角色叠加、自审约束、增量构建、受控外部连接器及 Linux 文件向 YashanDB 分批迁移路线 |
| [知识中心-平台-llm-wiki接入需求调研文档](./知识中心-平台-llm-wiki接入需求调研文档.md) | 草拟中 | 基于第一性原理和最小可验证闭环，评估将 llm-wiki 类能力接入资料清洗之后知识综合层的边界、需求和验收 |

后续模块需求使用中文文件名，并在正文中分配稳定的中文需求编号。接口、数据结构和伪代码不得写入本目录，应分别归档到概要设计或详细设计目录。

大纲管理的模块化需求已补充至总体需求 7.2；产品业务版本标签、结构版本、稳定节点身份和逆向提取 Agent 的实现契约分别在概要/详细设计阶段冻结。
