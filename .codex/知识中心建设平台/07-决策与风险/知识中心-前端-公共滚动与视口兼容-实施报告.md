# 知识中心-前端-公共滚动与视口兼容-实施报告

> 实施时间：2026-10-12 18:37:18 +0800
> 状态：代码与自动化验收完成；真实旧 WebView 现场认证待完成
> 兼容边界：不识别 `dvh`、但满足平台现有 ES Module 基线的 Chromium/WebView；不包含 IE11

## 1. 结论与根因

缺陷风险确认存在。原应用壳依赖 `100dvh` 建立有界高度，同时锁定 `html/body`，主滚动交给 `.main-shell`。部分旧 Chromium/WebView 忽略动态视口单位后，壳高度退化为内容高度；此时主区没有可滚动溢出，而 document 又被锁定，最终表现为“右侧没有滚轮栏、页面无法向下到达”。本地现代内核支持 `dvh`，所以不复现。

本次没有把问题处理成单点 CSS 补丁，而是建立了公共视口令牌、滚动所有者契约、失效时 document 降级、脱敏诊断和自动化门禁。另在真实浏览器回归中发现并修复手册生产窄中栏操作区溢入助手栏、遮挡全局预览按钮的问题。

## 2. 实现范围

- `common/viewport-runtime.js`：检测 `dvh` 实际可用性；以 `visualViewport.height` 或 `innerHeight` 生成测量回退；监听 resize、方向变化和 visual viewport；使用 animation frame 与 1px 阈值合并更新；销毁时完整清理。
- `common/scroll-runtime.js`：桌面选择唯一 main owner，移动端选择 document；只有应用壳与主区高度有效时锁定 body，异常立即降级；公开 `getScrollOwner`、`inspectScrollRegion`、`inspectScrollContract`；动态渲染后重检；输出不含 id、正文和业务属性的中文几何告警。
- 公共 CSS：`100vh` → 支持时 `100dvh` → 测量令牌；统一 scroll padding/margin 与焦点避让。
- 应用壳在可见前初始化，页面渲染后刷新契约，不改现有页面滚动位置持久化。
- 大纲、生产、审核、仓库高风险区域声明 main/panel/dialog/drawer；资产、平台管理、模板、清洗、登录及公共弹窗/抽屉进入契约扫描。
- 手册生产操作区和选项区允许在窄中栏换行，模板控件可收缩；助手与 Vditor 格式栏注册公共语义。
- 测试入口修正：Playwright 文件优先归入 e2e，避免文件名包含 `contract` 时被静态契约分类吞掉。

## 5. 尚未关闭的边界

- 自动化中的旧 `dvh` 模拟证明回退路径有效，但不能替代客户现场真实 WebView 型号、操作系统、缩放和壳容器组合认证；该项仍是发布门禁。
- 本轮共享全量 E2E 曾存在 GitLab 标签严格性、旧大纲断言、团队 fixture、大纲删除及 Firefox 增量流程等非本变更失败；没有将它们伪报为通过。与本次布局直接相关的生产页失败已经修复并专项复验通过。
- 浏览器或操作系统设置为自动隐藏滚动条时，可能视觉上没有常驻滚动条；验收以滚动能力、内容可达与焦点可见为准。
- 若现场旧内核连现有 ES Module/可选链基线也不支持，需要单独的构建降级方案，超出本次边界。
