## 决策结论

用户已确认以上四项推荐方案，作为本轮前端流程骨架的实施基线：

1. 使用“建立任务、确认输入、生成与修订、按文档审核、整体发布”五阶段主流程；
2. 采用“左侧任务列表 + 中间阶段工作区 + 右侧任务摘要/门禁”的页面布局；
3. 文档生产页只汇总文档级审核状态，具体差异、评论和审核操作复用独立审核工作区；
4. 未接入能力只显示“待接入/不可用”及依赖，不模拟成功、进度或业务数据。

本决策允许开始前端流程骨架实施，但不改变后端业务规则、接口契约、数据库模型或正式发布事务。

## 推荐方案的产品取舍

- 删除：将“外部证据”从 MVP 主进度删除；删除用户手工输入内部 ID 和摘要指纹的前端入口。
- 简化：把同时展开的来源、范围、草稿、检查、审核和发布表单收敛成当前阶段工作区。
- 强化：任务当前状态、唯一主操作、多文档审核状态、发布阻断原因和失败恢复入口。
