# 决策与风险目录

本目录保存产品决策、架构决策、待确认事项、假设、风险、变更申请及影响评估。

本目录文档统一采用“知识中心-模块名-具体功能特性-决策记录文档.md”或“知识中心-模块名-具体功能特性-风险清单文档.md”命名。

每项决策至少记录背景、选项、结论、理由、影响、审批人、日期、失效条件和回退条件；未确认事项不得在需求或设计中伪装成正式结论。

| [知识中心-前端-未完成事项-风险清单文档](./知识中心-前端-未完成事项-风险清单文档.md) | 持续跟踪 | 记录未完成事实源、接口、模块、测试和外部集成风险 |
