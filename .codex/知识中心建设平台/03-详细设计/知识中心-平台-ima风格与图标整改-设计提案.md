用户确认采用资产列表示意的图标体系和界面风格，但明确保留导航、表格、正文、AI 面板和操作按钮。此次只实施品牌区的对齐与底色、24px 页面标题、轻量卡片和空状态容器、表格外状态呈现、普通关闭控件的中性语义及非保留区线性图标。导航图标映射不替换；表格内状态不改色；不调整按钮位置和主次关系，不重组筛选或分页，不压缩或删减已有业务信息。

## 目标与调研边界

借鉴 ima 的中性背景、单色线性图标、轻量导航和内容优先原则，让平台各模块与现有三栏手册工作台形成一致体验。保留 YashanDB 品牌和现有业务信息架构；不复制 ima Logo，不把管理平台改造成问答首页。

本轮走标准开发的设计阶段，主执行者完成界面观察、视觉方案与原型核对。仅登录及只读查看线上页面，未保存草稿、生成内容、提交审核、调整权限或重启服务。

实际加载仓库内 `.codex/plugins/rea/skills/reverse-engineer-anything/SKILL.md` 及连接恢复、运行时观察参考文件；结合全局 ui-ux-pro-max 规范。REA 用于明确观察、推断与未知的证据边界。常规源码核对使用仓库工具，浏览器截图使用 Playwright；不能把普通截图标记为 REA Evidence。REA CLI 诊断情况见末尾证据目录。

## 当前事实与证据

- 服务器 `172.16.91.10:13510` 当前代码为 `6889e84`，4 个组件健康。手册页已显示固定目录、正文与同屏 AI 面板，因此整改以现有新版为基础。
- 实际打开工作台、知识资产、文档生产、手册、模板、大纲、审核列表；DOM 与截图在 `runtime/design/platform-ima-review-20261029/`。平台管理的错误试探路径 `/platform-admin` 回退到了工作台，不作为该模块已调研证据。

- 全局导航：每项都是粗体标题加说明，选中项采用较饱和青蓝底和左侧强色线，信息量和强调程度高于手册页。
- 图标当前已主要使用 Lucide。`common/base.css` 定义默认图标 18px/1.8 笔画；同文件将普通关闭按钮映射到 danger 红色，是需纠正的具体语义问题。
- 图标加载存在固定 1200ms 延后；初次截图出现图标空位，等待后的 assets/outlines/templates/review 页面未渲染占位数均为 0。当前证据支持“加载期间出现空位”，不支持“图标永久缺失”。
- ima 官网匿名入口可访问，可见轻量侧栏、单色图标、浅灰背景和问答内容区域；出现微信登录弹窗，未登录进入笔记/编辑界面。用户前序提供的图 2 是工作台目标参考，不认定为本轮实际观察到的 ima 内部页面。

## 推荐方向

采用“白色内容区 + 浅中性灰导航 + 深灰主文字 + 克制蓝色强调”。现有手册三栏结构作为内容型页面基准，统一平台外壳和公共组件，再逐页收敛。

| 项目 | 当前问题 | 建议 |
|---|---|---|
| 导航 | 双行说明、粗字、强蓝底同时强调 | 常态单行 14px，说明移到悬停提示；浅灰侧栏，选中采用低饱和浅蓝底，移除强色竖线 |
| 品牌 | 品牌和工具按钮挤在同一视觉层级 | 保留平台图标，品牌区独立对齐；折叠按钮统一到中性无边框图标按钮 |
| 页面标题 | 标题区和表格工具区节奏不统一 | 列表页单一标题行，标题 24px；唯一主要动作置右；说明按需显示 |
| 操作按钮 | 主操作有蓝色实底、文字、描边等多套表达 | 每个作用域突出一个主要动作；建议常规主要动作用深灰实底，AI 执行用克制蓝色，其他操作用中性描边/文字 |
| 表格 | 控件多层堆叠，粗蓝链接过密 | 搜索和常用筛选一行，更多筛选渐进展开；分页放表尾；名称常态深灰、悬停强调；保留完整列配置与键盘可访问性 |
| 卡片 | 边框、嵌套和大空白占用注意力 | 白底、细灰线、6–10px 圆角；非浮层少用阴影；只在内容需要分组时使用卡片 |
| 状态 | 蓝色兼任选中、已发布、链接等含义 | 已发布绿、处理中蓝、待处理灰、风险琥珀、失败红，同时显示状态文字；颜色不可替代语义 |
| 关闭/删除 | 普通关闭使用危险红 | 关闭用中性灰 x，删除才用 trash-2 和危险色；退出、返回、收起各用独立语义 |
| 正文 | 阅读、模板、审核存在样式差异 | 共用正文排版、表格、代码、链接规范；正文 16px/1.8，标题有明确级差，长文限制可读宽度 |
| AI 面板 | 辅助说明、来源与设置权重接近 | 保持同屏面板；写作要求、来源、候选结果依次组织；高级设置折叠，默认 MCP 来源保持可见可解释 |

“缺失数据如何补齐”属于业务能力范围，本提案只调整其展示：事实未知用中性“数据暂未就绪”，不显示假数字、假成功，也不把缺失当空结果。工作台零失败状态不再使用整块红色告警。

## 图标映射与规范

沿用已在平台交付的 Lucide，优先修正语义和一致性，无需为接近 ima 再引入第二套图标库。下面是建议映射，确认后通过公共映射统一使用。

| 场景 | 当前/现状 | 建议图标 | 说明 |
|---|---|---|---|
| 工作台 | layout-dashboard | layout-dashboard | 保留 |
| 知识资产 | library | library | 保留，避免与单本手册混淆 |
| 大纲管理 | list-tree | list-tree | 保留树形语义 |
| 模板管理 | files | panels-top-left | 表达版式；若实测认知不佳，保留 files |
| 文档生产 | workflow | file-pen-line | 与面向用户的文档编写一致，流程图标留给任务流 |
| 审核与发布 | badge-check | clipboard-check | 强调待处理审核；发布动作内部用 send 或 upload |
| 资料清洗 | filter | filter | 保留 |
| 平台管理 | settings | settings-2 | 简化视觉，与参数设置语义统一 |
| 手册 / 章节 / 文档 | 多处局部定义 | book-open / folder / file-text | 同类对象跨模块用同一图标 |
| AI / 搜索 / 更多 | sparkles 等 | sparkles / search / ellipsis | AI 装饰不使用彩色渐变底或额外徽章 |
| 关闭 / 返回 / 收起 / 删除 | 部分样式混用 | x / arrow-left / panel-left-close / trash-2 | 图标与动作一一对应 |

建议尺寸：导航 20px、工具栏 18px、行内 16px；24×24 viewBox，圆端点，笔画 1.65–1.75。图形尺寸与点击热区分开，触屏目标至少 44px。中性默认色、悬停加深、选中跟随文字色；有文字的装饰图标 aria-hidden，纯图标按钮必须有中文可访问名称及选中/展开状态。

优先解决首屏加载空位：检查图标库就绪后的所有渲染入口，避免延迟策略造成空按钮；预留图形尺寸、保留可访问名称，并对动态创建节点补绘。采用哪种加载方式需实施时测量，不能为图标统一直接拖慢正文首屏。

以上不是 ima 测量值。中文优先使用系统无衬线字体；不新增外网字体依赖。当前已有 token 基础，实施应集中更新 tokens.css 和公共组件；模块不得散落硬编码色值、尺寸或提示规则。所有配色仍需在实际组合上验证普通文字对比度至少 4.5:1。

## 分阶段实施建议

1. 第一批：公共 token、导航、按钮、关闭控件、图标映射与首屏图标稳定性；用知识资产页和手册页验证共同风格。
2. 第二批：统一列表/筛选/分页/状态标签，将模板、大纲、生产、审核套入公共规范；平台管理与资料清洗需先补对应真实页面走查。
3. 第三批：工作台信息权重，正文/代码/表格、加载/无权限/错误/空状态，AI 来源卡片与高级设置等细节。

每批均需真实 API 与浏览器验证，覆盖 1440px 桌面和 390px 窄屏、阅读/编辑/AI、弹窗和键盘操作；截图不得停在图标未加载的过渡态。业务状态、权限判断、人工采用和手动保存语义不随视觉整改改变。
