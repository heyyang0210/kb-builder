# 知识中心平台页面风格整改（原始实施记录）

> 本文保留 2026-10-30 的批准范围、外观规格和验证结果，不作为所有新页面的通用规则。现行原则见[页面风格原则](<../12-开发原则 & 术语/知识中心-平台-页面风格设计原则与基本要求.md>)。

日期：2026-10-30。适用范围：知识中心管理平台的页面外观与新增页面设计。来源：[ima 风格与图标整改提案](./知识中心-平台-ima风格与图标整改-设计提案.md)及用户确认的资产列表示意图。ima 匿名页仅提供方向参考，不作为其内部设计系统的测量依据。

## 一、原则和边界

1. 内容优先。以白色内容表面、浅中性背景、细边线建立层级；标题、状态、下一步操作清晰可扫读。仅在需要区分独立内容时使用卡片，非浮层不依赖装饰性阴影，不嵌套卡片。
2. 语义优先。蓝色表示工作中的强调或链接，绿色表示明确成功或发布，红色用于真实失败和破坏性操作；未知、未就绪和零失败保持中性。颜色始终配合文字，不以颜色替代业务状态。
3. 保留品牌。使用现有 YashanDB 标识和中文产品名称；借鉴 ima 的克制与单色线性图标，不复制其 Logo、业务结构或问答首页。
4. 视觉与业务分离。外观整改不得增删功能、字段、入口、权限、状态、API 或操作顺序。状态展示依据服务端或既有业务状态值，不能从中文文案猜测。
5. 本次确认的保留区：导航、表格、正文、AI 面板、操作按钮均保持现有布局、颜色、字号、图标与交互。此原则文档不能反向授权修改这些区域；后续调整须有新的明确范围确认。

## 二、基础规格

| 对象 | 基本要求 |
|---|---|
| 外观令牌 | 使用 `common/appearance.css` 的 `--appearance-*` 独立令牌；白色 `#FFFFFF`、浅灰 `#F7F8FA`、边线 `#E6E8EB`、主文 `#25262B`、次文 `#606671`、强调蓝 `#335C98`。不覆盖全局 `--color-*`，避免保留区串色。 |
| 页面标题 | 顶层页面标题 24px、行高 1.35；正文、AI、卡片内标题沿用各自规范。标题与工具区保持清晰分隔，不能因固定高度裁切长中文。 |
| 容器 | 普通内容容器白底、1px 细灰边、8px 圆角，无装饰阴影；空状态只保留一层容器，不改变说明和恢复操作。 |
| 间距 | 优先沿用既有间距令牌和 4/8/12/16/24/32px 节奏；调整容器留白前检查窄屏与数据密集页。 |
| 状态 | 表格外状态可用浅底文字标签；处理中蓝、已发布绿，未知灰，真实失败红。表格内状态属于保留区，不套用外观标签。 |
| 图标 | 沿用本地图标库 Lucide 的单色线条。非保留区建议 18px、约 1.7 笔画；导航、按钮、正文和 AI 原尺寸保留。图标必须预留尺寸，动态节点在图标库就绪后补绘，避免首屏空位。 |
| 关闭动作 | 非保留区普通关闭 X 用中性色；删除、停用等破坏性操作继续使用明确危险语义。关闭不改变既有点击区、键盘行为或焦点返回。导航、正文和 AI 内关闭控件保持现状。 |

## 三、可访问性与响应式

- 页面展示使用中文；装饰图标设 `aria-hidden`，纯图标按钮提供中文可访问名称，切换类控件保留当前展开或选中状态。
- 普通文字与背景对比度至少 4.5:1，非文字状态边界和图标至少 3:1；不能只用颜色表达状态。焦点提示可见，触屏可操作目标至少 44px，已有受保护控件尺寸不因本轮改变。
- 桌面和 390px 窄屏均不得产生新横向溢出、文字截断或内容遮挡；尊重系统减少动态效果设置。中文长标题、空态、加载和错误信息均要在实际内容下检查。

## 四、实施与验收

外观改动集中在独立样式层；模块仅添加必要的显式状态或风险标记，不写新的业务判断。变更前核对功能清单和保留区；变更后用真实登录及只读 API 检查桌面、窄屏和实际数据，目视截图，并在同一 DOM 上开关外观层比较保留区计算样式。不得把视觉稿中的示例数据当作真实页面事实。

本次实施证据保存在 `runtime/design/platform-style-20261030/`：七个模块的 1440px/390px 浏览器截图与同页样式对照；导航、表格、操作按钮等已覆盖保留节点的差异均为 0，窄屏无新横向溢出。手册正文与 AI 的实际页面验证以该目录的 `verified-handbook.json` 为准。仅验证本地工作树静态资源与本机真实 API 的组合，未部署到远端平台。

## 五、第二轮容器补齐（2026-10-30）

本轮按用户要求完成多角色需求、视觉和独立验收。允许调整资产列表与详情工作区外层，以及平台治理统计、人员统计、平台事实、数据库连接和运行信息等非交互容器的边色、8px 圆角与装饰阴影。保持白底、既有内边距、宽高和内部排版，不向子元素继承新的文字或交互样式。治理操作记录容器内含表格，仅调整外边线、圆角与阴影，背景维持原白；人员目录表格容器排除。

资产阶段统计区实际使用导航链接，模板项也是按钮式导航，审核证据区包含 AI 和导航，因此整体排除。本轮不改页面标题字号：平台管理标题紧邻页签导航，改变行盒高度可能使保留区移位；标题统一须在后续单独确认导航位置。验收对同一 DOM 的本轮前后样式与控件几何进行桌面、390px 窄屏比较，覆盖实际登录与只读 API；容器视觉另行截图复核。

验收结果：`runtime/design/platform-style-round2-20261030/` 保存冻结基线、浏览器脚本、截图和 `verification.json`。16 个页面/场景在 1440px 与 390px 共 32 组中，保留区计算样式与几何差异均为 0；无新横向溢出、未替换图标或页面脚本错误。真实手册 DB-004 的正文与 AI 页面已覆盖。`containers.json` 实测治理摘要 3 项、数据库连接面板 1 项、打开抽屉后的运行卡 1 项、人员统计 4 项均命中边线 `#E6E8EB`、圆角 8px、无阴影。平台事实与非目录治理记录在当前数据下没有渲染，尚无实际页面命中证据。只验证本地工作树和本机只读 API，未部署。

### 图标效果与部署证据补正

本轮没有整套替换图标形状。非保留区主要调整 Lucide 线宽和色彩，不能将“图标占位为零”或“保留区差异为零”当作图标整改完成的正向证据。`icon-proof.json` 使用同一 DOM、关闭过渡动画后开关外观层实测：空态 blocks 图标由 `#0369A1` 改为 `#606671`，线宽从 1.8 调为 1.7；资产列表外壳圆角由 0px 调为 8px。内嵌图片对照页为 `runtime/design/platform-style-round2-20261030/外观与图标实测对照.html`。
