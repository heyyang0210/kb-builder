# 详细设计目录

本目录保存经批准模块的详细设计，包括接口契约、数据结构、状态机、业务不变量、伪代码、异常处理、并发策略、权限校验、配置、兼容、迁移和测试设计。

详细设计必须引用对应需求与概要设计；设计未批准前不得进入功能代码开发。

本目录文档统一采用“知识中心-模块名-具体功能特性-详细设计文档.md”命名；模块名和功能特性必须能从文件名识别，避免使用无法表达业务边界的缩写。
