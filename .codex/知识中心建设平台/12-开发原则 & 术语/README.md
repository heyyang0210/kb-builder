# 开发原则与术语

本目录只保存两类当前依据：**开发原则**说明在什么范围做什么、怎样判断遵守；**术语表**定义平台对象和统一名称。字段格式、伪代码、候选方案、案例和历史验收分别放在设计、审查与治理档案中。每条现行规则只维护一份正文。

开发原则进入本目录前必须同时满足：一句话能说清主要要求；写明适用范围；给出可执行动作；说明如何检查；长期有效或明确有效期；与其他规则的关系清楚。缺一项先补齐，不把设计草案当成现行原则。
