## 对知识中心平台的参考价值

1. **知识采集与引用**：Firecrawl、Crawl4AI、RAGFlow 值得比较文档抽取、更新和来源追踪。优先验证权限过滤、引用可回读与失效源处理，不能用抓取成功代替知识正确。
2. **工作流与治理**：Dify、Langflow、Flowise、OpenHands、browser-use 可参考任务编排与人工接管。平台现有工单、审核、MR 权限链不能因为引入 Agent 而绕过具名责任与审计。
3. **模型服务与质量**：Ollama、vLLM、Transformers、Unsloth、LlamaFactory 分别对应本地试验、服务推理和微调。先按现有模型接口做延迟、失败恢复、数据边界与成本对比，再决定是否接入。
4. **前端首版质量**：Impeccable、Hallmark 的检查思路可用于设计走查，但最终门禁仍应是当前平台真实页面、权限、响应式和端到端任务结果。

本次仅做公开仓库调研，没有安装仓库、运行其代码，也没有对其安全性、性能或生产适用性做实测。
