## 2026-11-12 晚间失败复现与 Agent + Skill 边界

用户给定的 `27.1.1 版本需求` 基线第 1 页只读读取返回 50 条 IR、60 条关联 SR；第 5 页返回 HTTP 422，具体为 `YASHAN-4241` 声明 1 条关联、结构化关系接口返回 0。阻断点是来源中的 IR→SR 关系数量不一致。平台同步服务之前只解析 `detail` 字段，而 Pingcode API 使用 `error` 信封，导致具体错误码被改写为 `PINGCODE_READ_FAILED`；本轮补齐解包并加入合成 HTTP 回归测试。诊断仅返回编号与数量，不包含正文或凭证。
