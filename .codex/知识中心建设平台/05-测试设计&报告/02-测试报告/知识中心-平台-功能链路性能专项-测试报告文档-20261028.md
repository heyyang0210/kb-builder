# 知识中心功能链路性能验收报告（2026-10-28）

本报告承接“按功能模块，从用户操作到界面变化逐步计时”的纠偏；替代旧报告中只测页面外壳就认为模块可用的口径。旧API、并发与外壳样本保留为历史诊断，不与本轮功能链路样本合并。

本轮主要结果：目录展开214–284 ms、正文就绪626–909 ms、专用草稿保存4.01–5.09秒、AI采用保存4.25–6.69秒。AI点击后反馈42–46 ms，真实生成完成102–140秒；提交接口自身仍需18.2–22.3秒。69种操作中37种三轮均满足当前预算，32种未通过。外部发布、界面导入发布及清洗加工等缺口仍未验收，详见下文逐项清单。

## 测试口径

- 当前运行实例 `http://127.0.0.1:13510`，真实 Chromium、真实后端、真实AI服务；使用新建的专用手册、大纲、模板、草稿和上传文件。未模拟产品接口或模型响应。
- 逐模块串行连续操作，逐步等待业务语义终态；每一步从真实 click/input/change 事件开始，记录指定反馈与成功可操作状态满足后的两帧绘制机会。截图、测试准备、Playwright自动等待不计入响应时间；不宣称测到了显示器扫描出的第一个像素。
- 预算暂按专项配置：交互指定反馈≤200ms、普通操作成功就绪≤500ms、真实AI完成≤120000ms；模型全文完成不是毫秒指标，但点击生成后的提交反馈仍须≤200ms。该预算用于暴露问题，不代表已经取得产品SLO批准。
- 每步3个样本，P95最近秩等于本组最大值，属于探索性验收，不能推断稳定生产P95或容量。第一轮为新浏览器会话首次访问，未清数据库或服务缓存。
- 失败、接口异常和未执行步骤全部保留；真实AI错误提示不能算生成成功。保存和采用需额外真实API回读正文并按既有Markdown规范化契约比较，回读校验不占界面时间。
- 未配置独立早期反馈的步骤，反馈列是首个指定终态；不会把该值表述成所有中间界面变化中的最早一帧。

整改按三个阶段验收：先解决草稿/AI任务全局写入与同步I/O、编辑器切换丢失和弹窗状态丢失；随后压缩工作台、大纲和文档的读取与渲染范围；最后在专用外部仓库、专用审核身份与隔离配置环境补齐未验收业务。每阶段必须在实际运行构建重跑对应连续链路，保留首轮失败；全部步骤完整、所有预算通过且覆盖缺口为零后，才可给出全功能通过结论。AI全文耗时应单独约定完成SLO，同时约束任务提交和状态读取，不能以“AI本来慢”为由接受秒级阻塞。
