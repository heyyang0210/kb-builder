# 工作台单页体验与统计优化验收（2026-11-05）

## 结果

按已确认的方案二，保留同一浏览器标签内的单页导航。工作台顶部显示“我的工作总量 = 待我处理 + 跟进中”；可执行事项继续按原类别筛选，跟进工单仍单独展示，不计入待办类别。截图所示示例对应 3 项总量、2 项待处理、1 项跟进中。

读取来源由四个减为三个：任务管理、本人审核和领域分派。模板列表没有个人指派接口，本轮停止为工作台读取模板摘要。页面先显示已有投影或框架；来源结果合并到浏览器绘制帧，更新变化的统计、分类列表、跟进区及来源提示，不重建搜索输入和整页。平台上下文更新不再重建工作台；旧请求不能覆盖新请求，打开的详情不被迟到来源关闭。
