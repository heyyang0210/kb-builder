## 回归修正原则与边界

旧用例因页面入口、接口参数、保存状态文案、测试实体及准入阶段前提变化而失败时，核对实际实现与已确认需求后修正测试，保留原行为断言。未降低性能预算、未删除失败用例。报告分别记录产品缺陷、测试问题、环境限制和跳过场景。

Jest 覆盖率仅表示其采集的 JavaScript 范围，不代表 Python、独立 Node 脚本、Playwright 或整个仓库的覆盖率。真实第三方 GitLab 写入及生产环境权限配置不由本轮隔离验证证明。
