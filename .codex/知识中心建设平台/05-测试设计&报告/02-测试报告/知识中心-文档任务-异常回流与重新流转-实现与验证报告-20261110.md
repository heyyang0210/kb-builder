# 文档任务异常回流与重新流转实现与验证报告

日期：2026-11-10
结论：**部分完成；隔离 HTTP 验证通过，外部通知与生产联验未完成。**

## 实施范围

- 工单及手册层可创建范围纠偏请求；明确受影响文档会暂停其完成投影，并可在预览后按版本和影响摘要确认或取消。
- 影响预览检查审核/MR 与远端观察时效。打开 MR 必须人工关闭后重新观察；状态未知或观察过期拒绝确认，不自动关闭或合并。
- 确认撤出已合并文档时生成发布内容核对待办；“无需修复”要求目标提交、正文和图片均验证，“需要修复”保持未完成，修复交付须关联同手册/文档的完整回读记录。
- 审核页提供当前审核关联手册的结构化选择。服务端用有效任务范围解析手册和负责人，忽略客户端提交的收件人身份；评论中保存提及快照和通知事件状态。
