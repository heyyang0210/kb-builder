# 测试设计与报告目录

本目录是知识中心建设平台测试资产的单一入口：`01-测试设计`保存策略、分层、公共命令和验收契约；`02-测试报告`保存真实执行结果、接口证据、性能结论和历史截图。

测试报告必须区分“未执行、执行失败、条件通过、通过”，并提供环境、输入、步骤、实际结果和证据位置。设计评审不能替代测试执行。
