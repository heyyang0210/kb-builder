## 三、重点成果说明

### 1. 质量分析治理能力

本周完成关键词过滤审计、人工复核、问题总览和证据下钻三项治理需求。目标批次保持只读，写入型验收使用隔离数据。已记录的典型 P95 为：AUD 详情/列表 62.87ms/3.59ms，REV 汇总/PATCH 100 条 6.47ms/40.59ms，INS 总览/证据 21.52ms/40.43ms。

当前准确表述是：**实现和组合回归完成，等待用户验收**。

### 2. M2 RAG / 知识治理链路

完成 Source/Schema 组件、规则版本证据、请求时冻结、规则重建内核、API-A 基础接线和生产出口治理包 helper。回归结果为 187 项中 185 项通过、2 项跳过；API-A 真实路由 7/7 通过。

已识别并纳入治理范围的历史问题包括：2,027 个上游 JSON 权限错误信封曾被错误视为成功，以及 55,324 条 legacy candidate 缺少可信 extractor 版本快照。当前已有隔离和版本证据方案，但这些组件证据不能替代真实训练出口、发布 API 和越权回归。

### 3. GraphStore

GraphStore 已完成存储无关契约、本地实现、写入运行和异步投影内核，最终联合回归 42/42 通过，独立验收发现的 5 个 P0 已修复。

当前不能表述为“M8 完成”：公共 API、GraphRAG、外部图数据库及容量、备份、灾备和厂商方案仍未确定；API 验收依赖可信身份参数、隔离测试身份、formal 数据集和写入许可。

### 4. 知识中心平台专项

本周形成从“文档生成 Demo”升级为“知识中心管理平台”的需求基线，核心范围包括知识空间、大纲、模板、多人异步协作、权限、版本、审核发布、来源快照、质量门禁、检索问答、反馈运营、审计和平台运维。

已确认的产品边界：单一企业内部平台；首期章节级异步协作；每个空间可配置一级或多级审核；PingCode 首期只读获取并保存来源快照，GitLab 首期允许知识发布后异步创建文档分支和 MR，不回写 PingCode、不覆盖 GitLab 既有分支或文件；同时预留平台管理下的“集成管理”模块。D-11“哪些版本进入正式知识检索范围”仍待确认；当前建议为仅审核发布版本进入正式检索范围，草稿只允许授权协作者隔离预览。
