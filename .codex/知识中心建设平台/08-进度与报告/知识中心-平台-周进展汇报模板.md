# 知识中心管理平台周进展汇报模板

> 汇报周期：YYYY-MM-DD 至 YYYY-MM-DD
> 汇报时长：5 分钟以内
> 填写原则：降低填写成本、增加透明度、突出进度、聚焦业务

## 一、一页结论（约 1 分钟）

| 判断项 | 结论 |
|---|---|
| 项目状态 | 绿灯 / 黄灯 / 红灯 |
| 当前可用性 | 不可演示 / 内部演示 / 受控试用 / 生产可用 |
| 整体开发进度 | X%（核心功能完成度，需在附录说明分子分母） |
| 本周计划 | 全部完成 / 部分完成 / 未完成 |
| 上线阻断 | X 项 |
| 下个里程碑 | 里程碑名称、目标日期 |
| 需要领导决定 | 无 / X 项 |

**一句话结论：** 本周最重要的业务结果和未完成事项，以及对里程碑的影响。

**当前能做什么：** 用不超过 3 句话说明哪些角色已经能够完成什么工作，不罗列接口、代码或测试框架。

## 二、模块功能开发进展（约 2 分钟）

按模块列出本周进展，**无变化的模块必须写"本周无修改"或"本周无进展"**，让领导看到全貌。

### 1. 模块进展列表

1. **平台管理：** 做了什么，进度 X%，下一步方向（或"本周无进展"）。
2. **知识资产：** 本周无修改。
3. **审核功能：** 本周无修改。
4. **模板管理：** 本周无修改。
5. **大纲管理：** Bug 修复，修复 XXX 问题，进度 X%。
6. **文档生产：** 完成 XXX 功能，可以基于默认模板手动编辑文档（AI 生成功能作为下一阶段），开发进度 50%。
7. **工作台：** 增加 XXX 能力，进度 X%。
8. **知识服务：** 待启动。
9. **平台工程化：** 优化 XXX，测试时间从 X 秒降到 Y 秒。

### 2. 核心业务链路

```text
核心链路：选择手册 → 编辑预览 → 草稿保存 → 来源快照 → 审核 → 发布
当前完成：2/6（33%）
当前阻断：正式草稿保存未实现，阻断后续所有步骤
```

**填写要求：**
- 用业务语言，不用技术术语
- 增加百分比，让领导一眼看到进度
- "当前阻断"要说明"阻断后续所有步骤"，让领导理解严重性

## 三、P0 阻断与计划偏差（约 1 分钟）

### 1. 计划偏差

| 原计划 | 实际结果 | 偏差原因 | 对里程碑的影响 |
|---|---|---|---|
|  |  |  |  |

没有偏差时明确写"本周无影响里程碑的计划偏差"。

### 2. P0 阻断

最多 3 项，只保留阻断下一里程碑的事项。

| 阻断项 | 量化事实 | 责任人 | 承诺日期 |
|---|---|---|---|
|  |  |  |  |

没有责任人或日期时写"待指定/待确认"，并立即进入"需要领导决定"；不得只保留无人负责的问题描述。

## 四、下周计划（约 1 分钟）

### 1. 下周可验收承诺

最多 3 项。计划必须是可验收结果，不使用"继续推进、持续优化、进一步完善"。

| 承诺结果 | 验收标准 | 责任人 | 日期 | 前置依赖 |
|---|---|---|---|---|
|  |  |  |  |  |

### 2. 需要领导决定

最多 3 项；无决策事项时明确写"无"。

| 决策事项 | 推荐方案 | 备选方案 | 不决策的影响 | 最晚决策时间 |
|---|---|---|---|---|
|  |  |  |  |  |

## 模板使用说明

### 修改理由

1. **降低填写成本**：从"三段式"改为"一句话"，从表格改为列表，汇报人填写时间从 30 分钟降到 10 分钟
2. **增加透明度**：要求写"本周无修改"或"本周无进展"，避免汇报人只写有进展的模块，让领导看到全貌
3. **突出进度**：增加百分比字段，让领导一眼看到完成了多少
4. **聚焦业务**：用业务语言，不用技术术语，领导阅读时间从 5 分钟降到 2 分钟

### 填写示例

```markdown
## 二、模块功能开发进展

1. **平台管理：** 优化人员管理功能，添加团队管理（用于技术领域分工），进度 80%，下周完成团队改派权限校验。
2. **知识资产：** 本周无修改。
3. **审核功能：** 本周无修改。
4. **模板管理：** 本周无修改。
5. **大纲管理：** Bug 修复，修复大纲分工与手册生产"只看我负责"视图的断链问题，进度 100%。
6. **文档生产：** 完成手册文档生产工作台编辑体验优化，可以基于默认模板手动编辑文档（AI 生成功能作为下一阶段），开发进度 50%。
7. **工作台：** 增加文档生产"我的生成"真实个人关联能力，进度 100%。
8. **知识服务：** 待启动。
9. **平台工程化：** 优化测试用例并行度和测试时间，从 428 秒降到 300 秒，进度 100%。

**核心链路：** 选择手册 → 编辑预览 → 草稿保存 → 来源快照 → 审核 → 发布
**当前完成：** 2/6（33%）
**当前阻断：** 正式草稿保存未实现，阻断后续所有步骤
```
