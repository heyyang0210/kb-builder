# 进度与报告目录

本目录保存项目路线图、阶段计划、里程碑、进度看板、周报、下一步和交付偏差。

本目录文档统一采用“知识中心-模块名-时间范围-进展报告文档.md”命名。

平台级开发进度总览使用固定入口 [知识中心-平台-开发进展总览-进展报告文档](./知识中心-平台-开发进展总览-进展报告文档.md)，持续汇总 `04-开发任务` 的任务卡和通用化专项进展。`04-开发任务` 保存单项任务执行细节，本目录负责跨模块进度、依赖、阻塞和下一步，不重复维护任务日志。

进度只依据已验证证据更新，不得把“已有需求”“已有设计”或“正在处理”记录为功能完成。

周报和阶段报告是对应时点的历史快照，必须保留原目录和原始事实。后续决策覆盖历史口径时，在原报告追加修订说明，并以 `07-决策与风险` 的批准记录作为当前有效依据。
