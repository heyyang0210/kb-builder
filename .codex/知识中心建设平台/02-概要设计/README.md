# 概要设计目录

本目录保存知识中心建设平台的系统级和模块级概要设计，重点说明建设边界、模块职责、上下游、主流程、数据流、部署视图和关键架构决策。

概要设计不得包含动态任务进度，也不得将拟议技术方案写成已实现能力。涉及新增模块、技术栈、公共接口、外部依赖、安全或性能的方案，必须标记审批状态和回退条件。
