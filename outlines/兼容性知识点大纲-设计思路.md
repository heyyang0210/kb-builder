## 一、大纲定位与目标

### 1.1 核心定位

本大纲是数据库迁移项目的**兼容性检查清单**，目标是帮助迁移工程师系统化地评估和解决源库与目标库之间的兼容性问题。

这是一份**从 Oracle 到目标库（如 YashanDB/PostgreSQL）的迁移实战指南**。

### 1.2 设计原则

1. **检查清单导向**：按数据库对象类型横向展开，便于逐项对照
2. **迁移生命周期驱动**：从 DDL → DML → 查询 → 函数 → 存储过程 → 工具，覆盖完整迁移流程
3. **难度分层**：三级难度标注，帮助读者按场景学习
4. **实用优先**：每个知识点都包含"源库语法 → 目标库替代"的映射关系

```

第2章（DML 兼容性）── 第3章的前置（DML 中嵌入查询）
第3章（查询兼容性）── 独立章节

第6章（工具与接口）── 独立章节，迁移流程的最后环节
```
