## 四、使用方式

### 4.1 作为大模型输入索引

大模型读取本目录时，可按以下优先级：

1. **先读设计思路文档**：了解大纲的定位、目标人群、学习路径
2. **再读大纲文件**：获取具体知识点列表和难度标注
3. **根据需求选择**：根据目标人群和难度要求选择知识点

### 4.2 批量生成知识文档

```bash
# 示例：生成某个大纲的所有知识点文档
for 知识点 in $(grep "^- [0-9]" 共享集群领域知识点大纲.md | head -20); do
    # 构造输入 JSON 并调用 Skill
    echo "生成: $知识点"
done
```
