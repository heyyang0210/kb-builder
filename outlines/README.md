# 知识点大纲目录说明

本目录包含数据库知识点大纲，作为批量生成知识文档的输入源。

## 大纲文件

| 文件 | 说明 |
|------|------|
| `数据库知识点大纲.md` | 完整的数据库知识体系大纲，包含 8 个部分、38 个章节、200+ 知识点 |

## 大纲结构概览

| 部分 | 章节数 | 难度 | 主要内容 |
|------|--------|------|---------|
| 第一部分：数据库基础入门 | 4 | ★ | 数据库概念、关系模型、设计理论、SQL基础 |
| 第二部分：数据库核心原理 | 4 | ★★ | 存储引擎、索引、事务、日志恢复 |
| 第三部分：数据库管理 | 5 | ★★ | 安装配置、用户权限、存储管理、备份恢复、日常运维 |
| 第四部分：SQL编程与开发 | 5 | ★★★ | 高级SQL、存储过程、触发器、动态SQL、游标 |
| 第五部分：性能优化 | 5 | ★★★ | 性能监控、优化器、SQL调优、实例优化、对象优化 |
| 第六部分：高可用与集群 | 5 | ★★★ | 复制、共享存储集群、多主复制、高可用方案、容灾 |

## 使用方式

1. 从大纲中选择要生成的知识点
2. 构造输入 JSON（包含知识点名称、部分、章节、描述）
3. 调用对应的 Skill 生成文档
4. 输出到 `output/` 目录对应子目录

## 批量生成示例

```bash
# 生成第一部分所有知识点
for 知识点 in $(grep "### 1\." 数据库知识点大纲.md | awk '{print $2}'); do
    # 构造输入 JSON 并调用 Skill
    echo "生成: $知识点"
done
```
