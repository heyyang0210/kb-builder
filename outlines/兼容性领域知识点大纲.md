
## 数据库兼容性知识点大纲

### 1. DDL 兼容性
- **1.1 数据类型映射**
  - 1.1.1 字符串类型：`CHAR` / `VARCHAR2` / `NCHAR` / `NVARCHAR2` → 目标库等价类型（含长度语义 byte/char）
  - 1.1.2 数值类型：`NUMBER(p,s)` → `INTEGER` / `DECIMAL` / `NUMERIC` 等
  - 1.1.3 日期时间：`DATE`（含时间） → `TIMESTAMP` / `DATETIME`；`TIMESTAMP WITH TIME ZONE` 等
  - 1.1.4 大对象：`CLOB` / `BLOB` / `NCLOB` → 对应类型
  - 1.1.5 布尔类型：`BOOLEAN`（PL/SQL 中）→ 目标库模拟（`TINYINT`、`BOOLEAN` 支持情况）
  - 1.1.6 自定义类型与集合：对象类型、`VARRAY`、嵌套表 → 目标库替代（JSON/数组/自定义类型）
- **1.2 表定义**
  - 1.2.1 默认值中使用序列：`col NUMBER DEFAULT seq.NEXTVAL` → 自增列/`IDENTITY`
  - 1.2.2 虚拟列/计算列：`col AS (expression)` → 目标库生成列语法
  - 1.2.3 临时表：`GLOBAL TEMPORARY TABLE` → 局部/全局临时表差异（数据可见性、事务级/会话级）
  - 1.2.4 表空间/存储子句：`TABLESPACE`、`STORAGE` 等 → 忽略或映射到目标库对应设置
  - 1.2.5 只读表：`ALTER TABLE ... READ ONLY` → 目标库对应权限或特性
- **1.3 约束**
  - 1.3.1 外键匹配规则：`ON DELETE SET NULL/CASCADE` 等行为差异
  - 1.3.2 检查约束中使用函数：源库允许函数 → 目标库限制（如不可使用 `SYSDATE`）
  - 1.3.3 约束的禁用/启用语法：`ENABLE/DISABLE NOVALIDATE` → 目标库替代方式
  - 1.3.4 约束命名与延迟检查：`DEFERRABLE INITIALLY DEFERRED` 等
- **1.4 索引**
  - 1.4.1 索引类型：B-tree、位图、函数索引、部分索引、全文索引的语法差异
  - 1.4.2 索引选项：`COMPUTE STATISTICS`、`TABLESPACE` 等非标准子句
  - 1.4.3 唯一索引与唯一约束的区别对待
- **1.5 视图**
  - 1.5.1 可更新视图的限制差异（`WITH CHECK OPTION` 行为）
  - 1.5.2 物化视图：刷新方式（`FAST`/`COMPLETE`/`FORCE`）、日志、`ON DEMAND/COMMIT`
  - 1.5.3 带 `ORDER BY` 的视图（部分目标库不支持）
- **1.6 序列与自增列**
  - 1.6.1 `CREATE SEQUENCE` 与 `IDENTITY` 列映射
  - 1.6.2 `CURRVAL` / `NEXTVAL` 的替代方案（`LAST_INSERT_ID()` 等）
  - 1.6.3 序列缓存/周期等参数差异
- **1.7 同义词**
  - 1.7.1 公有/私有同义词 → 无此特性时的替代（视图、别名、`search_path` 等）
- **1.8 分区表**
  - 1.8.1 分区策略：范围、列表、哈希、复合分区语法
  - 1.8.2 分区操作：`ADD/DROP/TRUNCATE/MERGE/SPLIT PARTITION`
  - 1.8.3 子分区模板和间隔分区的支持度
- **1.9 其他对象**
  - 1.9.1 外部表定义差异
  - 1.9.2 注释对象：`COMMENT ON TABLE/COLUMN` → 目标库对应语法

### 2. DML 兼容性
- **2.1 INSERT**
  - 2.1.1 多表插入：`INSERT ALL` / `INSERT FIRST` → 使用多条语句或条件插入
  - 2.1.2 直接路径插入提示：`/*+ APPEND */` → 目标库批量加载方式
  - 2.1.3 `INSERT ... RETURNING` 子句 → 目标库 `OUTPUT` / `RETURNING` 支持
  - 2.1.4 带子查询的插入中省略 `VALUES` 关键字
- **2.2 UPDATE/DELETE**
  - 2.2.1 多表连接更新/删除：`UPDATE ... FROM` / `DELETE ... USING` 语法差异
  - 2.2.2 `UPDATE/DELETE ... RETURNING` 子句
  - 2.2.3 `TRUNCATE TABLE` 行为差异（触发器触发、回滚可能性、外键处理）
- **2.3 MERGE/UPSERT**
  - 2.3.1 `MERGE INTO` 与 `INSERT ... ON CONFLICT` / `REPLACE` 映射
  - 2.3.2 条件匹配差异（Oracle 可多次匹配，部分目标库只匹配一次）
  - 2.3.3 `MERGE` 中的 `DELETE` 子句支持度
- **2.4 锁与并发**
  - 2.4.1 `SELECT ... FOR UPDATE` 语法与选项（`WAIT`/`NOWAIT`/`SKIP LOCKED`）
  - 2.4.2 表级锁语法：`LOCK TABLE ... IN ... MODE`

### 3. 查询兼容性
- **3.1 SELECT 子句**
  - 3.1.1 行限制：`ROWNUM` / `FETCH FIRST` / `TOP` / `LIMIT` 语法差异
  - 3.1.2 别名使用：`AS` 关键字可选性、别名在 `WHERE` 中引用
  - 3.1.3 虚表访问：`SELECT ... FROM DUAL` → 目标库无 `DUAL` 时的替代
  - 3.1.4 `SELECT` 中不带 `FROM` 的支持度
- **3.2 连接**
  - 3.2.1 旧式外连接：`(+)` → `LEFT/RIGHT/FULL OUTER JOIN`
  - 3.2.2 `CROSS JOIN`、`NATURAL JOIN` 支持度
  - 3.2.3 `PARTITION BY` 外连接（Oracle 特有）→ 模拟或声明补齐
- **3.3 子查询**
  - 3.3.1 多列子查询（如 `WHERE (a,b) IN (SELECT ...)`）
  - 3.3.2 相关子查询在 `SELECT` 列表中
  - 3.3.3 `WITH` 子句中的相互递归（`WITH RECURSIVE`）
- **3.4 集合操作**
  - 3.4.1 `MINUS` → `EXCEPT`；`INTERSECT` 行为差异（重复行处理）
  - 3.4.2 集合操作中的 `ORDER BY` 位置与别名引用
- **3.5 公用表表达式（CTE）**
  - 3.5.1 `WITH` 子句的递归语法（`WITH RECURSIVE`）
  - 3.5.2 物化/非物化提示差异
  - 3.5.3 CTE 在 DML 中的使用（如 `WITH ... INSERT`）
- **3.6 层次查询**
  - 3.6.1 `CONNECT BY PRIOR` / `START WITH` → 递归 CTE 改写
  - 3.6.2 层次伪列/函数：`LEVEL`、`SYS_CONNECT_BY_PATH`、`CONNECT_BY_ROOT`、`CONNECT_BY_ISLEAF` 替代
  - 3.6.3 层次查询中的排序（`ORDER SIBLINGS BY`）
- **3.7 PIVOT / UNPIVOT**
  - 3.7.1 `PIVOT` 关键字语法差异（Oracle vs SQL Server）
  - 3.7.2 无 `PIVOT` 时使用 `CASE + GROUP BY` 替代模式
  - 3.7.3 `UNPIVOT` 对应转换
- **3.8 分析/窗口函数**
  - 3.8.1 基础窗口函数：`ROW_NUMBER` / `RANK` / `DENSE_RANK` / `LEAD` / `LAG` 参数差异
  - 3.8.2 窗口子句（`RANGE` / `ROWS`）默认行为与边界处理
  - 3.8.3 聚合扩展：`KEEP (DENSE_RANK FIRST/LAST)`、`LISTAGG` 窗口化等
  - 3.8.4 窗口函数中的 `EXCLUDE` 子句等高级特性
- **3.9 行模式识别**
  - 3.9.1 `MATCH_RECOGNIZE` → 目标库支持度极低，标注为需补齐特性或改用复杂 CTE
- **3.10 其他查询特性**
  - 3.10.1 闪回查询（`AS OF TIMESTAMP`）→ 时态表或日志替代
  - 3.10.2 `SAMPLE` 子句采样 → 目标库 `TABLESAMPLE` / `RANDOM()`

### 4. 函数与操作符兼容性
- **4.1 字符串函数**
  - 4.1.1 拼接：`||` vs `CONCAT`（参数个数限制）
  - 4.1.2 截取：`SUBSTR` → `SUBSTRING`（起始位置与长度语义）
  - 4.1.3 正则：`REGEXP_LIKE` / `REGEXP_REPLACE` / `REGEXP_SUBSTR` / `REGEXP_INSTR` → 目标库正则函数
  - 4.1.4 `INSTR` → `POSITION` / `CHARINDEX`
  - 4.1.5 `INITCAP`、`LPAD` / `RPAD`、`TRANSLATE`、`REPLACE` 等函数差异
  - 4.1.6 `LISTAGG`（作为聚合函数）→ `STRING_AGG` / `GROUP_CONCAT`，及其分隔符和排序
- **4.2 数值函数**
  - 4.2.1 `TRUNC`（数值）与 `FLOOR`/`CEIL` 行为
  - 4.2.2 `MOD` 负数行为差异
  - 4.2.3 `ROUND` 精度处理
  - 4.2.4 `BITAND` 等位运算函数 → `&` 操作符或函数
- **4.3 日期时间函数**
  - 4.3.1 当前时间：`SYSDATE` / `SYSTIMESTAMP` → `CURRENT_TIMESTAMP` / `NOW()`
  - 4.3.2 日期运算：直接用 `+1` 加一天 vs 要求 `INTERVAL` 关键字
  - 4.3.3 `ADD_MONTHS` / `LAST_DAY` / `MONTHS_BETWEEN` / `NEXT_DAY`
  - 4.3.4 `TRUNC`（日期）截断 → `DATE_TRUNC`
  - 4.3.5 `EXTRACT` 函数差异
  - 4.3.6 时区相关函数：`FROM_TZ`、`AT TIME ZONE` 等
- **4.4 转换函数**
  - 4.4.1 `TO_CHAR` / `TO_DATE` / `TO_NUMBER` → `CAST` / `CONVERT` / `STR_TO_DATE`
  - 4.4.2 格式掩码差异（`YYYY` vs `YY`、`FF`、`RR` 等）
  - 4.4.3 `CAST` 在类型转换限制上的差异
- **4.5 空值处理**
  - 4.5.1 `NVL` → `COALESCE` / `IFNULL`
  - 4.5.2 `NVL2` → `CASE` / `IIF`
  - 4.5.3 `DECODE` → `CASE` / `IIF`
  - 4.5.4 `LNNVL`、`NULLIF` 等
- **4.6 聚合函数**
  - 4.6.1 `LISTAGG` → `STRING_AGG` / `GROUP_CONCAT`
  - 4.6.2 统计聚合：`PERCENTILE_CONT` / `PERCENTILE_DISC`、`STATS_MODE` 等
  - 4.6.3 `MEDIAN` → `PERCENTILE_CONT(0.5)`
  - 4.6.4 聚合函数 `FIRST` / `LAST` 的 `KEEP` 子句
- **4.7 加密与哈希函数**
  - 4.7.1 `DBMS_CRYPTO` 包函数 → 目标库加密函数（`pgcrypto`、`ENCRYPT` 等）
  - 4.7.2 `STANDARD_HASH`、`DBMS_OBFUSCATION_TOOLKIT` 等
- **4.8 JSON/XML 处理函数**
  - 4.8.1 JSON 提取：`JSON_VALUE`、`JSON_QUERY`、`JSON_TABLE` → 目标库操作符（`->>` / `#>>`）
  - 4.8.2 XML 函数：`XMLELEMENT`、`XMLAGG`、`EXTRACT` (XML) 等
- **4.9 其他函数**
  - 4.9.1 `GREATEST` / `LEAST` 对 NULL 的处理差异
  - 4.9.2 `SYS_GUID()` → `UUID` 生成函数
  - 4.9.3 `USER` / `UID` → 目标库当前用户函数

### 5. 过程化语言兼容性
- **5.1 块结构与声明**
  - 5.1.1 匿名块语法：`DECLARE ... BEGIN ... END` → 目标库 `DO` 块或直接执行
  - 5.1.2 变量声明：`:=` 赋值、`DEFAULT` 关键字
  - 5.1.3 `%TYPE` / `%ROWTYPE` 属性 → 无此特性时的显式类型声明
  - 5.1.4 记录类型与集合类型：`TYPE ... IS RECORD`、`TYPE ... IS TABLE OF` / `VARRAY`
- **5.2 控制流**
  - 5.2.1 `IF ... ELSIF ... ELSE` → 目标库 `ELSEIF` / `ELSE IF` 差异
  - 5.2.2 `FOR i IN 1..n LOOP` 整数范围循环
  - 5.2.3 `FOR rec IN cursor LOOP` 隐式游标循环
  - 5.2.4 `GOTO` 语句支持度
  - 5.2.5 `CASE` 语句/表达式差异
- **5.3 游标管理**
  - 5.3.1 显式游标：`OPEN` / `FETCH` / `CLOSE` 及 `%FOUND` / `%NOTFOUND` / `%ROWCOUNT`
  - 5.3.2 参数化游标
  - 5.3.3 `REF CURSOR`（`SYS_REFCURSOR`）返回结果集 → 目标库 `REFCURSOR` 或表值函数
  - 5.3.4 `CURSOR FOR ...` 隐式游标与 `FOR UPDATE` 结合
- **5.4 异常处理**
  - 5.4.1 `EXCEPTION WHEN` 块结构
  - 5.4.2 预定义异常名称映射（`NO_DATA_FOUND` → `SQLSTATE '02000'`）
  - 5.4.3 `RAISE_APPLICATION_ERROR` → `RAISE EXCEPTION`
  - 5.4.4 异常传播与 `PRAGMA EXCEPTION_INIT`
- **5.5 存储过程与函数**
  - 5.5.1 参数模式：`IN` / `OUT` / `IN OUT` 对应实现
  - 5.5.2 默认参数值、命名参数调用
  - 5.5.3 管道函数（`PIPELINED`）→ 表值函数 / `RETURN QUERY`
  - 5.5.4 函数返回值类型限制（如不可返回 `BOOLEAN` 在某些目标库）
- **5.6 包/模块**
  - 5.6.1 包规范与包体分离 → 使用 schema + 函数/过程 + 类型组织
  - 5.6.2 包级变量和常量（会话级全局状态）→ 替代方案（临时表、自定义上下文变量）
  - 5.6.3 包初始化块
- **5.7 触发器**
  - 5.7.1 行级/语句级 `BEFORE` / `AFTER` / `INSTEAD OF`
  - 5.7.2 复合触发器（`COMPOUND TRIGGER`）→ 拆分为多个触发器
  - 5.7.3 `:OLD` / `:NEW` 引用差异（`OLD` / `NEW` 无冒号）
  - 5.7.4 触发器执行顺序控制（`FOLLOWS` 等）
- **5.8 动态 SQL**
  - 5.8.1 `EXECUTE IMMEDIATE` 语法差异
  - 5.8.2 `OPEN FOR` 动态游标
  - 5.8.3 `DBMS_SQL` 包替代（构建动态 SQL 的 API）
- **5.9 事务管理**
  - 5.9.1 自治事务（`PRAGMA AUTONOMOUS_TRANSACTION`）→ 目标库 `dblink` 或模拟
  - 5.9.2 `SAVEPOINT` / 部分回滚行为
  - 5.9.3 隐式提交差异（DDL 是否自动提交等）
  
### 5.10 内置系统包

#### 5.10.1 调试、输出与诊断
- `DBMS_OUTPUT` → 目标库 `RAISE NOTICE` / `PRINT` / 系统日志函数
- `DBMS_DEBUG` → 目标库调试器（如 `pldbgapi`）
- `DBMS_PROFILER` / `DBMS_HPROF` → 性能剖析工具替代（`pg_stat_statements` / `Query Profiler`）
- `DBMS_TRACE` → SQL 跟踪替代（`auto_explain` / 扩展事件）
- `DBMS_ERRLOG` → DML 错误日志记录表（需手动实现或特性补齐）
- `UTL_CALL_STACK` → 调用堆栈信息函数（`GET DIAGNOSTICS` / `pg_backtrace`）

#### 5.10.2 作业与调度
- `DBMS_JOB` → `pg_cron` / `mysql.event` / 操作系统 crontab
- `DBMS_SCHEDULER` → `pg_cron` / `pgAgent` / SQL Server Agent / 外部调度器
- `DBMS_REFRESH` （快照刷新组）→ 物化视图刷新组或调度任务替代

#### 5.10.3 文件与操作系统交互
- `UTL_FILE` → 服务端文件读写扩展（`pg_file_write` / `LOAD_FILE` / 外部过程）
- `UTL_RAW` → `bytea` 类型与二进制函数
- `UTL_I18N` → 国际化与字符集转换函数
- `UTL_ENCODE` / `UTL_DECODE` → Base64/十六进制编解码函数（`encode`/`decode`）
- `UTL_COMPRESS` → 压缩/解压缩函数

#### 5.10.4 网络与通信
- `UTL_MAIL` → 邮件扩展（`pgMail` / 外部脚本调用）
- `UTL_SMTP` → 发送邮件（需外部邮件服务或 SMTP 扩展）
- `UTL_HTTP` → HTTP 请求扩展（`http` 扩展 / `curl` 函数）
- `UTL_TCP` → TCP/IP 套接字通信
- `UTL_URL` → URL 编码/解码函数

#### 5.10.5 安全与加密
- `DBMS_CRYPTO` → `pgcrypto` 扩展 / 内置加解密函数
- `DBMS_OBFUSCATION_TOOLKIT` → 同上，功能可合并
- `DBMS_RLS` （行级安全，RLS/VPD）→ 目标库行级安全策略（PostgreSQL RLS / 视图）
- `DBMS_FGA` （细粒度审计）→ 审计扩展 / 触发器替代
- `DBMS_LDAP` → LDAP 认证扩展
- `DBMS_NETWORK_ACL_ADMIN` → 网络访问控制列表（目标库访问控制方式）

#### 5.10.6 XML 处理
- `DBMS_XMLDOM` → XML 解析与操作函数（`xpath` / `xml2` 扩展）
- `DBMS_XMLPARSER` → XML 解析器
- `DBMS_XSLPROCESSOR` → XSLT 转换
- `DBMS_XMLGEN` → 从 SQL 生成 XML
- `DBMS_XMLQUERY` → XML 查询
- `DBMS_XMLSTORE` → 通过 XML 进行 DML 操作
- `DBMS_XMLSCHEMA` → XML Schema 管理
- `DBMS_XMLINDEX` → XML 索引管理

#### 5.10.7 JSON 处理
- `JSON_OBJECT_T` / `JSON_ARRAY_T` 等 PL/SQL JSON 类型 → 目标库 JSON 类型/函数（`jsonb`）
- `JSON_TABLE` → `jsonb_to_recordset` / `OPENJSON` 等
- `APEX_JSON` （旧版或 APEX 依赖）→ 目标库 JSON 函数替代

#### 5.10.8 高级队列与消息传递
- `DBMS_AQ` （高级队列）→ `pgmq` / Redis / RabbitMQ / `LISTEN`/`NOTIFY`
- `DBMS_AQADM` （队列管理包）→ 对应队列的管理命令
- `DBMS_PIPE` → `LISTEN`/`NOTIFY` 或会话间通信替代方案
- `DBMS_ALERT` → `LISTEN`/`NOTIFY` / 轮询表

#### 5.10.9 动态 SQL 与执行
- `DBMS_SQL` （完整动态 SQL API）→ `EXECUTE IMMEDIATE` / 目标库动态 SQL 函数（部分高级特性需声明补齐）
- `DBMS_PARALLEL_EXECUTE` → 并行执行框架替代（`dblink` + 分片 / 并行查询）

#### 5.10.10 统计与性能分析
- `DBMS_STATS` → `ANALYZE` / `VACUUM ANALYZE` / 自动统计收集
- `DBMS_STAT_FUNCS` → 统计函数
- `DBMS_SQLTUNE` → 查询优化建议工具（`EXPLAIN` 结合外部工具）

#### 5.10.11 元数据与 DDL 管理
- `DBMS_METADATA` → `pg_get_*` 函数 / `information_schema` 查询
- `DBMS_DDL` → 直接执行 DDL 及系统目录操作函数
- `DBMS_REDEFINITION` → 在线重定义工具（`pg_repack` / `pt-online-schema-change`）
- `DBMS_COMPARISON` → 数据比较与同步工具（外部工具替代）

#### 5.10.12 事务与恢复
- `DBMS_FLASHBACK` → 时态表 / 时间点恢复（PITR） / 闪回查询替代
- `DBMS_LOGMNR` → 逻辑解码（`pgoutput` / `test_decoding`）
- `DBMS_XA` → XA 分布式事务接口（目标库 XA 支持）

#### 5.10.13 常用工具与系统信息
- `DBMS_UTILITY` （含 `FORMAT_CALL_STACK`、`GET_TIME` 等）→ 系统信息函数、时间函数
- `DBMS_RANDOM` → `RANDOM()` / `gen_random_uuid()` 等
- `DBMS_APPLICATION_INFO` → `application_name` 参数设置
- `DBMS_SESSION` → 会话级参数设置（`SET` 命令）
- `DBMS_LOCK` → `pg_advisory_lock` 等锁管理函数
- `DBMS_ASSERT` → SQL 注入检查函数（需特性补齐或应用层校验）

#### 5.10.14 空间数据
- `MDSYS.SDO_GEOMETRY` 相关包 → PostGIS / 空间扩展
- `SDO_CS` / `SDO_TUNE` / `SDO_GEOM` 等 → 对应空间函数

#### 5.10.15 数据泵与迁移
- `DBMS_DATAPUMP` → `pg_dump` / `pg_restore` 编程调用或外部脚本
- `DBMS_FILE_TRANSFER` → `COPY` 命令 / 文件传输工具

#### 5.10.16 其他高级特性
- `DBMS_MVIEW` （物化视图管理）→ 物化视图刷新函数
