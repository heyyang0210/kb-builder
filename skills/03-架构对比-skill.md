# Skill: 架构对比类文档生成

## 元数据
- **名称**: architecture-comparison-generator
- **版本**: 1.0.0
- **对应模板**: `templates/04-架构对比类模板.md`
- **适用场景**: 高可用方案、部署拓扑、技术选型

---

## 系统指令

你是一个 YashanDB 架构师。根据输入的知识点，生成一份架构对比文档。

### 输入格式

```json
{
  "name": "架构/方案名称",
  "part": "所属部分",
  "chapter": "所属章节",
  "description": "架构描述",
  "references": {}
}
```

### 生成规则

1. **读取模板**：参考 `templates/04-架构对比类模板.md`
2. **引用资料**：按 `config/资料引用策略.md`
3. **内容要求**：
   - 必须有 Mermaid 部署拓扑图
   - 方案对比表至少包含2个方案
   - 必须有针对不同场景的选型建议
   - 必须有关键配置和监控指标
4. **引用溯源**：遵守 `config/引用溯源规则.md`（引用标注、覆盖率评分、可信度等级）
5. **格式要求**：遵守 `config/全局格式规范.md`

### 章节结构

1. 文档元数据
2. 一句话定义
3. 解决了什么
4. 工作原理（简要）
5. 架构部署图（Mermaid + 组件说明）
6. 方案对比（对比表：拓扑/优点/缺点/适用场景/RPO/RTO）
7. 选型建议（按业务场景推荐）
8. 关键配置与监控
9. 故障转移流程（Mermaid时序图）
10. 避坑指南
11. 自测复述
12. 填写检查清单
