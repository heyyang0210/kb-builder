# 生成输出目录

本目录存放 AI 生成的 YashanDB 知识文档。

## 目录结构

```
output/
├── 01-基础入门/          # 第一部分生成的文档
├── 02-核心原理/          # 第二部分生成的文档
├── 03-数据库管理/        # 第三部分生成的文档
├── 04-SQL编程/          # 第四部分生成的文档
├── 05-性能优化/          # 第五部分生成的文档
├── 06-高可用与集群/      # 第六部分生成的文档
├── 07-内核与高级专题/    # 第七部分生成的文档
└── 08-架构设计与实践/    # 第八部分生成的文档
```

## 文件命名规范

`[序号]-[知识名称].md`

示例：
- `01-数据库概述.md`
- `02-B+树索引原理.md`
- `07-序列兼容性.md`

## 审阅状态

每个文档的 YAML 元数据中包含审阅状态：

- `□待审阅`：AI 生成后未经人工审阅
- `□已审阅`：人工审阅通过，内容基本准确
- `□已验证`：通过双库测试验证，可发布
